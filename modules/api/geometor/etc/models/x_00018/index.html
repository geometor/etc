Construct X_18 = 2ND NAPOLEON POINT and its classical incident central lines on ABC.

Constructed elements include:

  • Inner equilateral triangles and inner Napoleon triangle < Nap'_a Nap'_b Nap'_c > with perspectivity lines [ A Nap'_a ], [ B Nap'_b ], [ C Nap'_c ] concurring at X_18.

  • Incident central lines: { 3, 14 }, { 5, 13 }, { 4, 16 }, and Napoleon line { 6, 17 }.
