geometor.etc.svg_opt¶

SVG optimization utilities for GEOMETOR ETC web delivery and thumbnail generation.

Provides exact analytical Liang-Barsky viewport line clipping and asset stripping so:

  1. Infinite dashed lines span ~2.5x the viewBox (~250 dashes) instead of 1,500x (~165k dashes).

  2. Web-injected viewer SVGs strip duplicate per-SVG <style> and <script> blocks while keeping pure SVG geometry, data-line vectors for infinite pan/zoom, and .etc-elements-meta.

  3. Collection thumbnail SVGs (loaded in <img loading="lazy">) strip all scripts and JSON metadata and keep only a compact ~1.3 KB visual-only <style> block.

Clip oversized infinite <line> elements to a tight box around the SVG viewBox.

Also injects data-line="x0,y0,ux,uy" so etc-viewer.js can dynamically re-clip infinite lines seamlessly during interactive pan and zoom.

geometor.etc.svg_opt.normalize_svg_points(svg_text: str, point_r_px: float = 4.8) → str¶

Normalize all point dots to a uniform compact radius and Explorer selected styling.

Applies both to Explorer-rendered #points groups and static coordinate/4-triangle .etc-plate-pt SVGs so existing on-disk SVGs stay visually consistent without re-rendering.

geometor.etc.svg_opt.strip_svg_for_viewer(svg_text: str, lines_vb: str | None = None) → str¶

Prepare a lightweight pure-geometry + metadata SVG for injection into .etc-viewer.

Strips XML declaration, duplicate <style> blocks, duplicate <script> controllers, and expensive Gaussian blur filters while preserving .etc-elements-meta, normalizing point radii uniformly, and clipping infinite dashed lines to 2.5x viewBox with data-line.

geometor.etc.svg_opt.strip_svg_for_thumbnail(svg_text: str) → str¶

Prepare a compact standalone SVG for <img loading="lazy"> collection thumbnails.

Strips all <script> blocks (including etc-elements-meta JSON, which <img> cannot use), replaces the 12.5 KB interactive stylesheet with a ~1.3 KB static visual stylesheet, normalizes point sizes uniformly, and clips oversized infinite dashed lines.
