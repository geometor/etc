geometor.etc.triangles¶

Exact symbolic reference triangles for the Encyclopedia of Triangle Centers.

Defines the four canonical exact symbolic reference triangles over closed-form algebraic number fields in SymPy:

  1. heronian — Acute Heronian \((15, 13, 14)\) over \(\mathbb{Q}\)

  2. right — Pythagorean Right \((3, 4, 5)\) over \(\mathbb{Q}\)

  3. kepler — Kepler Golden Right \((1, \sqrt{\phi}, \phi)\) over \(\mathbb{Q}(\sqrt{\phi})\)

  4. kimberling — Kimberling Search \((6, 9, 13)\) over \(\mathbb{Q}(\sqrt{35})\)

Exact symbolic reference triangle with side lengths, vertices, and invariants.

Parameters:

  • key – Preset identifier ("heronian", "right", "kepler", "kimberling", or "acute").

  • label – Short human-readable title (e.g. "Heronian (15, 13, 14)").

  • field_latex – LaTeX string naming the ambient algebraic field (e.g. r"\mathbb{Q}").

  • a – Exact side lengths \(a = |BC|\), \(b = |CA|\), \(c = |AB|\).

  • b – Exact side lengths \(a = |BC|\), \(b = |CA|\), \(c = |AB|\).

  • c – Exact side lengths \(a = |BC|\), \(b = |CA|\), \(c = |AB|\).

  • A_xy – Exact Cartesian coordinates of vertices \(A\), \(B\), \(C\).

  • B_xy – Exact Cartesian coordinates of vertices \(A\), \(B\), \(C\).

  • C_xy – Exact Cartesian coordinates of vertices \(A\), \(B\), \(C\).

  • area – Exact area \(\Delta = \operatorname{Area}(\triangle ABC)\).

  • simplify_fn – Field-aware exact simplification callable.

Construct an exact SymbolicTriangle from three side lengths.
