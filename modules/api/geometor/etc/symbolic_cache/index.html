geometor.etc.symbolic_cache¶

Exact symbolic triangle-center registry and disk cache (CenterSymbolicRegistry).

Evaluates homogeneous barycentrics, homogeneous trilinears, normalized barycentrics, exact Cartesian coordinates, signed sub-triangle areas, and Kimberling search values over the four canonical exact symbolic reference triangles without floating-point approximations.

Parameters:

  • triangle – A SymbolicTriangle instance or canonical preset name ("heronian", "right", "kepler", "kimberling").

  • cache_dir – Directory where per-triangle JSON cache files are stored. Pass None to disable disk persistence (in-memory only).
