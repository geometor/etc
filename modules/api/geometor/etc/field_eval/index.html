geometor.etc.field_eval¶

Fast, 100% exact algebraic-field evaluator for ETC triangle centers.

Evaluates arbitrary ETC homogeneous trilinear/barycentric expressions and algebraic relation graphs directly inside each canonical reference triangle’s exact number field — zero floating-point drift, zero SymPy expression-tree blowup, and ~500x faster than symbolic expression simplification:

  1. heronian (15, 13, 14) : Q (and Q(sqrt(3)) when trig pi/3 appears)

  2. right (5, 3, 4) : Q (and Q(sqrt(3)))

  3. equilateral (2, 2, 2) : Q(sqrt(3))

  4. kimberling (6, 9, 13) : Q(sqrt(35)) (and Q(sqrt(35), sqrt(3)))

  5. kepler (phi, 1, s_phi): Q(sqrt(phi)), alpha^4 = alpha^2 + 1

  6. golden (phi, phi, 1) : Q(tau), tau^4 = 10*tau^2 - 5

  7. gnomon (1, 1, phi) : Q(tau), tau^4 = 10*tau^2 - 5

For the small subset of ETC centers involving genuinely transcendental or non-field expressions (e.g. cos(A/3), arcsin, cubic roots), falls back explicitly to 50-digit mpmath evaluation tagged precision="mpmath-50" while never injecting floats into geometor.model.
