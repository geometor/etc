geometor.etc.shards¶

Parallel exact-symbolic JSON shard builder for GEOMETOR ETC.

Compiles parsed ETC center HTML files across all 7 canonical reference triangles using geometor.etc.field_eval into compact 100-center JSON shards, a shared companion-center lookup table (core-centers.json), a fast search index (search-index.json), and a manifest with exact projective collinearity audit metrics (manifest.json).

Usage:

uv run --no-sync python -m geometor.etc.shards --end 4000
        uv run --no-sync python -m geometor.etc.shards --end 53144
