geometor.etc.ops¶

Composable geometric construction operators for geometor.etc using geometor.model.

Every operator accepts (model, A, B, C, …) or (model, P, Q, …) where points are sympy.geometry.Point instances registered in model, enabling both classical Euclidean compass-and-straightedge constructions and higher-order triangle-center compositions.
