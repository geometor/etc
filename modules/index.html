geometor.etc¶

Tools for processing and modeling the Encyclopedia of Triangle Centers (ETC).

Key Components:¶

  • Ingest: Tools (ingest_folder()) to split and organize the raw HTML source.

  • Parser: Tools (parse_center()) to extract center data from HTML.

  • Glossary: Tools (extract_glossary_terms()) to handle glossary terms, persons, and citations.

  • Ops: Composable Euclidean construction primitives and triangle operators (geometor.etc.ops).

  • Construct: Coordinate/incidence resolver, Model builder, and per-center model.py generator (geometor.etc.construct).

  • Render: Explorer-styled SVG renderer (geometor.etc.render).

  • Transform: Tools (generate_rst_files()) to generate per-center ReStructuredText folders and graphics.

Usage:¶

Use the main function in __main__.py or the individual modules to process ETC data.
