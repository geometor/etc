changelog¶

project:

geometor.etc

0.4.0¶

2026-11-19

  • added: Full 73,310-center exact symbolic evaluation engine (field_eval.py) and sharded JSON corpus generator (shards.py) spanning all 37 ETC Parts (X_1–X_73310, zero gaps) across all 7 canonical reference triangles (Heronian (15, 13, 14), Right (5, 3, 4), Kepler (φ, 1, √φ), Kimberling (6, 9, 13), Golden (φ, φ, 1), Gnomon (1, 1, φ), Equilateral (2, 2, 2)) with 96.9% exact algebraic resolution on Heronian/Kimberling and 98.37% exact projective collinearity verification.

  • added: Unified client-side Live Center Explorer (docsrc/centers/explore.rst, etc-live-viewer.js) serving all 73,310 centers and all 987 family groups (925 ETC preamble families + 62 curated collections via families.json) with live 7-triangle Family Constellations (#family/<id>), searchable Families drawer, Tier 0–4 geometric construction engine (complete textbook compass-and-straightedge constructions for X_1–X_19 plus universal derived-triangle, defining-line, functional-relation, and cevian constructions for X_20–X_73310), sparse-dot-to-solid color-matched line highlighting, zoom-invariant point rings, unified Construction/Coordinates workspace, docked stage footer, and true edge-to-edge Fullscreen App Mode (F) with live center ID, title, and 5-track switching.

  • changed: Unified Collection 1 (X_1–X_19) and all 62 collection landing pages into one consistent format backed by the Live Center Explorer; preserved the 19 exact SymPy geometor.model construction scripts under src/geometor/etc/models/x_00001.py–x_00019.py and retired all 4,000 redundant static x-00001–x-04000 directories (cutting clean Sphinx build time from 6+ minutes to 46.6 s and docs/ footprint from 1.2 GB to 409 MB).

  • changed: Updated GitHub Actions deployment workflow (.github/workflows/action.yml) to fetch the compressed v0.4.0 exact symbolic shard corpus archive into .cache/etc_data prior to publish build.

  • fixed: Resolved 4 upstream Evansville HTML heading typos (X_57621, X_60349, X_68618, X_71412) in ingest.py and parser.py, hardened field_eval.py against >308-digit OverflowError via 50-digit mpmath normalization, and fixed MathJax v4 typesetting inside dynamic live explorer views.

0.3.2¶

2026-11-14

  • Standardized top-level About page (docsrc/about/index.rst promoted to top header :order: 10) with the three-pillar GEOMETOR semantic-extraction mission and archival provenance; retired docsrc/mission/ stubs cleanly into Home and About.

0.3.1¶

2026-11-14

  • Standardized Book Title Page, top-level Header Navigation (Book, People, Bibliography, Usage), Reader’s Guide (docsrc/usage/), featured Author/Translator profiles in People, and English structural terminology.

0.3.0¶

  • Generalized the 5-act exact symbolic Book Codex architecture across all 19 classical centers of Collection 1 (X_1–X_19: plates.py, ops.py, symbolic_cache.py, transform.py), generating 156 interactive Explorer-styled SVGs (8 plates per center + 4 collection overview plates) and caching 84 exact symbolic center records across all 4 canonical reference triangles with zero floating-point drift.

0.2.0¶

  • Added the 4-triangle exact symbolic reference engine (triangles.py) and persistent symbolic evaluation cache (symbolic_cache.py: CenterSymbolicRegistry, SymbolicCenterRecord) over 5, 6, 7, 3, 4, 5, Kepler, and Kimberling triangles.

  • Expanded ops.py with exact Euclidean construction primitives and CANONICAL_CENTER_CONCORDANCE operators built on geometor.model v0.6.0 targeted DAGs and Rational Trigonometry invariants.

  • Established the 5-act X_1 Book Codex center template, multi-panel Explorer-styled SVG diagrams (01_primary through 05_four_triangles), exact symbolic HUD metadata, and synchronized videos/x-00001/script.scr studio choreography.

  • Updated GitHub Actions deployment workflow to install geometor/model before geometor/etc with contents: write permissions.

0.1.8¶

  • Replaced generic local point/triangle symbols (A’, B’, C’, X, Y, Z, X’, Y’, Z’, I_aI_bI_c) in enunciations and notes with their canonical special point labels (T_a, T_b, T_c, H_a, H_b, H_c, M_a, M_b, M_c, N_a, N_b, N_c, J_a, J_b, J_c, I_a, I_b, I_c, Tan_a, Tan_b, Tan_c, K_a, K_b, K_c, Sym_a, Sym_b, Sym_c, Eu_a, Eu_b, Eu_c, Ref_a, Ref_b, Ref_c, Cm_a, Cm_b, Cm_c, O_A, O_B, O_C, Nap_a, Nap_b, Nap_c) whenever bound to a known special triangle or vertex triple.

  • Removed redundant side-by-side (denoted …) and (:g:`A’ <T_a>)` alias annotations from Constructed Elements blocks across all 3,000 center pages.

0.1.7¶

  • Expanded coordinate, incidence, and functional relation resolution to X1 through X3000 (100% resolved across all 4 reference triangles: 5, 6, 7, 3, 4, 5, Kepler, and Kimberling).

  • Added preamble transformation handlers (Orion transforms, Eigentransforms, Gibert-Simson transforms, Rigby-Simson and Simson-Rigby points, Simson-Moses points, Tangential/Medial/Anticomplementary-Isogonal conjugates, Dual Center DC(X) / CD(X) mappings, and $Xi$-isoconjugates), Steiner inellipse constant $K$, and multi-clause cyclic helper expansion (h(a,b,c), k(a,b,c)).

  • Added a continuous-limit perturbation pass for removable $0/0$ singularities at $C = 90^circ$ on right and Kepler triangles.

  • Added 14 new thematic collections (c-02001-02054 through c-02967-03000, bringing the total to 52 thematic collections) with 4-triangle constellation graphics (c-XXXXX-YYYYY.svg).

0.1.6¶

  • Expanded coordinate and geometric construction resolution to X1 through X2000 (100% resolved across all 4 reference triangles: 5, 6, 7, 3, 4, 5, Kepler, and Kimberling).

  • Added preamble transformation handlers (Saragossa points, Collings transforms, Brisse transforms, Orthojoin points, TCC-perspectors), x:y:z = Xk trilinear coordinate substitutions, and seeded roots (X134, X180, X1144).

  • Organized X1–X2000 into 38 thematic collections (docsrc/centers/c-XXXXX-YYYYY/) aligned with Kimberling’s section preambles and geometric families so docs/centers/index.html loads instantaneously (~54 KB instead of ~30 MB).

  • Generated multi-center constellation graphics (c-XXXXX-YYYYY.svg across all 4 reference triangles) for each thematic collection using an editorial selection of 11–16 spatially separated landmark centers with interactive hover labels and click-to-navigate center dots.

0.1.5¶

  • Standardized triangle center identifiers and references from Xn to subscripted Xn (X1, X2, …, rendered as X<sub>n</sub> in HTML and <tspan> subscripts in SVG).

  • Added contextual A’B’C’ classical triangle resolution in prose so :g: roles bind A’, B’, C’ to their model IDs (M_a, H_a, T_a, I_a, etc.) when constructed on the canvas.

  • Rendered underscore point labels (M_a, H_a, I_a, Xn) with <tspan> subscripts and font-relative 0.15em strokes in Explorer-styled SVGs.

  • Redesigned center page headings as two centered lines (Xn over bold non-italic subtitle rubric, with position: absolute headerlink alignment).

0.1.4¶

  • Added semantic math normalization and :g: geometric element roles across parsed center descriptions, notes, and glossary entries.

0.1.3¶

  • Adopted the Book Codex layout (:layout: book) across docsrc/centers/ and the scholarly apparatus (glossary.rst, persons.rst, bibliography.rst).

  • Added a 2-track companion switcher (Overview | Code) generating per-center code.rst pages alongside index.rst.

  • Extracted primary geometric definitions into .. enunciation:: banners (powering collection excerpts and :ref: tooltips) and consolidated primary coordinates into a compact .. signature:: center card.

  • Organized secondary apparatus into collapsible .. collapse:: sections (Alternate Coordinates, Linear Combinations, Incident Central Lines, and Functional Relations) with count badges.

0.1.2¶

  • Simplified initial center graphics into a focused primary construction layer showing only the specific defining geometric relationship (and the golden Euler line whenever $Xn$ lies on the Euler line).

  • Added a Lines toolbar toggle button to show/hide incident central lines {i, j} and their defining centers across all 4 reference triangle tabs.

  • Escaped XML special characters (<, >, &) as JSON unicode sequences in embedded SVG metadata so collection page <img> thumbnails pass strict XML validation.

  • Expanded coordinate/incidence resolution and generated documentation and interactive graphics for X1 through X1000.

0.1.1¶

  • Added interactive Explorer-styled SVG controls (zoom, pan, reset, label/guide toggles) and native topmost element hover highlighting with named points, lines, circles, and triangles.

  • Scaled point radii and label typography $1.5times$ for legibility.

  • Unified reference triangle graphics into a 4-tab graphics panel (5, 6, 7, 3, 4, 5, Kepler, and Kimberling) on center pages while keeping static thumbnails on collection pages.

  • Added projective limit fallback evaluation and coincident point handling for right triangles (3, 4, 5 and Kepler).

0.1.0¶

  • Added semantic parser, glossary/person/citation registries, composable triangle construction operators (ops.py), and per-center folders with model.py, x-NNNNN.json, and x-NNNNN.svg.

0.0.2¶

  • Refined docstrings and type hinting.

  • Fixed from __future__ import annotations placement.
