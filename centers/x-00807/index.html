X(807) = o-(- 2, 3) CIRCUMCIRCLE POINT¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = 1/[a -3(b3 - c3) + a2(b -2 - c -2)]

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = af(a,b,c)

  • Kimberling (6, 9, 13) Search Value: \(-0.512487665362\)

Incidence¶

X(807) lies on the circumcircle.

Relations¶

"""GEOMETOR construction model for X(807) = o-(- 2, 3) CIRCUMCIRCLE POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00807(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(807) = o-(- 2, 3) CIRCUMCIRCLE POINT on reference triangle ABC."""
              X_806 = eval_trilinear_point(model, A, B, C, 'a**(-3)*(b**(3)- c**(3)) + a**(2)*(b**(-2)- c**(-2))', ID="X(806)", classes=["center"])
              X_807 = isogonal_conjugate(model, A, B, C, X_806, ID="X(807)", classes=["selected", "target"])
              return promote_point_to_top(model, X_807)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(807) on the given reference triangle."""
              model = create_model('X(807) = o-(- 2, 3) CIRCUMCIRCLE POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00807(model, A, B, C)
              return model


          if __name__ == "__main__":
