X(646) = BARYCENTRIC MULTIPLIER FOR YFF PARABOLA¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = (b + c - a)/[a2(b - c)]

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = (b + c - a)/[a(b - c)]

  • Kimberling (6, 9, 13) Search Value: \(9.403725070080\)

Notes¶

X(646) satisfies the equation X*(incircle) = Yff parabola, where * denotes barycentric multiplication, defined by

(u : v : w) * (x : y : z) = ux : vy : wz (barycentric coordinates, see note at X(2)).

Incidence¶

X(646) lies and on these lines:

{190, 668}, {644, 645}

Relations¶

  • X(646) = isotomic conjugate of X(3669)

  • X(646) = trilinear pole of line X(8)X(210) (the tangent to Feuerbach hyperbola at X(8))

  • X(646) = X(650)-cross conjugate of X(8)

  • X(646) = X(522)-cross conjugate of X(314)

  • X(646) = PU(4)-harmonic conjugate of polar conjugate of X(35158)

"""GEOMETOR construction model for X(646) = BARYCENTRIC MULTIPLIER FOR YFF PARABOLA."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00646(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(646) = BARYCENTRIC MULTIPLIER FOR YFF PARABOLA on reference triangle ABC."""
              X_646 = eval_trilinear_point(model, A, B, C, '(b + c - a)/(a**(2)*(b - c))', ID="X(646)", classes=["selected", "target"])
              X_644 = eval_trilinear_point(model, A, B, C, '(b + c - a)/(b - c)', ID="X(644)", classes=["center", "incident"])
              X_645 = eval_trilinear_point(model, A, B, C, '(b + c - a)/(a*(b**(2)- c**(2)))', ID="X(645)", classes=["center", "incident"])
              central_line(model, X_644, X_645, 644, 645, incident=True)
              X_190 = eval_trilinear_point(model, A, B, C, 'b*c/(b - c)', ID="X(190)", classes=["center", "incident"])
              X_668 = eval_trilinear_point(model, A, B, C, '1/(a**(2)*(b - c))', ID="X(668)", classes=["center", "incident"])
              central_line(model, X_190, X_668, 190, 668, incident=True)
              return promote_point_to_top(model, X_646)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(646) on the given reference triangle."""
              model = create_model('X(646) = BARYCENTRIC MULTIPLIER FOR YFF PARABOLA')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00646(model, A, B, C)
              return model
