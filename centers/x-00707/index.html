X(707) = EVEN (- 4, 2) CIRCUMCIRCLE POINT¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = 1/[a -5(b2 + c2) - a1(b -4 + c -4)]

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = af(a,b,c)

  • Kimberling (6, 9, 13) Search Value: \(-0.463105198649\)

Incidence¶

Relations¶

  • X(707) = isotomic conjugate of X(35528)

"""GEOMETOR construction model for X(707) = EVEN (- 4, 2) CIRCUMCIRCLE POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00707(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(707) = EVEN (- 4, 2) CIRCUMCIRCLE POINT on reference triangle ABC."""
              X_706 = eval_trilinear_point(model, A, B, C, 'a**(-5)*(b**(2)+ c**(2)) - a**(1)*(b**(-4)+ c**(-4))', ID="X(706)", classes=["center"])
              X_707 = isogonal_conjugate(model, A, B, C, X_706, ID="X(707)", classes=["selected", "target"])
              return promote_point_to_top(model, X_707)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(707) on the given reference triangle."""
              model = create_model('X(707) = EVEN (- 4, 2) CIRCUMCIRCLE POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00707(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
