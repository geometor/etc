X(249) = ISOGONAL CONJUGATE OF X(115)¶

Group Preamble — Centers X(249)-X(297)

Centers X(249)-X(297) are isogonal conjugates of previously listed centers.

Coordinates¶

Trilinears¶

  • \((\csc A)\csc^{2}(B - C) : (\csc B)\csc^{2}(C - A) : (\csc C)\csc^{2}(A - B), = a/(b^{2} - c^{2})^{2} : b/(c^{2} - a^{2})^{2} : c/(a^{2} - b^{2})^{2}\)

  • Kimberling (6, 9, 13) Search Value: \(0.395641663632\)

Notes¶

Barycentrics csc2(B - C) : csc2(C - A) : csc2(A - B)

X(249) is the vertex conjugate of the foci of the inellipse that is the barycentric square of line X(2)X(6). The center of this inellipse is X(620), and its perspector is X(4590). (Randy Hutson, October 15, 2018)

X(249) is the trilinear pole of line X(110)X(351), which is the tangent to the circumcircle at X(110), and the locus of trilinear poles of tangents at P to hyperbola {A,B,C,X(6),P}}, as P moves on the Brocard axis. (Randy Hutson, October 15, 2018)

Incidence¶

X(249) lies and on these lines:

{99, 525}, {110, 512}, {186, 250}, {187, 323}, {297, 316}, {648, 687}, {805, 827}, {849, 1110}

Relations¶

  • X(249) = isogonal conjugate of X(115)

  • X(249) = isotomic conjugate of X(338)

  • X(249) = cevapoint of X(i) and X(j) for these (i,j): (6, 110), (24, 112), (1379, 1380)

  • X(249) = X(i)-cross conjugate of X(j) for these (i,j): (3, 99), (6, 110)

  • X(249) = perspector of ABC and reflection of symmedial triangle in the Brocard axis

  • X(249) = polar conjugate of X(2970)

  • X(249) = X(63)-isoconjugate of X(8754)

  • X(249) = X(92)-isoconjugate of X(125)

  • X(249) = crossdifference of every pair of points on line X(1648)X(8029)

  • X(249) = Vu circlecevian point of PU(2)

"""GEOMETOR construction model for X(249) = ISOGONAL CONJUGATE OF X(115)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00249(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(249) = ISOGONAL CONJUGATE OF X(115) on reference triangle ABC."""
              X_115 = eval_trilinear_point(model, A, B, C, 'b*c*(b**(2) - c**(2))**(2)', ID="X(115)", classes=["center"])
              X_249 = isogonal_conjugate(model, A, B, C, X_115, ID="X(249)", classes=["selected", "target"])
              X_186 = eval_trilinear_point(model, A, B, C, '4*cos(A) - sec(A)', ID="X(186)", classes=["center", "incident"])
              X_250 = eval_trilinear_point(model, A, B, C, '(sec(A))*(csc(B - C))**(2)', ID="X(250)", classes=["center", "incident"])
              central_line(model, X_186, X_250, 186, 250, incident=True)
              X_187 = eval_trilinear_point(model, A, B, C, 'a*(2*a**(2) - b**(2) - c**(2))', ID="X(187)", classes=["center", "incident"])
              X_323 = eval_trilinear_point(model, A, B, C, '4*sin(A) - 3*csc(A)', ID="X(323)", classes=["center", "incident"])
              central_line(model, X_187, X_323, 187, 323, incident=True)
              X_297 = eval_trilinear_point(model, A, B, C, 'csc(2*A)*cos(A + omega )', ID="X(297)", classes=["center", "incident"])
              X_316 = eval_trilinear_point(model, A, B, C, 'b*c*(b**(4)+ c**(4)- a**(4)- b**(2)*c**(2))', ID="X(316)", classes=["center", "incident"])
              central_line(model, X_297, X_316, 297, 316, incident=True)
              return promote_point_to_top(model, X_249)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(249) on the given reference triangle."""
              model = create_model('X(249) = ISOGONAL CONJUGATE OF X(115)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00249(model, A, B, C)
              return model
