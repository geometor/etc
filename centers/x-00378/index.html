X(378) = REFLECTION OF X(22) IN X(3)¶

Coordinates¶

Trilinears¶

  • \(\sec A + 2 \cos A : \sec B + 2 \cos B : \sec C + 2 \cos C\)

Barycentrics¶

  • \(\tan A + \sin 2A : \tan B + \sin 2B : \tan C + \sin 2C : :\)

  • \(a^2 (a^4 + b^4 + c^4 - 2 a^2 b^2 - 2 a^2 c^2 + 4 b^2 c^2)/(b^2 + c^2 - a^2) : :\)

  • Kimberling (6, 9, 13) Search Value: \(37.928175425362\)

Linear Combinations¶

  • X(378) = 6 X(2) + (J^2 + 3) X(3) = 2 X(3) - X(22)

Notes¶

As a point on the Euler line, X(378) has Shinagawa coefficients (2F, E - 2F).

X(378) is the {X(3),X(4)}-harmonic conjugate of X(24).

Incidence¶

X(378) lies and on these lines:

{1, 1063}, {2, 3}, {6, 74}, {33, 36}, {34, 35}, {54, 64}, {99, 264}, {185, 578}, {232, 574}, {477, 935}, {847, 1105}

Relations¶

  • X(378) = reflection of X(i) in X(j) for these (i,j): (4, 427), (22, 3)

  • X(378) = isogonal conjugate of X(4846)

  • X(378) = anticomplement of X(15760)

  • X(378) = inverse-in-orthocentroidal-circle of X(403)

  • X(378) = harmonic center of circumcircle and polar circle

  • X(378) = polar conjugate of X(34289)

  • X(378) = endo-homothetic center of X(4)-anti-altimedial and anti-orthocentroidal triangles

Construction¶

"""GEOMETOR construction model for X(378) = REFLECTION OF X(22) IN X(3)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcenter_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00378(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(378) = REFLECTION OF X(22) IN X(3) on reference triangle ABC."""
              X_378 = eval_trilinear_point(model, A, B, C, 'sec(A) + 2*cos(A)', ID="X(378)", classes=["selected", "target"])
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              central_line(model, X_2, X_3, 2, 3)
              X_33 = eval_trilinear_point(model, A, B, C, '1 + sec(A)', ID="X(33)", classes=["center", "incident"])
              X_36 = eval_trilinear_point(model, A, B, C, '1 - 2*cos(A)', ID="X(36)", classes=["center", "incident"])
              central_line(model, X_33, X_36, 33, 36, incident=True)
              X_34 = eval_trilinear_point(model, A, B, C, '1 - sec(A)', ID="X(34)", classes=["center", "incident"])
              X_35 = eval_trilinear_point(model, A, B, C, '1 + 2*cos(A)', ID="X(35)", classes=["center", "incident"])
              central_line(model, X_34, X_35, 34, 35, incident=True)
              return promote_point_to_top(model, X_378)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(378) on the given reference triangle."""
              model = create_model('X(378) = REFLECTION OF X(22) IN X(3)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00378(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00378.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00378.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
