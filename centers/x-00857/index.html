X(857) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(75)¶

Coordinates¶

Trilinears¶

  • \(f(A,B,C) : f(B,C,A) : f(C,A,B),\), where f(A,B,C) = sin2C sin 2B sin(C - A) + sin2B sin 2C sin(B - A)

Barycentrics¶

  • \(g(A,B,C) : g(B,C,A) : g(C,A,B)\), where g(A,B,C) = (sin A)f(A,B,C)

  • Kimberling (6, 9, 13) Search Value: \(8.299528356664\)

Notes¶

As a point on the Euler line, X(857) has Shinagawa coefficients ($aSBSC$, - $a$S2).

Incidence¶

X(857) lies and on these lines:

{2, 3}, {514, 661}

Relations¶

  • X(857) = isotomic conjugate of X(37202)

  • X(857) = complement of X(14953)

  • X(857) = anticomplement of X(1375)

  • X(857) = inverse-in-orthocentroidal-circle of X(379)

  • X(857) = crossdifference of every pair of points on line X(31)X(647)

"""GEOMETOR construction model for X(857) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(75)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcenter_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              intersect_lines,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00857(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(857) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(75) on reference triangle ABC."""
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              X_514 = eval_trilinear_point(model, A, B, C, '(b - c)/a', ID="X(514)", classes=["center"])
              X_661 = eval_trilinear_point(model, A, B, C, 'cot(B) - cot(C)', ID="X(661)", classes=["center"])
              central_line(model, X_2, X_3, 2, 3)
              central_line(model, X_514, X_661, 514, 661)
              X_857 = intersect_lines(model, X_2, X_3, X_514, X_661, ID="X(857)", classes=["selected", "target"])
              return promote_point_to_top(model, X_857)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(857) on the given reference triangle."""
              model = create_model('X(857) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(75)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00857(model, A, B, C)
              return model
