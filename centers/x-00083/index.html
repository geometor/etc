X(83) = CEVAPOINT OF CENTROID AND SYMMEDIAN POINT¶

Coordinates¶

Trilinears¶

  • \(bc/(b^{2} + c^{2}) : ca/(c^{2} + a^{2}) : ab/(a^{2} + b^{2}), = \csc(A + \omega ) : \csc(B + \omega ) : \csc(C + \omega )\)

  • Kimberling (6, 9, 13) Search Value: \(1.810750169532\)

Notes¶

Barycentrics 1/(b2 + c2) : 1/(c2 + a2) : 1/(a2 + b2)

Let K denote the symmedian point, X(6). Let A’B’C’ be the cevian triangle of K. Let KA be K of the triangle AB’C’; let KB be K of A’BC’ and let KC be K of A’B’C. The lines AKA, BKB, CKC concur in X(83). (Randy Hutson, 9/23/2011)

Let A’B’C’ be the 1st Brocard triangle. Let A″ be the reflection of A’ in BC, and define B″ and C″ cyclically. AA″, BB″, CC″ concur in X(83). (Randy Hutson, December 26, 2015)

Let Ba, Ca be the intersections of lines CA, AB, resp., and the antiparallel to BC through X(2). Define Cb, Ab, Ac, Bc cyclically. Triangles ABaCa, AbBCb, AcBcC are similar to each other and inversely similar to ABC. Let Sa be the similitude center of triangles AbBCb and AcBcC. Define Sb and Sc cyclically. The lines ASa, BSb, CSc concur in X(83). (Randy Hutson, December 26, 2015)

Let (Oa) be the circle whose diameter is the orthogonal projections of PU(1) on line BC. Define (Ob) and (Oc) cyclically. X(83) is the radical center of circles (Oa), (Ob), (Oc). (Randy Hutson, December 26, 2015)

Let A’B’C’ be the circummedial triangle. Let A″ be the trilinear pole of line B’C’, and define B″ and C″ cyclically. The lines AA″, BB″, CC″ concur in X(83). (Randy Hutson, December 26, 2015)

"""GEOMETOR construction model for X(83) = CEVAPOINT OF CENTROID AND SYMMEDIAN POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
              spieker_center_of,
              symmedian_point_of,
              tangential_triangle,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00083(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(83) = CEVAPOINT OF CENTROID AND SYMMEDIAN POINT on reference triangle ABC."""
              tangential_triangle(model, A, B, C)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_32 = eval_trilinear_point(model, A, B, C, 'a**(3)', ID="X(32)", classes=["center"])
              central_line(model, X_2, X_32, 2, 32)
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              X_76 = eval_trilinear_point(model, A, B, C, '1/a**(3)', ID="X(76)", classes=["center"])
              central_line(model, X_6, X_76, 6, 76)
              X_10 = spieker_center_of(model, A, B, C, ID="X(10)", classes=["center"])
              X_82 = eval_trilinear_point(model, A, B, C, '1/(b**(2) + c**(2))', ID="X(82)", classes=["center"])
              central_line(model, X_10, X_82, 10, 82)
              X_39 = eval_trilinear_point(model, A, B, C, 'a*(b**(2) + c**(2))', ID="X(39)", classes=["center"])
              X_83 = isogonal_conjugate(model, A, B, C, X_39, ID="X(83)", classes=["selected", "target"])
              return promote_point_to_top(model, X_83)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(83) on the given reference triangle."""
              model = create_model('X(83) = CEVAPOINT OF CENTROID AND SYMMEDIAN POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00083(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00083.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00083.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
