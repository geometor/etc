X(46) = -CEVA CONJUGATE OF X(1)¶

Notes¶

Let Ja’ be the reflection of the A-excenter in BC, and define Jb’, Jc’ cyclically. Let Oa be the circumcenter of AJb’Jc’, and define Ob, Oc cyclically. OaObOc and ABC are perspective at X(46). (Randy Hutson, July 20, 2016)

Let A’ be the inverse-in-Bevan-circle of the A-vertex of the hexyl triangle, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(46). (Randy Hutson, July 20, 2016)

Let JaJbJc be the excentral triangle. Let A″ be the inverse-in-Bevan-circle of A, and define B″, C″ cyclically. The lines JaA″, JbB″, JcC″ concur in X(46). (Randy Hutson, July 20, 2016)

X(46) is the {X(3),X(65)}-harmonic conjugate of X(1).

Construction¶

"""GEOMETOR construction model for X(46) = -CEVA CONJUGATE OF X(1)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              circumcenter_of,
              circumcircle,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              promote_point_to_top,
              spieker_center_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00046(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(46) = -CEVA CONJUGATE OF X(1) on reference triangle ABC."""
              circumcircle(model, A, B, C)
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              central_line(model, X_1, X_3, 1, 3)
              X_10 = spieker_center_of(model, A, B, C, ID="X(10)", classes=["center"])
              X_63 = eval_trilinear_point(model, A, B, C, 'cot(A)', ID="X(63)", classes=["center"])
              central_line(model, X_10, X_63, 10, 63)
              X_34 = eval_trilinear_point(model, A, B, C, '1 - sec(A)', ID="X(34)", classes=["center"])
              X_47 = eval_trilinear_point(model, A, B, C, 'cos(2*A)', ID="X(47)", classes=["center"])
              central_line(model, X_34, X_47, 34, 47)
              X_46 = eval_trilinear_point(model, A, B, C, 'cos(B) + cos(C) - cos(A)', ID="X(46)", classes=["selected", "target"])
              return promote_point_to_top(model, X_46)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(46) on the given reference triangle."""
              model = create_model('X(46) = -CEVA CONJUGATE OF X(1)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00046(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent

              write_center_svg(

                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
