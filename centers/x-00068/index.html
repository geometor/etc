X(68) = PRASOLOV POINT¶

Coordinates¶

Trilinears¶

  • \(\cos A \sec 2A : \cos B \sec 2B : \cos C \sec 2C\)

Barycentrics¶

  • \(\tan 2A : \tan 2B : \tan 2C\)

  • \((b^2 + c^2 - a^2)/(a^4 + b^4 + c^4 - 2a^2b^2 - 2a^2c^2) : :\)

  • Kimberling (6, 9, 13) Search Value: \(1.370063903568\)

Notes¶

Let A’B’C’ be the 2nd Euler triangle. The lines AA’, BB’, CC’ concur in X(68), as proved in V. V. Prasolov, Zadachi po planimetrii, Moscow, 4th edition, 2001.

Coordinates for X(68) can be obtained easily from the Ceva ratios given his Prasolov’s proof of concurrence.

Let Oa be the circle centered at the A-vertex of the orthic triangle and passing through A; define Ob and Oc cyclically. Then X(68) is the radical center of Oa, Ob, Oc. (Randy Hutson, November 2, 2017)

The X(3)-Fuhrmann triangle is inversely similar to ABC, with similitude center X(3), and perspective to ABC at X(68). (Randy Hutson, November 3, 2017)

Construction¶

"""GEOMETOR construction model for X(68) = PRASOLOV POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              nine_point_center_of,
              orthocenter_of,
              promote_point_to_top,
              symmedian_point_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00068(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(68) = PRASOLOV POINT on reference triangle ABC."""
              X_5 = nine_point_center_of(model, A, B, C, ID="X(5)", classes=["center"])
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              central_line(model, X_5, X_6, 5, 6)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_54 = eval_trilinear_point(model, A, B, C, 'sec(B - C)', ID="X(54)", classes=["center"])
              central_line(model, X_2, X_54, 2, 54)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              X_52 = eval_trilinear_point(model, A, B, C, 'cos(2*A)*cos(B - C)', ID="X(52)", classes=["center"])
              central_line(model, X_4, X_52, 4, 52)
              X_24 = eval_trilinear_point(model, A, B, C, 'sec(A)*cos(2*A)', ID="X(24)", classes=["center"])
              X_68 = isogonal_conjugate(model, A, B, C, X_24, ID="X(68)", classes=["selected", "target"])
              return promote_point_to_top(model, X_68)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(68) on the given reference triangle."""
              model = create_model('X(68) = PRASOLOV POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00068(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00068.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00068.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
