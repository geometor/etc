X(38) = CROSSPOINT OF X(1) AND X(75)¶

  • \(\csc A \sin(A + \omega ) : \csc B \sin(B + \omega ) : \csc C \sin(C + \omega )\)

  • \(S_{A} + S_{\omega } : :\)

Barycentrics¶

  • \(a(b^{2} + c^{2}) : :\)

  • \(\sin(A + \omega ) : \sin(B + \omega ) : \sin(C + \omega )\)

  • Kimberling (6, 9, 13) Search Value: \(2.431598760008\)

Notes¶

X(38) is the {X(1),X(63)}-harmonic conjugate of X(31).

Construction¶

"""GEOMETOR construction model for X(38) = CROSSPOINT OF X(1) AND X(75)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00038(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(38) = CROSSPOINT OF X(1) AND X(75) on reference triangle ABC."""
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_21 = eval_trilinear_point(model, A, B, C, '1/(cos(B) + cos(C))', ID="X(21)", classes=["center"])
              central_line(model, X_1, X_21, 1, 21)
              X_38 = eval_trilinear_point(model, A, B, C, 'b**(2) + c**(2)', ID="X(38)", classes=["selected", "target"])
              return promote_point_to_top(model, X_38)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(38) on the given reference triangle."""
              model = create_model('X(38) = CROSSPOINT OF X(1) AND X(75)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00038(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00038.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00038.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
