X(76) = 3rd BROCARD POINT¶

Coordinates¶

Trilinears¶

  • \(1/a^{3} : 1/b^{3} : 1/c^{3}\)

  • \(\csc(A - \omega ) : \csc(B - \omega ) : \csc(C - \omega )\)

Barycentrics¶

  • \(1/a^{2} : 1/b^{2} : 1/c^{2}\)

  • Kimberling (6, 9, 13) Search Value: \(4.759147084540\)

Linear Combinations¶

  • X(76) = 3*X(2) - 2*X(39) = 3*X(2) - P(1) - U(1)

Notes¶

Let A’ be the perspector of the A-McCay circle, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(76). (Randy Hutson, April 9, 2016)

X(76) is the vertex conjugate of the foci of the inellipse that is the barycentric square of the de Longchamps line. The center of the inellipse is X(626) and its Brianchon point (perspector) is X(1502). (Randy Hutson, October 15, 2018)

Let A’B’C’ be the obverse triangle of X(1). Let A″B″C″ be the N-obverse triangle of X(1). Let A* be the barycentric product A’*A″, and define B* and C* cyclically. The lines AA*, BB*, CC* concur in X(76). (Randy Hutson, October 15, 2018)

X(76) is the barycentric multiplier for the Steiner circumellipse. (The barycentric product of X(76) and the circumcircle is the Steiner circumellipse.) (Randy Hutson, August 19, 2019)

For an artistic design generated by X(76), see X(244).

X(76) is the {X(2),X(194)}-harmonic conjugate of X(39).

Construction¶

"""GEOMETOR construction model for X(76) = 3rd BROCARD POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              orthocenter_of,
              promote_point_to_top,
              spieker_center_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00076(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(76) = 3rd BROCARD POINT on reference triangle ABC."""
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_39 = eval_trilinear_point(model, A, B, C, 'a*(b**(2) + c**(2))', ID="X(39)", classes=["center"])
              central_line(model, X_2, X_39, 2, 39)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              X_69 = eval_trilinear_point(model, A, B, C, '(cos(A))/a**(2)', ID="X(69)", classes=["center"])
              central_line(model, X_4, X_69, 4, 69)
              X_10 = spieker_center_of(model, A, B, C, ID="X(10)", classes=["center"])
              X_75 = eval_trilinear_point(model, A, B, C, '1/a**(2)', ID="X(75)", classes=["center"])
              central_line(model, X_10, X_75, 10, 75)
              X_32 = eval_trilinear_point(model, A, B, C, 'a**(3)', ID="X(32)", classes=["center"])
              X_76 = isogonal_conjugate(model, A, B, C, X_32, ID="X(76)", classes=["selected", "target"])
              return promote_point_to_top(model, X_76)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(76) on the given reference triangle."""
              model = create_model('X(76) = 3rd BROCARD POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00076(model, A, B, C)
              return model


          if __name__ == "__main__":
