X(77) = ISOGONAL CONJUGATE OF X(33)¶

In the plane of a triangle ABC, let
Trilinears: \(1/(1 + \sec A) : 1/(1 + \sec B) : 1/(1 + \sec C)\)
Barycentrics: \(a/(1 + \sec A) : b/(1 + \sec B) : c/(1 + \sec C)\)
Search Value (6, 9, 13): \(-4.331307128236\)
▸ Alternate Coordinates4 forms

  • Trilinears: \(\cos A \sec^{2}(A/2) : \cos B \sec^{2}(B/2) : \cos C \sec^{2}(C/2)\)

  • Trilinears: \((b^{2} + c^{2} - a^{2})/(b + c - a) : :\)

  • Trilinears: \(S_{A}(S_{A} - bc) : :\)

  • Barycentrics: \(\cot A (1 - \cos A) : :\)

X(77) lies.

{1, 7}, {2, 189}, {6, 241}, {9, 651}, {29, 34}, {40, 947}, {55, 1037}, {56, 1036}, {57, 81}, {63, 219}, {65, 969}, {69, 73}, {75, 664}, {102, 934}, {283, 603}, {309, 318}, {738, 951}, {988, 1106}, {999, 1057}

Notes¶

  • Ia = line through X(7) parallel to BC, and define Ib and Ic cyclically.

    • Ac = Ia∩AB, and define Ba and Cb cyclically.

    • Ab = Ia∩AC, and define Bc and Ca cyclically.

    • Oa = circumcircle of A, Bc, Cb, and define Ob and Oc cyclically.

Then X(77) = radical center of Oa, Ob, Oc. See also X(77). (Ivan Pavlov, April 1, 2022)
