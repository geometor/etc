X(363) = EQUAL PERIMETERS ISOSCELIZER POINT¶

Coordinates¶

Trilinears¶

  • \(b/(1 + \sin B/2) + c/(1 + \sin C/2) - a/(1 + \sin A/2) : :\)

  • Kimberling (6, 9, 13) Search Value: \(2.584980945018\)

Notes¶

If X = X(363), the isoscelizer triangles of X have equal perimeters.

X(363) is the homothetic center of the excentral triangle and the inner Hutson triangle. A construction of the latter follows. The internal bisector of angle A meets the A-excircle in two points. Let PA be the point closer to line BC and let QA be the other point. Define PB and PC cyclically, and define QB and QC cyclically. Let LA be the line tangent to the A-excircle at PA, and define LB and LC cyclically. Let MA be the line tangent to the A-excircle at QA, and define MB and MC cyclically. The inner Hutson triangle is the triangle A’B’C’ given by A’ = LB∩LC, B’ = LC∩LA, C’ = LA∩LB; the outer Hutson triangle is given by A’’ = MB∩MC, B’’ = MC∩MA, C’ = MA∩MB. (Based on a description of A’B’C’ by Randy Hutson, September 23, 2011)

Peter Moses (November 10, 2011) found trilinears for A’B’C’ and A’’B’’C’’. As these are central triangles, trilinears for A’ and A’’ suffice:

A’ = aUA(a2 + b2 + c2 - 2bc - 2ca - 2ab) + bUB(b + c - a)(c + a - b) + cUC(b + c - a)(a + b - c)

: aUA(a2 + b2 - 3c2 + 2bc + 2ca - 2ab) + UB(c - a)(-a + b + c)(a - b + c) - cUC(-a + b + c)(a + b - c)

: aUA(a2 - 3b2 + c2 + 2bc - 2ca + 2ab) - bUB(-a + b + c)(a - b + c) + UC(b - a)(-a + b + c)(a + b - c)

A’’ = aUA(a2 + b2 + c2 - 2bc - 2ca - 2ab) - bUB(b + c - a)(c + a - b) - cUC(b + c - a)(a + b - c)

: aUA(a2 + b2 - 3c2 + 2bc + 2ca - 2ab) - UB(c - a)(-a + b + c)(a - b + c) + cUC(-a + b + c)(a + b - c)

: aUA(a2 - 3b2 + c2 + 2bc - 2ca + 2ab) + bUB(-a + b + c)(a - b + c) - UC(b - a)(-a + b + c)(a + b - c),

where UA = sqrt[bc/((a - b + c)(a + b - c)] = (1/2)csc(A/2), and UB and UC are defined cyclically.

A’B’C’ is perspective to the following triangles: intouch, hexyl,Yff, and the 1st and 2nd circumperp triangles. A’’B’’C’’ is perspective to these: ABC, intouch, hexyl, Yff, and the 1st and 2nd circumperp triangles. A’B’C’ is homothetic to A’’B’’C’’, which is perspective to the excentral triangle at X(168). (Peter Moses, 11/10/11)

Let UVW and U’V’W’ be the tangential-midarc triangles introduced in the preamble to X(8075). The inner and outer Hutson triangles introduced at X(363) are the excircles-version of UVW and U’V’W’. (Randy Hutson and César Lozada, August 29, 2015)

Incidence¶

X(363) lies and on these lines:

{1, 289}, {40, 164}, {165, 166}

Relations¶

  • X(363) = X(57) of excentral triangle

  • X(363) = homothetic center of ABC and orthic triangle of inner Hutson triangle

Construction¶

"""GEOMETOR construction model for X(363) = EQUAL PERIMETERS ISOSCELIZER POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00363(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(363) = EQUAL PERIMETERS ISOSCELIZER POINT on reference triangle ABC."""
              X_363 = eval_trilinear_point(model, A, B, C, 'b/(1 + sin(B/2)) + c/(1 + sin(C/2)) - a/(1 + sin(A/2))', ID="X(363)", classes=["selected", "target"])
              X_40 = eval_trilinear_point(model, A, B, C, 'cos(B) + cos(C) - cos(A) - 1', ID="X(40)", classes=["center", "incident"])
              X_164 = eval_trilinear_point(model, A, B, C, 'sin(B/2) + sin(C/2) - sin(A/2)', ID="X(164)", classes=["center", "incident"])
              central_line(model, X_40, X_164, 40, 164, incident=True)
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center", "incident"])
              X_289 = eval_trilinear_point(model, A, B, C, '(sin(A/2))/(cos(B/2) + cos(C/2) - cos(A/2))', ID="X(289)", classes=["center", "incident"])
              central_line(model, X_1, X_289, 1, 289, incident=True)
              X_165 = eval_trilinear_point(model, A, B, C, 'tan(B/2) + tan(C/2) - tan(A/2)', ID="X(165)", classes=["center", "incident"])
              X_166 = eval_trilinear_point(model, A, B, C, '(tan(A/2))/(cos(B/2) + cos(C/2) - cos(A/2)) - (tan(B/2))/(cos(C/2) + cos(A/2) - cos(B/2)) - (tan(C/2))/(cos(A/2) + cos(B/2) - cos(C/2))', ID="X(166)", classes=["center", "incident"])
              central_line(model, X_165, X_166, 165, 166, incident=True)
              return promote_point_to_top(model, X_363)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(363) on the given reference triangle."""
              model = create_model('X(363) = EQUAL PERIMETERS ISOSCELIZER POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00363(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00363.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00363.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
