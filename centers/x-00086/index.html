X(86) = CEVAPOINT OF INCENTER AND CENTROID¶

Coordinates¶

Trilinears¶

  • \(bc/(b + c) : ca/(c + a) : ab/(a + b)\)

Barycentrics¶

  • \(1/(b + c) : 1/(c + a) : 1/(a + b)\)

  • Kimberling (6, 9, 13) Search Value: \(2.176292659804\)

Linear Combinations¶

  • X(86) = 2(r2 + 2rR + s2)*X(1) + 3(r2 + s2)*X(2) - 4r2*X(3) (Peter Moses, April 2, 2013)

Notes¶

Let A’B’C’ be the anticomplement of the Feuerbach triangle. Let La be the tangent to the circumcircle at A’, and define Lb and Lc cyclically. Let A″ be the point where La is tangent to the Steiner circumellipse, and define B″ and C″ cyclically. Let A* = BB″∩CC″, and define B* and C* cyclically. The lines AA*, BB*, CC* concur in X(86). (Randy Hutson, December 10, 2016)

Let A1B1C1 be the 1st Conway triangle. Let A’ be the trilinear pole of line B1C1, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(86). (Randy Hutson, December 10, 2016)

Let A5B5C5 be the 5th Conway triangle. Let A’ be the trilinear pole of line B5C5, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(86). (Randy Hutson, December 10, 2016)

Let A3B3C3 and A4B4C4 be Gemini triangles 3 and 4, resp. Let LA be the tangent at A to conic {A,B3,C3,B4,C4}}, and define LB, LC cyclically. Let A’ = LB∩LC, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(86). (Randy Hutson, January 15, 2019)

Let A21B21C21 be Gemini triangle 21. Let A’ be the perspector of conic {A,B,C,B21,C21}}, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(86). (Randy Hutson, January 15, 2019)

"""GEOMETOR construction model for X(86) = CEVAPOINT OF INCENTER AND CENTROID."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcircle,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              gergonne_point_of,
              incircle,
              isogonal_conjugate,
              medial_triangle,
              nine_point_circle,
              promote_point_to_top,
              symmedian_point_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00086(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(86) = CEVAPOINT OF INCENTER AND CENTROID on reference triangle ABC."""
              medial_triangle(model, A, B, C)
              incircle(model, A, B, C)
              circumcircle(model, A, B, C)
              nine_point_circle(model, A, B, C)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              central_line(model, X_2, X_6, 2, 6)
              X_7 = gergonne_point_of(model, A, B, C, ID="X(7)", classes=["center"])
              X_21 = eval_trilinear_point(model, A, B, C, '1/(cos(B) + cos(C))', ID="X(21)", classes=["center"])
              central_line(model, X_7, X_21, 7, 21)
              X_29 = eval_trilinear_point(model, A, B, C, '(sec(A))/(cos(B) + cos(C))', ID="X(29)", classes=["center"])
              X_34 = eval_trilinear_point(model, A, B, C, '1 - sec(A)', ID="X(34)", classes=["center"])
              central_line(model, X_29, X_34, 29, 34)
              X_42 = eval_trilinear_point(model, A, B, C, 'a*(b + c)', ID="X(42)", classes=["center"])
              X_86 = isogonal_conjugate(model, A, B, C, X_42, ID="X(86)", classes=["selected", "target"])
              return promote_point_to_top(model, X_86)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(86) on the given reference triangle."""
              model = create_model('X(86) = CEVAPOINT OF INCENTER AND CENTROID')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00086(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00086.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00086.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
