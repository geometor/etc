X(82) = ISOGONAL CONJUGATE OF X(38)¶

Coordinates¶

Trilinears¶

  • \(1/(b^{2} + c^{2}) : 1/(c^{2} + a^{2}) : 1/(a^{2} + b^{2})\)

  • \(\sin A \csc(A + \omega ) : \sin B \csc(B + \omega ) : \sin C \csc(C + \omega )\)

  • Kimberling (6, 9, 13) Search Value: \(1.057543146404\)

Notes¶

Barycentrics a/(b2 + c2) : b/(c2 + a2) : c/(a2 + b2)

Let A’B’C’ be the circummedial triangle. Let A″ be the trilinear product B’*C’, and define B″, C″ cyclically. A″, B″, C″ are collinear on line X(798)X(812) (the trilinear polar of X(3112)). The lines AA″, BB″, CC″ concur in X(82). (Randy Hutson, October 15, 2018)

Incidence¶

X(82) lies and on these lines:

{1, 560}, {10, 83}, {31, 75}, {37, 251}, {58, 596}, {689, 715}, {759, 827}

Relations¶

  • X(82) = isogonal conjugate of X(38)

  • X(82) = isotomic conjugate of X(1930)

  • X(82) = anticomplement of X(21249)

  • X(82) = cevapoint of X(1) and X(31)

  • X(82) = trilinear pole of line X(661)X(830)

  • X(82) = crossdifference of every pair of points on line X(2084)X(2530)

  • X(82) = perspector of ABC and extraversion triangle of X(82) (which is also the anticevian triangle of X(82))

  • X(82) = crosspoint of X(1) and X(31) wrt the excentral triangle

Construction¶

"""GEOMETOR construction model for X(82) = ISOGONAL CONJUGATE OF X(38)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
              spieker_center_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00082(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(82) = ISOGONAL CONJUGATE OF X(38) on reference triangle ABC."""
              X_31 = eval_trilinear_point(model, A, B, C, 'a**(2)', ID="X(31)", classes=["center"])
              X_75 = eval_trilinear_point(model, A, B, C, '1/a**(2)', ID="X(75)", classes=["center"])
              central_line(model, X_31, X_75, 31, 75)
              X_10 = spieker_center_of(model, A, B, C, ID="X(10)", classes=["center"])
              X_83 = eval_trilinear_point(model, A, B, C, 'b*c/(b**(2) + c**(2))', ID="X(83)", classes=["center"])
              central_line(model, X_10, X_83, 10, 83)
              X_38 = eval_trilinear_point(model, A, B, C, 'b**(2) + c**(2)', ID="X(38)", classes=["center"])
              X_82 = isogonal_conjugate(model, A, B, C, X_38, ID="X(82)", classes=["selected", "target"])
              return promote_point_to_top(model, X_82)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(82) on the given reference triangle."""
              model = create_model('X(82) = ISOGONAL CONJUGATE OF X(38)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00082(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00082.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00082.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
