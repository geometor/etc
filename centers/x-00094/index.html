X(94) = ISOGONAL CONJUGATE OF X(50)¶

Coordinates¶

Trilinears¶

  • \(\csc 3A : \csc 3B : \csc 3C\)

Barycentrics¶

  • \(\sin A \csc 3A : \sin B \csc 3B : \sin C \csc 3C\)

  • \(b^2 c^2 / ((a^2 - b^2 - c^2)^2 - b^2 c^2) : :\)

  • Kimberling (6, 9, 13) Search Value: \(-0.265365586504\)

Notes¶

Let A1B1C1 and A2B2C2 be the 1st and 2nd Ehrmann circumscribing triangles. Let A’ be the trilinear pole of line A1A2, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(94). Let A1’B1’C1’ and A2’B2’C2’ be the 1st and 2nd Ehrmann inscribed triangles. Then X(94) is the radical center of nine-point circles of AA1’A2’, BB1’B2’, CC1’C2’. (Randy Hutson, June 27, 2018)

Let A’B’C’ be the medial or orthic triangle of ABC and A″, B″, C″ the centers of circles {A’, X(3), X(4)}}, {B’, X(3), X(4)}} and {C’, X(3), X(4)}}, respectively. Then A″, B″, C″ are collinear on the trilinear polar of X(94). (César Lozada, March 9, 2021).

Incidence¶

X(94) lies on the Kiepert hyperbola and on these lines:

{2, 300}, {4, 143}, {23, 98}, {49, 93}, {96, 925}, {275, 324}

Construction¶

"""GEOMETOR construction model for X(94) = ISOGONAL CONJUGATE OF X(50)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              nine_point_circle,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00094(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(94) = ISOGONAL CONJUGATE OF X(50) on reference triangle ABC."""
              nine_point_circle(model, A, B, C)
              X_49 = eval_trilinear_point(model, A, B, C, 'cos(3*A)', ID="X(49)", classes=["center"])
              X_93 = eval_trilinear_point(model, A, B, C, 'sec(3*A)', ID="X(93)", classes=["center"])
              central_line(model, X_49, X_93, 49, 93)
              X_23 = eval_trilinear_point(model, A, B, C, 'a*(b**(4) + c**(4) - a**(4) - b**(2)*c**(2))', ID="X(23)", classes=["center"])
              X_98 = eval_trilinear_point(model, A, B, C, 'sec(A + omega )', ID="X(98)", classes=["center"])
              central_line(model, X_23, X_98, 23, 98)
              X_50 = eval_trilinear_point(model, A, B, C, 'sin(3*A)', ID="X(50)", classes=["center"])
              X_94 = isogonal_conjugate(model, A, B, C, X_50, ID="X(94)", classes=["selected", "target"])
              return promote_point_to_top(model, X_94)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(94) on the given reference triangle."""
              model = create_model('X(94) = ISOGONAL CONJUGATE OF X(50)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00094(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00094.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00094.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
