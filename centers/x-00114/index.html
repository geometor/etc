X(114) = KIEPERT ANTIPODE¶

Coordinates¶

  • Kimberling (6, 9, 13) Search Value: \(-1.118944978639\)

Notes¶

Trilinears bc[b sec(B + ω) + c sec(C + ω)] : :

  • Trilinears cos(B - C) cos 2ω - sin ω sin(A + ω) (Peter J. C. Moses, 9/12/03)

  • Barycentrics b sec(B + ω) + c sec(C + ω) : :

  • Barycentrics (b^4 + c^4 - a^2b^2 - a^2c^2)(2a^4 + b^4 + c^4 - a^2b^2 - a^2c^2 - 2b^2c^2) : :

X(114) is the QA-P30 center (Reflection of QA-P2 in QA-P11) of quadrangle ABCX(2) (see http://www.chrisvantienhoven.nl/quadrangle-objects/15-mathematics/quadrangle-objects/artikelen-qa/58-qa-p30.html)

Let A’B’C’ be the orthic triangle. Let La be the Lemoine axis of triangle AB’C’, and define Lb and Lc cyclically. Let A″ = Lb∩Lc, and define B″ and C″ cyclically. Triangle A″B″C″ is inversely similar to ABC, with similicenter X(2). The lines A’A″, B’B″, C’C″ concur in X(114), which is X(3)-of-A″B″C″.

Let OA be the circle centered at the A-vertex of the obverse triangle of X(69) and passing through A; define OB and OC cyclically. X(114) is the radical center of OA, OB, OC. (Randy Hutson, August 30, 2020)

Incidence¶

X(114) lies on the bicevian conic of X(2) and X(99) and on these lines:

{2, 98}, {3, 127}, {4, 99}, {5, 39}, {25, 135}, {52, 211}, {113, 690}, {132, 684}, {136, 427}, {325, 511}, {381, 543}

Construction¶

"""GEOMETOR construction model for X(114) = KIEPERT ANTIPODE."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              complement,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              nine_point_center_of,
              orthocenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00114(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(114) = KIEPERT ANTIPODE on reference triangle ABC."""
              X_98 = eval_trilinear_point(model, A, B, C, 'sec(A + omega )', ID="X(98)", classes=["center"])
              X_114 = complement(model, A, B, C, X_98, ID="X(114)", classes=["selected", "target"])
              X_5 = nine_point_center_of(model, A, B, C, ID="X(5)", classes=["center", "incident"])
              X_39 = eval_trilinear_point(model, A, B, C, 'a*(b**(2) + c**(2))', ID="X(39)", classes=["center", "incident"])
              central_line(model, X_5, X_39, 5, 39, incident=True)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center", "incident"])
              central_line(model, X_2, X_98, 2, 98, incident=True)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center", "incident"])
              X_99 = eval_trilinear_point(model, A, B, C, 'b*c/(b**(2) - c**(2))', ID="X(99)", classes=["center", "incident"])
              central_line(model, X_4, X_99, 4, 99, incident=True)
              return promote_point_to_top(model, X_114)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(114) on the given reference triangle."""
              model = create_model('X(114) = KIEPERT ANTIPODE')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00114(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00114.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00114.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
