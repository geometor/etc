X(47) = -BETH CONJUGATE OF X(34)¶

Coordinates¶

Trilinears¶

  • \(\cos 2A : \cos 2B : \cos 2C = f(a,b,c) : f(b,c,a) : f(c,a,b)\), where, f(a,b,c) = a2(a4 + b4 + c4 - 2a2b2 - 2a2c2)

  • \(a^{2} - 2R^{2} : b^{2} - 2R^{2} : c^{2} - 2R^{2}\)

  • \(\tan A \cot 2A : :\)

  • \(\cos^2 A - \sin^2 A : :\)

  • \(1 - 2 \sin^2 A : :\)

  • \(1 - 2 \cos^2 A : :\)

Barycentrics¶

  • \(a \cos 2A : b \cos 2B : c \cos 2C\)

  • Kimberling (6, 9, 13) Search Value: \(-56.512488734291\)

Linear Combinations¶

  • X(47) = (r2 - R2 + s2)*X(1) - 6rR*X(2) - 4r2*X(3) (Peter Moses, April 2, 2013)

Notes¶

Let A’B’C’ be the Kosnita triangle. Let A″ be the trilinear product B’*C’, and define B″, C″ cyclically. The lines AA″, BB″, CC″ concur in X(47). (Randy Hutson, March 21, 2019)

Let A’B’C’ and A″B″C″ be the Lucas and Lucas(-1) tangents triangles. Let A* be the trilinear product A’*A″, and define B*, C* cyclically. The lines AA*, BB*, CC* concur in X(47). (Randy Hutson, March 21, 2019)

X(47) is the {X(91),X(92)}-harmonic conjugate of X(564).

Construction¶

"""GEOMETOR construction model for X(47) = -BETH CONJUGATE OF X(34)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00047(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(47) = -BETH CONJUGATE OF X(34) on reference triangle ABC."""
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_21 = eval_trilinear_point(model, A, B, C, '1/(cos(B) + cos(C))', ID="X(21)", classes=["center"])
              central_line(model, X_1, X_21, 1, 21)
              X_34 = eval_trilinear_point(model, A, B, C, '1 - sec(A)', ID="X(34)", classes=["center"])
              X_46 = eval_trilinear_point(model, A, B, C, 'cos(B) + cos(C) - cos(A)', ID="X(46)", classes=["center"])
              central_line(model, X_34, X_46, 34, 46)
              X_33 = eval_trilinear_point(model, A, B, C, '1 + sec(A)', ID="X(33)", classes=["center"])
              X_90 = eval_trilinear_point(model, A, B, C, '1/(cos(B) + cos(C) - cos(A))', ID="X(90)", classes=["center"])
              central_line(model, X_33, X_90, 33, 90)
              X_47 = eval_trilinear_point(model, A, B, C, 'cos(2*A)', ID="X(47)", classes=["selected", "target"])
              return promote_point_to_top(model, X_47)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(47) on the given reference triangle."""
              model = create_model('X(47) = -BETH CONJUGATE OF X(34)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00047(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00047.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00047.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
