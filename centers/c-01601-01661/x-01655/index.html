X1655¶

2nd HATZIPOLAKIS PARALLELIAN POINT

Continuing from the description of X1654, let h(B,A) be the distance from the point BA to the line CA, and define five other distances cyclically. If P = X1655, then

Constructed Elements

  • Derived Triangle: Anticomplementary Triangle △KaKbKc — vertices Ka, Kb, Kc (Formed by lines through A, B, C parallel to opposite sides)

  • Central Lines: {2, 274}

  • Related Centers: X2 (CENTROID), X274 (ISOGONAL CONJUGATE OF X213)

Trilinears: \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where \(f(a,b,c) = bc[-1/a^{2} + 1/b^{2} + 1/c^{2} + 1/(bc) + 1/(ca) + 1/(ab)]\)
Barycentrics: \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where \(g(a,b,c) = -1/a^{2} + 1/b^{2} + 1/c^{2} + 1/(bc) + 1/(ca) + 1/(ab)\)
