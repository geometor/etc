X1652¶

4th EVANS PERSPECTOR

X1652 = X554-aleph conjugate of X1652

Constructed Elements

  • Central Lines: {2, 7}, {1, 15}

  • Related Centers: X2 (CENTROID), X7 (GERGONNE POINT), X1 (INCENTER), X15 (1st ISODYNAMIC POINT)

Trilinears: \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where \(f(A,B,C) = \sqrt{3/4} - \sin(A + \pi /3) + \sin(B + \pi /3) + \sin(C + \pi /3)\)
