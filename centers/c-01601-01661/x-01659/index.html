X1659¶

YIU-PAASCHE POINT

X1659 = X482-cross conjugate of X7

Constructed Elements

  • Central Lines: {1, 4}, {2, 176}

  • Related Centers: X482 (2nd EPPSTEIN POINT), X7 (GERGONNE POINT), X1 (INCENTER), X4 (ORTHOCENTER), X2 (CENTROID), X176 (EQUAL DETOUR POINT)

Trilinears: \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where \(f(A,B,C) = 1/(1 + \sin A + \cos A)\)
Barycentrics: \(\sin A + \cos B + \cos C : :\)
Search Value (6, 9, 13): \(1.303745560539\)
▸ Incident Central Lines6 lines

{1, 4}, {2, 176}, {57, 482}, {75, 491}, {92, 1585}, {553, 1373}

▸ Functional Relations3 relations

  • X1659 = isogonal conjugate of X2066

  • X1659 = X482-cross conjugate of X7

  • X1659 = crosssum of X48 and X605

Notes¶

For a discussion of this point, see Paul Yiu, Introduction to the Geometry of the Triangle, 2002, Article 3.5.4 Exercise 4d.

(The preceding Exercise 4c presents the Paasche point, X1123,) (Contributed by Darij Grinberg, 8/24/03)

See Francisco Javier García Capitán, Hyacinthos #21541, 2/14/2013.
