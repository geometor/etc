X3514¶

INVERSE-IN-CIRCUMCIRCLE OF X3513

X3514 = circumcircle-inverse of X3513

Constructed Elements

  • Central Lines: {3513, 3660}

  • Related Centers: X3513 (1st DILATION CENTER), X3660 (MIDPOINT OF {X3513, X3514})

Trilinears: \((a - b + c)(a + b - c) - 4r(r^{2} + 4rR)^{1/2} : :\) (Peter Moses, 7/24/08)
Tripolars: \(1/r_{a} : :\), where \(r_{a}\), \(r_{b}\), \(r_{c}\) are the exradii
Search Value (6, 9, 13): \(-1.246261237787\)
▸ Alternate Coordinates2 forms

  • Tripolars: \(b + c - a : :\)

  • X3514 = circumcircle-inverse of X3513

Notes¶
