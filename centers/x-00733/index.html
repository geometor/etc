X(733) = EVEN (- 2, 2) CIRCUMCIRCLE POINT¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = 1/[a-3(b2 + c2) - a1(b-2 + c -2)]

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = af(a,b,c)

  • Kimberling (6, 9, 13) Search Value: \(-0.104982804195\)

Incidence¶

X(733) lies on the circumcircle and on these lines:

{2, 689}, {32, 827}, {39, 83}, {100, 893}, {101, 904}, {110, 251}, {755, 882}

  • X(733) = isotomic conjugate of X(35540)

  • X(733) = orthoptic-circle-of-Steiner-inellipse-inverse of X(35971)

  • X(733) = trilinear pole of line X(6)X(688)

  • X(733) = Ψ(X(6), X(688))

          from __future__ import annotations

          import sympy.geometry as spg

          def construct_x_00733(

              X_83 = eval_trilinear_point(model, A, B, C, 'b*c/(b**(2) + c**(2))', ID="X(83)", classes=["center", "incident"])

              X_110 = eval_trilinear_point(model, A, B, C, 'csc(B - C)', ID="X(110)", classes=["center", "incident"])

          def build_model(
