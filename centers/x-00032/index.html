Notes¶

The 5th Brocard triangle is here introduced as the vertex triangle of the circumcevian triangles of the 1st and 2nd Brocard points. (Randy Hutson, December 26, 2015)

The 5th Brocard triangle is homothetic to ABC at X(32), homothetic to the medial triangle at X(3096), homothetic to the anticomplementary triangle at X(2896), perspective to the 1st Brocard triangle at X(2896), and perspective to the 3rd Brocard triangle at X(32).(Randy Hutson, December 26, 2015)

Let A’B’C’ be the 1st Brocard triangle. Let A″, B″, C″ be inverse-in-circumcircle of A’, B’ and C’ resp. AA″, BB″, CC″ concur in X(32). (Randy Hutson, July 20, 2016)

Let A’B’C’ be the 1st Brocard triangle. Let A″ be the cevapoint, wrt A’B’C’, of B and C, and define B″, C″ cyclically. A’A″, B’B″, C’C″ concur in X(32). (Randy Hutson, July 20, 2016)

X(32) is the Brianchon point (perspector) of the inellipse that is the barycentric square of the Lemoine axis. The center of this inellipse is X(8265). (Randy Hutson, October 15, 2018)

X(32) is the {X(3),X(6)}-harmonic conjugate of X(39).

Construction¶

"""GEOMETOR construction model for X(32) = 3rd POWER POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcenter_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
              symmedian_point_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00032(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(32) = 3rd POWER POINT on reference triangle ABC."""
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              central_line(model, X_3, X_6, 3, 6)
              X_31 = eval_trilinear_point(model, A, B, C, 'a**(2)', ID="X(31)", classes=["center"])
              X_41 = eval_trilinear_point(model, A, B, C, 'a**(2)*(b + c - a)', ID="X(41)", classes=["center"])
              central_line(model, X_31, X_41, 31, 41)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_83 = eval_trilinear_point(model, A, B, C, 'b*c/(b**(2) + c**(2))', ID="X(83)", classes=["center"])
              central_line(model, X_2, X_83, 2, 83)
              X_32 = eval_trilinear_point(model, A, B, C, 'a**(3)', ID="X(32)", classes=["selected", "target"])
              return promote_point_to_top(model, X_32)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(32) on the given reference triangle."""
              model = create_model('X(32) = 3rd POWER POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00032(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00032.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00032.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
