X(72) = ISOGONAL CONJUGATE OF X(28)¶

Coordinates¶

Trilinears¶

  • \((b + c) \cot A : (c + a) \cot B : (a + b) \cot C\)

  • \((b + c)(b^{2} + c^{2} - a^{2}) : (c + a)(c^{2} + a^{2} - b^{2}) : (a + b)(a^{2} + b^{2} - c^{2})\)

Barycentrics¶

  • \((b + c) \cos A : (c + a) \cos B : (a + b) \cos C\)

  • Kimberling (6, 9, 13) Search Value: \(5.668071554504\)

Linear Combinations¶

  • X(72) = (r + 2R)*X(1) - 3R*X(2) - r*X(3) (Peter Moses, April 2, 2013)

Notes¶

Let Ia be the reflection of X(1) in the perpendicular bisector of BC, and define Ib and Ic cyclically. X(72) = X(11) of IaIbIc. (Randy Hutson, September 14, 2016)

X(72) is the {X(1),X(9)}-harmonic conjugate of X(405).

X(72) is the perspector of the 1st and 2nd extouch triangles. X(72) is also the orthocenter of the 2nd extouch triangle. (Randy Hutson, August 23, 2011)

Construction¶

"""GEOMETOR construction model for X(72) = ISOGONAL CONJUGATE OF X(28)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              isogonal_conjugate,
              nagel_point_of,
              orthocenter_of,
              promote_point_to_top,
              spieker_center_of,
              symmedian_point_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00072(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(72) = ISOGONAL CONJUGATE OF X(28) on reference triangle ABC."""
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              central_line(model, X_1, X_6, 1, 6)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              X_8 = nagel_point_of(model, A, B, C, ID="X(8)", classes=["center"])
              central_line(model, X_4, X_8, 4, 8)
              X_10 = spieker_center_of(model, A, B, C, ID="X(10)", classes=["center"])
              X_12 = eval_trilinear_point(model, A, B, C, '1 + cos(B - C)', ID="X(12)", classes=["center"])
              central_line(model, X_10, X_12, 10, 12)
              X_28 = eval_trilinear_point(model, A, B, C, '(tan(A))/(b + c)', ID="X(28)", classes=["center"])
              X_72 = isogonal_conjugate(model, A, B, C, X_28, ID="X(72)", classes=["selected", "target"])
              return promote_point_to_top(model, X_72)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(72) on the given reference triangle."""
              model = create_model('X(72) = ISOGONAL CONJUGATE OF X(28)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00072(model, A, B, C)
              return model


          if __name__ == "__main__":

                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
