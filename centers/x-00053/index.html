X(53) = SYMMEDIAN POINT OF ORTHIC TRIANGLE¶

Coordinates¶

Trilinears¶

  • \(\tan A \cos(B - C) : \tan B \cos(C - A) : \tan C \cos(A - B)\)

Barycentrics¶

  • \(a \tan A \cos(B - C) : b \tan B \cos(C - A) : c \tan C \cos(A - B)\)

  • \((a^2 (b^2 + c^2) - (b^2 - c^2)^2)/(a^2 - b^2 - c^2) : :\)

  • Kimberling (6, 9, 13) Search Value: \(-0.134512425200\)

Notes¶

Let A’B’C’ be the Euler triangle. Let LA be the trilinear polar of A’, and define LB and LC cyclically. Let A″ = LB∩LC, and define B″ and C″ cyclically. The lines AA″, BB″, CC″ concur in X(53). (Randy Hutson, June 7, 2019)

X(53) is the {X(4),X(393)}-harmonic conjugate of X(6).

Incidence¶

X(53) lies and on these lines:

{4, 6}, {5, 216}, {25, 157}, {30, 577}, {45, 281}, {115, 133}, {128, 139}, {137, 138}, {141, 264}, {232, 427}, {273, 1086}, {275, 288}, {311, 324}, {317, 524}, {318, 594}, {395, 472}, {396, 473}

Construction¶

"""GEOMETOR construction model for X(53) = SYMMEDIAN POINT OF ORTHIC TRIANGLE."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              orthic_triangle,
              orthocenter_of,
              promote_point_to_top,
              symmedian_point_of,
              tangential_triangle,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00053(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(53) = SYMMEDIAN POINT OF ORTHIC TRIANGLE on reference triangle ABC."""
              orthic_triangle(model, A, B, C)
              tangential_triangle(model, A, B, C)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              central_line(model, X_4, X_6, 4, 6)
              X_53 = eval_trilinear_point(model, A, B, C, 'tan(A)*cos(B - C)', ID="X(53)", classes=["selected", "target"])
              return promote_point_to_top(model, X_53)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(53) on the given reference triangle."""
              model = create_model('X(53) = SYMMEDIAN POINT OF ORTHIC TRIANGLE')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00053(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00053.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00053.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
