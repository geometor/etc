X(453) = POINT ALSHAIN¶

As a point on the Euler line, X(453) has Shinagawa coefficients (2$aSBSC$+$aSA$(E+2F)-2$a$S\ :sup:`2`-2abcF, -$aSA$E+2$a$S2+abcE).
Trilinears: \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where f(A,B,C)=(cos B + cos C - cos A)2/(cos B + cos C)
Barycentrics: \((\sin A)f(A,B,C) : (\sin B)f(B,C,A) : (\sin C)f(C,A,B)\)
Search Value (6, 9, 13): \(1.182719776028\)

X(453) lies.
