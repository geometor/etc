X(484) = 1st EVANS PERSPECTOR¶

Coordinates¶

Trilinears¶

  • \(1 + 2(\cos A - \cos B - \cos C) : 1 + 2(\cos B - \cos C - \cos A) : 1 + 2(\cos C - \cos A - \cos B)\)

  • \(a^3 + a^2 (b + c) - a (b^2 + b c + c^2) - (b - c)^2 (b + c) : :\)

Barycentrics¶

  • \(a[1 + 2(\cos A - \cos B - \cos C)] : b[1 + 2(\cos B - \cos C - \cos A)] : c[1 + 2(\cos C - \cos A - \cos B)]\)

  • Kimberling (6, 9, 13) Search Value: \(-6.840882082776\)

Notes¶

X(484) is the perspector of the excentral triangle and the triangle A’B’C’, where A’ is the reflection of vertex A in sideline BC and B’, C’ are determined cyclically. (Lawrence Evans, 10/22/98)

Incidence¶

X(484) lies on the Neuberg cubic and on these lines:

{1, 3}, {4, 3483}, {10, 191}, {12, 79}, {13, 1277}, {14, 1276}, {30, 80}, {63, 535}, {74, 3465}, {100, 758}, {499, 962}, {759, 901}, {1046, 1048}, {1138, 3464}, {3466, 3484}

Construction¶

"""GEOMETOR construction model for X(484) = 1st EVANS PERSPECTOR."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              ceva_conjugate,
              circumcenter_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00484(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(484) = 1st EVANS PERSPECTOR on reference triangle ABC."""
              X_80 = eval_trilinear_point(model, A, B, C, '1/(1 - 2*cos(A))', ID="X(80)", classes=["center"])
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_484 = ceva_conjugate(model, A, B, C, X_80, X_1, ID="X(484)", classes=["selected", "target"])
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center", "incident"])
              central_line(model, X_1, X_3, 1, 3, incident=True)
              X_12 = eval_trilinear_point(model, A, B, C, '1 + cos(B - C)', ID="X(12)", classes=["center", "incident"])
              X_79 = eval_trilinear_point(model, A, B, C, '1/(1 + 2*cos(A))', ID="X(79)", classes=["center", "incident"])
              central_line(model, X_12, X_79, 12, 79, incident=True)
              X_30 = eval_trilinear_point(model, A, B, C, 'cos(A) - 2*cos(B)*cos(C)', ID="X(30)", classes=["center", "incident"])
              central_line(model, X_30, X_80, 30, 80, incident=True)
              return promote_point_to_top(model, X_484)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(484) on the given reference triangle."""
              model = create_model('X(484) = 1st EVANS PERSPECTOR')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00484(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00484.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00484.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
