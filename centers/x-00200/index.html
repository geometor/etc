X(200) = X(8)-CEVA CONJUGATE OF X(9)¶

Coordinates¶

Trilinears¶

  • \(\cot^{2}(A/2) : :\)

  • \((b + c - a)^{2} : :\)

  • (1 + cos A)/(1 - cos A) : : (Randy Hutson, 9/23/2011)

  • \(1 - \csc^2(A/2) : :\)

  • squared distance of A to Gergonne line : :

Barycentrics¶

  • \(a(b + c - a)^{2} : :\)

  • Kimberling (6, 9, 13) Search Value: \(4.869827731426\)

Notes¶

Let A’B’C’ be the extouch triangle. Let A″ be the trilinear product of the circumcircle intercepts of line B’C’, and define B″ and C″ cyclically. The lines A’A″, B’B″, C’C″ concur in X(200). (Randy Hutson, July 31 2018)

Let A’ be the trilinear product of the circumcircle intercepts of the A-excircle. Define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(200). (Randy Hutson, July 31 2018)

X(200) is the {X(8),X(78)}-harmonic conjugate of X(1). For a list of harmonic conjugates of X(200), click Tables at the top of this page.

Construction¶

"""GEOMETOR construction model for X(200) = X(8)-CEVA CONJUGATE OF X(9)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              mittenpunkt_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00200(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(200) = X(8)-CEVA CONJUGATE OF X(9) on reference triangle ABC."""
              X_200 = eval_trilinear_point(model, A, B, C, '(cot(A/2))**(2)', ID="X(200)", classes=["selected", "target"])
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center", "incident"])
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center", "incident"])
              central_line(model, X_1, X_2, 1, 2, incident=True)
              X_9 = mittenpunkt_of(model, A, B, C, ID="X(9)", classes=["center", "incident"])
              X_55 = eval_trilinear_point(model, A, B, C, 'a*(b + c - a)', ID="X(55)", classes=["center", "incident"])
              central_line(model, X_9, X_55, 9, 55, incident=True)
              X_40 = eval_trilinear_point(model, A, B, C, 'cos(B) + cos(C) - cos(A) - 1', ID="X(40)", classes=["center", "incident"])
              X_64 = eval_trilinear_point(model, A, B, C, '1/(cos(A) - cos(B)*cos(C))', ID="X(64)", classes=["center", "incident"])
              central_line(model, X_40, X_64, 40, 64, incident=True)
              return promote_point_to_top(model, X_200)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(200) on the given reference triangle."""
              model = create_model('X(200) = X(8)-CEVA CONJUGATE OF X(9)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00200(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00200.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00200.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
