X(805) = o-(- 2, 2) CIRCUMCIRCLE POINT¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = 1/[a -3(b2 - c2) + a1(b -2 - c -2)]

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = af(a,b,c)

  • Kimberling (6, 9, 13) Search Value: \(0.223824932622\)

Notes¶

Let A’B’C’ be the vertex-triangle of the 2nd and 3rd Brocard triangles. The lines AA’, BB’, CC’ concur in X(805). (Randy Hutson, March 25, 2016)

Let La, Lb, Lc be the lines through A, B, C, resp. parallel to the Brocard axis. Let Ma, Mb, Mc be the reflections of BC, CA, AB in La, Lb, Lc, resp. Let A’ = Mb∩Mc, and define B’ and C’ cyclically. Triangle A’B’C’ is inversely similar to, and 3 times the size of, ABC. The centroid of A’B’C’ is X(805); see Hyacinthos #16741/16782, Sep 2008. (Randy Hutson, March 25, 2016)

Let La, Lb, Lc be the lines through A, B, C, resp. parallel to the Lemoine axis. Let Ma, Mb, Mc be the reflections of BC, CA, AB in La, Lb, Lc, resp. Let A’ = Mb∩Mc, and define B’ and C’ cyclically. Triangle A’B’C’ is inversely similar to, and 3 times the size of, ABC. The centroid of A’B’C’ is X(805); see Hyacinthos #16741/16782, Sep 2008. (Randy Hutson, March 25, 2016)

Incidence¶

X(805) lies on the circumcircle and on these lines:

{98, 385}, {99, 512}, {110, 669}, {111, 694}, {187, 729}, {249, 827}, {574, 843}, {691, 882}, {888, 892}

  • X(805) = isogonal conjugate of X(804)

  • X(805) = isotomic conjugate of X(14295)

  • X(805) = trilinear pole of line X(6)X(694)

  • X(805) = Ψ(X(6), X(694))

  • X(805) = cevapoint of X(511) and X(512)

  • X(805) = reflection of X(99) in the Brocard axis

  • X(805) = Brocard-circle-inverse of X(32531)

  • X(805) = X(9831)-of-circumsymmedial-triangle

  • X(805) = intersection of antipedal lines of X(98) and X(99)

  • X(805) = perspector of ABC and the triangle formed by reflecting line X(5)X(39) in the sides of ABC

"""GEOMETOR construction model for X(805) = o-(- 2, 2) CIRCUMCIRCLE POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00805(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(805) = o-(- 2, 2) CIRCUMCIRCLE POINT on reference triangle ABC."""
              X_804 = eval_trilinear_point(model, A, B, C, 'a **(-3)*(b**(2) - c**(2)) + a**(1)*(b **(-2) - c **(-2))', ID="X(804)", classes=["center"])
              X_805 = isogonal_conjugate(model, A, B, C, X_804, ID="X(805)", classes=["selected", "target"])
              X_98 = eval_trilinear_point(model, A, B, C, 'sec(A + omega )', ID="X(98)", classes=["center", "incident"])
              X_385 = eval_trilinear_point(model, A, B, C, 'b*c*(a**(4) - b**(2)*c**(2))', ID="X(385)", classes=["center", "incident"])
              central_line(model, X_98, X_385, 98, 385, incident=True)
              X_99 = eval_trilinear_point(model, A, B, C, 'b*c/(b**(2) - c**(2))', ID="X(99)", classes=["center", "incident"])
              X_512 = eval_trilinear_point(model, A, B, C, 'a*(b**(2) - c**(2))', ID="X(512)", classes=["center", "incident"])
              central_line(model, X_99, X_512, 99, 512, incident=True)
              X_110 = eval_trilinear_point(model, A, B, C, 'csc(B - C)', ID="X(110)", classes=["center", "incident"])
              X_669 = eval_trilinear_point(model, A, B, C, 'a**(3)*(b**(2) - c**(2))', ID="X(669)", classes=["center", "incident"])
              central_line(model, X_110, X_669, 110, 669, incident=True)
              return promote_point_to_top(model, X_805)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(805) on the given reference triangle."""
              model = create_model('X(805) = o-(- 2, 2) CIRCUMCIRCLE POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00805(model, A, B, C)
              return model
