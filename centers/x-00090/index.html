X(90) = -CROSS CONJUGATE OF X(1)¶

Coordinates¶

Trilinears¶

  • \(1/(\cos B + \cos C - \cos A) : 1/(\cos C + \cos A - \cos B) : 1/(\cos A + \cos B - \cos C)\)

  • \(1/(a^3 + a^2 (b + c) - a (b^2 + c^2) - (b - c)^2 (b + c)) : :\)

Barycentrics¶

  • \(a/(\cos B + \cos C - \cos A) : b/(\cos C + \cos A - \cos B) : c/(\cos A + \cos B - \cos C)\)

  • Kimberling (6, 9, 13) Search Value: \(2.722260516138\)

Linear Combinations¶

  • X(90) = (r + R)2*X(1) - 6rR*X(2) - 2r(r - R)*X(3) (Peter Moses, April 2, 2013)

Incidence¶

X(90) lies and on these lines:

{1, 155}, {4, 46}, {9, 35}, {21, 224}, {33, 47}, {36, 84}, {40, 80}, {57, 79}

Relations¶

  • X(90) = isogonal conjugate of X(46)

  • X(90) = isotomic conjugate of X(20930)

  • X(90) = X(3)-cross conjugate of X(1)

  • X(90) = perspector of ABC and extraversion triangle of X(46)

  • X(90) = trilinear product of the extraversions of X(46), which is also the cross-triangle of the orthic and excentral triangles

  • X(90) = trilinear product of PU(125)

  • X(90) = Cundy-Parry Phi transform of X(90)

  • X(90) = Cundy-Parry Psi transform of X(46)

Construction¶

"""GEOMETOR construction model for X(90) = -CROSS CONJUGATE OF X(1)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              mittenpunkt_of,
              orthocenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00090(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(90) = -CROSS CONJUGATE OF X(1) on reference triangle ABC."""
              X_9 = mittenpunkt_of(model, A, B, C, ID="X(9)", classes=["center"])
              X_35 = eval_trilinear_point(model, A, B, C, '1 + 2*cos(A)', ID="X(35)", classes=["center"])
              central_line(model, X_9, X_35, 9, 35)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              X_46 = eval_trilinear_point(model, A, B, C, 'cos(B) + cos(C) - cos(A)', ID="X(46)", classes=["center"])
              central_line(model, X_4, X_46, 4, 46)
              X_33 = eval_trilinear_point(model, A, B, C, '1 + sec(A)', ID="X(33)", classes=["center"])
              X_47 = eval_trilinear_point(model, A, B, C, 'cos(2*A)', ID="X(47)", classes=["center"])
              central_line(model, X_33, X_47, 33, 47)
              X_90 = isogonal_conjugate(model, A, B, C, X_46, ID="X(90)", classes=["selected", "target"])
              return promote_point_to_top(model, X_90)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(90) on the given reference triangle."""
              model = create_model('X(90) = -CROSS CONJUGATE OF X(1)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00090(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00090.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00090.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
