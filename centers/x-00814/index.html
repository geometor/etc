X(814) = ODD (- 1, 2) INFINITY POINT¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = a -2(b2 - c2) + a1(b -1 - c -1)

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = af(a,b,c)

Notes¶

As the isogonal conjugate of a point on the circumcircle, X(814) lies on the line at infinity.

Incidence¶

X(814) lies and on these lines:

{30, 511}

Relations¶

  • X(814) = isogonal conjugate of X(815)

Construction¶

"""GEOMETOR construction model for X(814) = ODD (- 1, 2) INFINITY POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00814(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(814) = ODD (- 1, 2) INFINITY POINT on reference triangle ABC."""
              X_814 = eval_trilinear_point(model, A, B, C, 'a**(-2)*(b**(2)- c**(2)) + a**(1)*(b**(-1)- c**(-1))', ID="X(814)", classes=["selected", "target"])
              X_30 = eval_trilinear_point(model, A, B, C, 'cos(A) - 2*cos(B)*cos(C)', ID="X(30)", classes=["center", "incident"])
              X_511 = eval_trilinear_point(model, A, B, C, 'cos(A + omega )', ID="X(511)", classes=["center", "incident"])
              central_line(model, X_30, X_511, 30, 511, incident=True)
              return promote_point_to_top(model, X_814)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(814) on the given reference triangle."""
              model = create_model('X(814) = ODD (- 1, 2) INFINITY POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00814(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00814.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00814.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
