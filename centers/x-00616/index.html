X616¶

ANTICOMPLEMENT OF X13

The midpoint of X616 and X617 is the Steiner point, X99.

Group Preamble — Centers X616-X642

Centers X616-X642 were contributed by Bernard Gibert, March 2, 2001. Notation:

\(S_{A}\) = (\(b^{2}\) + \(c^{2}\) - \(a^{2})\)/2 \(S_{B}\) = (\(c^{2}\) + \(a^{2}\) - \(b^{2})\)/2 \(S_{C}\) = (\(a^{2}\) + \(b^{2}\) - \(c^{2})\)/2

Joe Goggins (Oct. 19, 2005) found trilinears for points in this section, using the following notation. Let

\(F(13) = a \csc(A + \pi /3) + b \csc(B + \pi /3) + c \csc(C + \pi /3)\)
\(F(14) = a \csc(A - \pi /3) + b \csc(B - \pi /3) + c \csc(C - \pi /3)\)
These are based on trilinears for the isogonic centers, X13 and X14. In like manner, F(i) is defined for i = 15, 16, 17, 18, 61, 62.
Using this notation, we have, for example,
X616 = F(13)/a - 2 csc(A + π/3) : F(13)/b - 2 csc(B + π/3) : F(13)/c - 2 csc(C + π/3)
X617 = F(14)/a - 2 csc(A - π/3) : F(14)/b - 2 csc(B - π/3) : F(14)/c - 2 csc(C - π/3)

Trilinears of this sort are given below at Xi for these i: 616-619, 621-624, 627-630, and 633-636.

Constructed Elements

  • Central Lines: {2, 13}, {69, 74}

  • Related Centers: X2 (CENTROID), X13 (1st ISOGONIC CENTER), X69 (SYMMEDIAN POINT OF THE ANTICOMPLEMENTARY TRIANGLE), X74 (ISOGONAL CONJUGATE OF EULER INFINITY POINT)

Trilinears: \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where \(f(a,b,c) = [S_{B}S_{C} - 2S_{A}(a^{2} + \sqrt{3} \operatorname{area})]/a\)
Search Value (6, 9, 13): \(7.736216073857\)

X616 lies on the Neuberg cubic.

Notes¶

Let OA be the circle centered at the A-vertex of the outer Napoleon triangle and passing through A; define OB and OC cyclically. X616 is the radical center of OA, OB, OC. (Randy Hutson, August 30, 2020)
