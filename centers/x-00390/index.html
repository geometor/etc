X(390) = REFLECTION OF GERGONNE POINT IN INCENTER¶

Coordinates¶

Trilinears¶

  • \(bc(b + c - a)[3a^{2} + (b - c)^{2}]\)

Barycentrics¶

  • \((b + c - a)[3a^{2} + (b - c)^{2}]\)

  • Kimberling (6, 9, 13) Search Value: \(2.636456039908\)

Linear Combinations¶

  • X(390) = 4(R/r)*X(1) - 3X(2) + 4X(3)

Notes¶

X(390) is the point in whIch the extended legs X(1)X(7) and X(8)X(9) of the trapezoid X(1)X(7)X(8)X(9) meet. (Randy Hutson, February 10, 2016)

Let A’B’C’ be the extangents-to-intangents similarity image of ABC. A’B’C’ is homothetic to ABC at X(55) and to the anticomplementary triangle at X(390). (Randy Hutson, June 7, 2019)

Incidence¶

X(390) lies and on these lines:

{1, 7}, {2, 11}, {3, 1058}, {4, 495}, {8, 9}, {30, 1056}, {40, 938}, {144, 145}, {376, 999}, {387, 595}, {496, 631}, {944, 971}, {952, 1000}

Relations¶

  • X(390) = midpoint of X(144) and X(145)

  • X(390) = reflection of X(i) in X(j) for these (i,j): (7, 1), (8, 9)

  • X(390) = anticomplement of X(2550)

  • X(390) = crossdifference of every pair of points on line X(657)X(665)

  • X(390) = inverse-in-Feuerbach-hyperbola of X(2)

  • X(390) = {X(1),X(20)}-harmonic conjugate of X(3600)

  • X(390) = {X(175),X(176)}-harmonic conjugate of X(279)

  • X(390) = bicentric sum of PU(122)

Construction¶

"""GEOMETOR construction model for X(390) = REFLECTION OF GERGONNE POINT IN INCENTER."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              feuerbach_point_of,
              gergonne_point_of,
              incenter_of,
              midpoint,
              mittenpunkt_of,
              nagel_point_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00390(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(390) = REFLECTION OF GERGONNE POINT IN INCENTER on reference triangle ABC."""
              X_144 = eval_trilinear_point(model, A, B, C, '(csc(A))*(tan(B/2) + tan(C/2) - tan(A/2))', ID="X(144)", classes=["center"])
              X_145 = eval_trilinear_point(model, A, B, C, 'b*c*(3*a - b - c)', ID="X(145)", classes=["center"])
              X_390 = midpoint(model, X_144, X_145, ID="X(390)", classes=["selected", "target"], guide=False)
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center", "incident"])
              X_7 = gergonne_point_of(model, A, B, C, ID="X(7)", classes=["center", "incident"])
              central_line(model, X_1, X_7, 1, 7, incident=True)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center", "incident"])
              X_11 = feuerbach_point_of(model, A, B, C, ID="X(11)", classes=["center", "incident"])
              central_line(model, X_2, X_11, 2, 11, incident=True)
              X_8 = nagel_point_of(model, A, B, C, ID="X(8)", classes=["center", "incident"])
              X_9 = mittenpunkt_of(model, A, B, C, ID="X(9)", classes=["center", "incident"])
              central_line(model, X_8, X_9, 8, 9, incident=True)
              return promote_point_to_top(model, X_390)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(390) on the given reference triangle."""
              model = create_model('X(390) = REFLECTION OF GERGONNE POINT IN INCENTER')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00390(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00390.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00390.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
