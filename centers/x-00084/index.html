X(84) = ISOGONAL CONJUGATE OF X(40)¶

Coordinates¶

Trilinears¶

  • \(1/(\cos B + \cos C - \cos A - 1) : :\)

  • \(a^2[a^2 - (b - c)^2]^2 - (b - c)^2[a^2 - (b + c)^2]^2 : :\)

  • Kimberling (6, 9, 13) Search Value: \(-52.770375222430\)

Linear Combinations¶

  • X(84) = (r + 2R)*X(1) - 6R*X(2) + (4R - 2r)*X(3) (Peter Moses, April 2, 2013)

Notes¶

Let A’,B’,C’ be the excenters. The perpendiculars from B’ to AB and from C’ to AC meet in a point A″. Points B″ and C″ are determined cyclically. The hexyl triangle, A″B″C″, is perspective to ABC, and X(84) is the perspector.

Let A’B’C’ be the extouch triangle. Let A″ be the orthocenter of AB’C’, and define B″ and C″ cyclically. The lines AA″, BB″, CC″ concur in X(84). (Randy Hutson, September 14, 2016)

Let A1B1C1 be the 1st Conway triangle. Let A’ be the crosspoint of B1 and C1, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(84). (Randy Hutson, December 2, 2017)

See Dasari Naga Vijay Krishna, On a Conic Through Twelve Notable Points, Int. J. Adv. Math. and Mech. 7(2) (2019) 1-15.

Incidence¶

X(84) lies on the Darboux cubic, the circumellipse with center X(9) and on these lines:

Construction¶

"""GEOMETOR construction model for X(84) = ISOGONAL CONJUGATE OF X(40)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              circumcenter_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              mittenpunkt_of,
              nagel_point_of,
              orthocenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00084(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(84) = ISOGONAL CONJUGATE OF X(40) on reference triangle ABC."""
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              X_9 = mittenpunkt_of(model, A, B, C, ID="X(9)", classes=["center"])
              central_line(model, X_3, X_9, 3, 9)
              X_8 = nagel_point_of(model, A, B, C, ID="X(8)", classes=["center"])
              X_20 = eval_trilinear_point(model, A, B, C, 'cos(A) - cos(B)*cos(C)', ID="X(20)", classes=["center"])
              central_line(model, X_8, X_20, 8, 20)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              X_57 = eval_trilinear_point(model, A, B, C, '1/(b + c - a)', ID="X(57)", classes=["center"])
              central_line(model, X_4, X_57, 4, 57)
              X_40 = eval_trilinear_point(model, A, B, C, 'cos(B) + cos(C) - cos(A) - 1', ID="X(40)", classes=["center"])
              X_84 = isogonal_conjugate(model, A, B, C, X_40, ID="X(84)", classes=["selected", "target"])
              return promote_point_to_top(model, X_84)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(84) on the given reference triangle."""
              model = create_model('X(84) = ISOGONAL CONJUGATE OF X(40)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00084(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00084.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00084.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
