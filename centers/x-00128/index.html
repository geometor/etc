X(128) = X(74)-OF-ORTHIC-TRIANGLE¶

Coordinates¶

Trilinears¶

  • \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where, f(A,B,C) = (sec A)(cos 2B + cos 2C)(1 + 2 cos 2A)(cos 2A + 2 cos 2B cos 2C)

  • Kimberling (6, 9, 13) Search Value: \(4.231492060175\)

Notes¶

Barycentrics g(A,B,C) : g(B,C,A) : g(C,A,B) where g(A,B,C) = (sin A) f(A,B,C)

Incidence¶

X(128) lies on the nine-point circle

X(128) lies and on these lines:

{5, 137}, {52, 134}, {53, 139}, {115, 233}, {125, 140}

Relations¶

  • X(128) = X(74)-of-orthic triangle.

  • X(128) = reflection of X(137) in X(5)

  • X(128) = isogonal conjugate of X(15401)

  • X(128) = complement of X(1141)

  • X(128) = anticomplement of X(34837)

  • X(128) = perspector of circumconic centered at X(231)

  • X(128) = center of circumconic that is locus of trilinear poles of lines passing through X(231)

  • X(128) = inverse-in-polar-circle of X(2383)

  • X(128) = X(2)-Ceva conjugate of X(231)

  • X(128) = orthojoin of X(231)

  • X(128) = excentral-to-ABC functional image of X(74)

"""GEOMETOR construction model for X(128) = X(74)-OF-ORTHIC-TRIANGLE."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              nine_point_center_of,
              point_from_barycentrics,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00128(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(128) = X(74)-OF-ORTHIC-TRIANGLE on reference triangle ABC."""
              X_128 = eval_trilinear_point(model, A, B, C, '(sec(A))*(cos(2*B) + cos(2*C))*(1 + 2*cos(2*A))*(cos(2*A) + 2*cos(2*B)*cos(2*C))', ID="X(128)", classes=["selected", "target"])
              X_5 = nine_point_center_of(model, A, B, C, ID="X(5)", classes=["center", "incident"])
              X_137 = point_from_barycentrics(model, A, B, C, 0.1354431, 0.64976082, 0.21479608, ID="X(137)", classes=["center", "incident"])
              central_line(model, X_5, X_137, 5, 137, incident=True)
              X_52 = eval_trilinear_point(model, A, B, C, 'cos(2*A)*cos(B - C)', ID="X(52)", classes=["center", "incident"])
              X_134 = point_from_barycentrics(model, A, B, C, 0.20948933, 0.10124204, 0.68926863, ID="X(134)", classes=["center", "incident"])
              central_line(model, X_52, X_134, 52, 134, incident=True)
              X_53 = eval_trilinear_point(model, A, B, C, 'tan(A)*cos(B - C)', ID="X(53)", classes=["center", "incident"])
              X_139 = point_from_barycentrics(model, A, B, C, 0.0028749347, 0.23097013, 0.76615493, ID="X(139)", classes=["center", "incident"])
              central_line(model, X_53, X_139, 53, 139, incident=True)
              return promote_point_to_top(model, X_128)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(128) on the given reference triangle."""
              model = create_model('X(128) = X(74)-OF-ORTHIC-TRIANGLE')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00128(model, A, B, C)
              return model
