X3591¶

2nd DIXIT POINT

This point is obtained in the manner of X3590 using the inward semicircles instead of outward.

Constructed Elements

  • Central Lines: {20, 1328}, {615, 1132}

  • Related Centers: X20 (DE LONGCHAMPS POINT), X1328 (ARCTAN(-3) KIEPERT POINT), X615 (ISOGONAL CONJUGATE OF X589), X1132 (ARCTAN(-2) KIEPERT POINT)

Trilinears: \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where \(f(a,b,c) = bc/(b^{2} + c^{2} - a^{2} - 6 \operatorname{area}(ABC))\)
Barycentrics: 1/(\(2S_{A}\) - 3S) : 1/(\(2S_{B}\) - 3S) : 1/(\(2S_{C}\) - 3S) [Conway notation]
Search Value (6, 9, 13): \(-2.337113387402\)
▸ Alternate Coordinates1 form

  • Trilinears: \(g(A,B,C) : g(B,C,A) : g(C,A,B)\), where \(g(A, B, C) = 1/(2 \cos A - 3 \sin A)\)

X3591 lies on the Kiepert hyperbola.
