Linear Combinations¶

  • X(7) = (2r + 4R)*X(1) + 3r*X(2) - 4r*X(3)

  • X(7) = [A]/Ra + [B]/Rb + [C]/Rc, where Ra, Rb, Rc = radii of Soddy circles

Notes¶

Let A’, B’, C’ denote the points in which the incircle meets the sides BC, CA, AB, respectively. The lines AA’, BB’, CC’ concur in X(7).

An exarc circle is a circle tangent to two sides of a triangle ABC and externally tangent to the circumcircle of ABC. The point whose distance to the sides BC, CA, AB are proportional to the respective radii of the exarc circles is X(279). The point having distances to the sides proportional to the radii of the inarc circles is X(7). See Martin Lukarevski, “Exarc radii and the Finsler-Hadwiger inequality”, The Mathematical Gazette 106, issue 565, March 2022, pp. 138-143.

X(7) is the {X(69),X(75)}-harmonic conjugate of X(8).

Construction¶

"""GEOMETOR construction model for X(7) = GERGONNE POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              gergonne_point_of,
              incenter_of,
              mittenpunkt_of,
              nagel_point_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00007(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(7) = GERGONNE POINT on reference triangle ABC."""
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_9 = mittenpunkt_of(model, A, B, C, ID="X(9)", classes=["center"])
              central_line(model, X_2, X_9, 2, 9)
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_20 = eval_trilinear_point(model, A, B, C, 'cos(A) - cos(B)*cos(C)', ID="X(20)", classes=["center"])
              central_line(model, X_1, X_20, 1, 20)
              X_8 = nagel_point_of(model, A, B, C, ID="X(8)", classes=["center"])
              X_65 = eval_trilinear_point(model, A, B, C, 'cos(B) + cos(C)', ID="X(65)", classes=["center"])
              central_line(model, X_8, X_65, 8, 65)
              X_7 = gergonne_point_of(model, A, B, C, ID="X(7)", classes=["selected", "target"], draw_cevians=True)
              return promote_point_to_top(model, X_7)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(7) on the given reference triangle."""
              model = create_model('X(7) = GERGONNE POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00007(model, A, B, C)
              return model
