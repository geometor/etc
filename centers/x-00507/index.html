X(507) = 5th ISOSCELIZER POINT¶

Coordinates¶

Trilinears¶

  • \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where f(A,B,C) = (cos A/2)-1/2

Barycentrics¶

  • \(af(A,B,C) : bf(B,C,A) : cf(C,A,B)\)

  • Kimberling (6, 9, 13) Search Value: \(1.426982771047\)

Notes¶

The isoscelizer equations

[area of T(A,X)][X(A)]2 = [area of T(B,X)][X(B)]2 = [area of T(C,X)][X(C)]2

have solution X = X(507). (Peter Yff, 4/9/99)

Relations¶

  • X(507) = trilinear square root of X(174)

Construction¶

"""GEOMETOR construction model for X(507) = 5th ISOSCELIZER POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00507(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(507) = 5th ISOSCELIZER POINT on reference triangle ABC."""
              X_507 = eval_trilinear_point(model, A, B, C, '(cos(A/2))**(-1/2)', ID="X(507)", classes=["selected", "target"])
              return promote_point_to_top(model, X_507)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(507) on the given reference triangle."""
              model = create_model('X(507) = 5th ISOSCELIZER POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00507(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00507.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00507.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
