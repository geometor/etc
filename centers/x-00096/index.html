X(96) = ISOGONAL CONJUGATE OF X(52)¶

Coordinates¶

Trilinears¶

  • \(\sec 2A \sec(B - C) : \sec 2B \sec(C - A) : \sec 2C \sec(A - B)\)

Barycentrics¶

  • \(a \sec 2A \sec(B - C) : b \sec 2B \sec(C - A) : c \sec 2C \sec(A - B)\)

  • Kimberling (6, 9, 13) Search Value: \(-1.299749991706\)

Notes¶

Let A’B’C’ be the reflection triangle. Let BA and CA be the orthogonal projections of B’ and C’ on line BC, resp. Let (OA) be the circle with segment BACA as diameter. Define (OB) and (OC) cyclically. X(96) is the radical center of circles (OA), (OB), (OC). (Randy Hutson, June 7, 2019)

Incidence¶

X(96) lies and on these lines:

{2, 54}, {4, 231}, {24, 847}, {76, 95}, {94, 925}

Relations¶

  • X(96) = isogonal conjugate of X(52)

  • X(96) = isotomic conjugate of X(39113)

  • X(96) = anticomplement of X(34835)

  • X(96) = cevapoint of X(3) and X(68)

  • X(96) = X(3)-cross conjugate of X(54)

  • X(96) = polar conjugate of X(467)

  • X(96) = Cundy-Parry Phi transform of X(5392)

  • X(96) = Cundy-Parry Psi transform of X(571)

Construction¶

"""GEOMETOR construction model for X(96) = ISOGONAL CONJUGATE OF X(52)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00096(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(96) = ISOGONAL CONJUGATE OF X(52) on reference triangle ABC."""
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_54 = eval_trilinear_point(model, A, B, C, 'sec(B - C)', ID="X(54)", classes=["center"])
              central_line(model, X_2, X_54, 2, 54)
              X_76 = eval_trilinear_point(model, A, B, C, '1/a**(3)', ID="X(76)", classes=["center"])
              X_95 = eval_trilinear_point(model, A, B, C, 'b**(2)*c**(2)*sec(B - C)', ID="X(95)", classes=["center"])
              central_line(model, X_76, X_95, 76, 95)
              X_52 = eval_trilinear_point(model, A, B, C, 'cos(2*A)*cos(B - C)', ID="X(52)", classes=["center"])
              X_96 = isogonal_conjugate(model, A, B, C, X_52, ID="X(96)", classes=["selected", "target"])
              return promote_point_to_top(model, X_96)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(96) on the given reference triangle."""
              model = create_model('X(96) = ISOGONAL CONJUGATE OF X(52)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00096(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00096.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00096.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
