X(533) = DIRECTION OF VECTOR AX + BX + CX, where X = X(18)¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where, f(a,b,c) = (2ax - by - cz)/a, x = x(A,B,C) = csc(A - π/6), y = x(B,C,A), z = x(C,A,B)

Notes¶

Barycentrics af(a,b,c) : bf(b,c,a) : cf(c,a,b)

Incidence¶

X(533) lies on the line at infinity.

X(533) lies and on these lines:

{2, 18}, {13, 621}, {14, 299}, {15, 298}, {16, 617}, {30, 511}, {395, 619}, {396, 623}, {398, 636}

Relations¶

  • X(533) = isogonal conjugate of X(2381)

Construction¶

"""GEOMETOR construction model for X(533) = DIRECTION OF VECTOR AX + BX + CX, where X = X(18)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_barycentric_point,
              eval_trilinear_point,
              intersect_lines,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00533(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(533) = DIRECTION OF VECTOR AX + BX + CX, where X = X(18) on reference triangle ABC."""
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_18 = eval_trilinear_point(model, A, B, C, 'csc(A - pi /6)', ID="X(18)", classes=["center"])
              X_14 = eval_trilinear_point(model, A, B, C, 'csc(A - pi /3)', ID="X(14)", classes=["center"])
              X_299 = eval_barycentric_point(model, A, B, C, 'csc(A)*sin(A - pi /3)', ID="X(299)", classes=["center"])
              central_line(model, X_2, X_18, 2, 18)
              central_line(model, X_14, X_299, 14, 299)
              X_533 = intersect_lines(model, X_2, X_18, X_14, X_299, ID="X(533)", classes=["selected", "target"])
              X_15 = eval_trilinear_point(model, A, B, C, 'sin(A + pi /3)', ID="X(15)", classes=["center", "incident"])
              X_298 = eval_barycentric_point(model, A, B, C, 'csc(A)*sin(A + pi /3)', ID="X(298)", classes=["center", "incident"])
              central_line(model, X_15, X_298, 15, 298, incident=True)
              return promote_point_to_top(model, X_533)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(533) on the given reference triangle."""
              model = create_model('X(533) = DIRECTION OF VECTOR AX + BX + CX, where X = X(18)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00533(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00533.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00533.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
