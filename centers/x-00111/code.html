X(111) = PARRY POINT — Code¶

Let L be a line tangent to the Brocard circle. Let P be the trilinear pole of L, and let P’ be the isogonal conjugate of P. As L varies, P’ traces a parabola with focus at X(111). The parabola meets the line at infinity at X(524). Also, X(111) is the QA-P4 center (Isogonal Center) of quadrangle X(13)X(14)X(15)X(16) (see http://www.chrisvantienhoven.nl/quadrangle-objects/15-mathematics/quadrangle-objects/artikelen-qa/25-qa-p4.html) Also, let A’ = BC∩X(115)X(125), and define B’ and C’ cyclically. The circumcircles of AB’C’, BC’A’, CA’B’ concur in X(111). (Randy Hutson, October 13, 2015)
"""GEOMETOR construction model for X(111) = PARRY POINT."""

        from __future__ import annotations

        from pathlib import Path

        import sympy.geometry as spg
        from geometor.model import Model

        from geometor.etc.ops import (
            central_line,
            centroid_of,
            construct_baseline_triangle,
            create_model,
            eval_trilinear_point,
            promote_point_to_top,
            symmedian_point_of,
        )
        from geometor.etc.render import write_center_svg


        def construct_x_00111(
            model: Model, A: spg.Point, B: spg.Point, C: spg.Point
        ) -> spg.Point:
            """Construct X(111) = PARRY POINT on reference triangle ABC."""
            X_111 = eval_trilinear_point(model, A, B, C, 'a/(2*a**(2) - b**(2) - c**(2))', ID="X(111)", classes=["selected", "target"])
            X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center", "incident"])
            X_99 = eval_trilinear_point(model, A, B, C, 'b*c/(b**(2) - c**(2))', ID="X(99)", classes=["center", "incident"])
            central_line(model, X_2, X_99, 2, 99, incident=True)
            X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center", "incident"])
            X_110 = eval_trilinear_point(model, A, B, C, 'csc(B - C)', ID="X(110)", classes=["center", "incident"])
            central_line(model, X_6, X_110, 6, 110, incident=True)
            X_37 = eval_trilinear_point(model, A, B, C, 'b + c', ID="X(37)", classes=["center", "incident"])
            X_100 = eval_trilinear_point(model, A, B, C, '1/(b - c)', ID="X(100)", classes=["center", "incident"])
            central_line(model, X_37, X_100, 37, 100, incident=True)
            return promote_point_to_top(model, X_111)


        def build_model(
            sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
            show_guides: bool = False,
        ) -> Model:
            """Build a `geometor.model.Model` for X(111) on the given reference triangle."""
            model = create_model('X(111) = PARRY POINT')
            A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
            construct_x_00111(model, A, B, C)
            return model


        if __name__ == "__main__":
            here = Path(__file__).resolve().parent
            model_acute = build_model((5.0, 6.0, 7.0))
            model_acute.save(str(here / "x-00111.json"))
            write_center_svg(
                model_acute,
                here / "x-00111.svg",
                subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
            )
