X(95) = CEVAPOINT OF CENTROID AND CIRCUMCENTER¶

Coordinates¶

Trilinears¶

  • \(b^{2}c^{2}\sec(B - C) : :\)

  • Kimberling (6, 9, 13) Search Value: \(-89.736436106389\)

Notes¶

Let A’B’C’ be the symmedial triangle. Let La be the reflection of line B’C’ in line BC, and define Lb and Lc cyclically. Let A″ = Lb∩Lc, and define B″ and C″ cyclically. The lines AA″, BB″, CC″ concur in X(95). (Randy Hutson, August 19, 2015)

Let A’ be the intersection, other than A, of the circumcircle and the branch of the Lucas cubic that contains A, and define B’ and C’ cyclically. The triangle A’B’C’ is here introduced as the Lucas triangle (not to be confused with the Lucas central triangle). The vertices A’, B’, C’ lie on the rectangular hyperbola {X(2),X(20),X(54),X(69),X(110),X(2574),X(2575),X(2979)}}. (See https://bernard-gibert.pagesperso-orange.fr/Exemples/k007.html.) Also, X(95) is the trilinear product of the vertices of the Lucas triangle. (Randy Hutson, August 19, 2015)

Incidence¶

X(95) lies and on these lines:

{2, 97}, {3, 264}, {54, 69}, {76, 96}, {99, 311}, {140, 340}, {141, 287}, {160, 327}, {183, 305}, {216, 648}, {307, 320}

Relations¶

  • X(95) = isogonal conjugate of X(51)

  • X(95) = isotomic conjugate of X(5)

  • X(95) = anticomplement of X(233)

  • X(95) = X(276)-Ceva conjugate of X(275)

  • X(95) = cevapoint of X(i) and X(j) for these (i,j): (2, 3), (6, 160), (54, 97)

  • X(95) = X(i)-cross conjugate of X(j) for these (i,j): (2, 276), (3, 97), (54, 275), (140, 2), (340, 1494)

  • X(95) = intersection of tangents at X(2) and X(3) to bianticevian conic of X(2) and X(3)

  • X(95) = crosspoint of X(2) and X(3) wrt both the anticomplementary triangle and anticevian triangle of X(3)

  • X(95) = trilinear pole of line X(323)X(401) (polar of X(53) wrt polar circle, and polar of X(69) wrt de Longchamps circle)

  • X(95) = pole wrt polar circle of trilinear polar of X(53)

  • X(95) = X(48)-isoconjugate (polar conjugate) of X(53)

  • X(95) = X(92)-isoconjugate of X(217)

Construction¶

"""GEOMETOR construction model for X(95) = CEVAPOINT OF CENTROID AND CIRCUMCENTER."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcircle,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              medial_triangle,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00095(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(95) = CEVAPOINT OF CENTROID AND CIRCUMCENTER on reference triangle ABC."""
              medial_triangle(model, A, B, C)
              circumcircle(model, A, B, C)
              X_54 = eval_trilinear_point(model, A, B, C, 'sec(B - C)', ID="X(54)", classes=["center"])
              X_69 = eval_trilinear_point(model, A, B, C, '(cos(A))/a**(2)', ID="X(69)", classes=["center"])
              central_line(model, X_54, X_69, 54, 69)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_97 = eval_trilinear_point(model, A, B, C, 'cot(A)*sec(B - C)', ID="X(97)", classes=["center"])
              central_line(model, X_2, X_97, 2, 97)
              X_76 = eval_trilinear_point(model, A, B, C, '1/a**(3)', ID="X(76)", classes=["center"])
              X_96 = eval_trilinear_point(model, A, B, C, 'sec(2*A)*sec(B - C)', ID="X(96)", classes=["center"])
              central_line(model, X_76, X_96, 76, 96)
              X_51 = eval_trilinear_point(model, A, B, C, 'a**(2)*cos(B - C)', ID="X(51)", classes=["center"])
              X_95 = isogonal_conjugate(model, A, B, C, X_51, ID="X(95)", classes=["selected", "target"])
              return promote_point_to_top(model, X_95)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(95) on the given reference triangle."""
              model = create_model('X(95) = CEVAPOINT OF CENTROID AND CIRCUMCENTER')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00095(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00095.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00095.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
