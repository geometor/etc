X(482) = 2nd EPPSTEIN POINT¶

Coordinates¶

Trilinears¶

  • \(1 + 2 \sec A/2 \cos B/2 \cos C/2 : :\)

  • \(1 + 4(area)/[a(b + c - a)] : : (E. Brisse, 3/20/01)\)

Barycentrics¶

  • \(a + (a + b + c) \tan(A/2) : :\)

  • Kimberling (6, 9, 13) Search Value: \(1.036212579546\)

Linear Combinations¶

  • X(482) = s*X(1) + (r + 4R)*X(7)

  • X(482) = [A]/Ra + [B]/Rb + [C]/Rc + X(1)/r, where Ra, Rb, Rc = radii of Soddy circles

  • X(482) = [A]/Ra + [B]/Rb + [C]/Rc + X(176)/Rs, where Ra, Rb, Rc = radii of Soddy circles, and Rs = radius of inner Soddy circle

Notes¶

Let S’ be the outer Soddy circle and SA, SB, SC the Soddy circles tangent to S. Let JA = S’∩SA, EA = SB∩SC, and determine JB, JC, EB, EC cyclically. Then X(482) is the point of concurrence of lines JA-to-EA, JB-to-EB, JC-to-EC.

David Eppstein, “Tangent spheres and triangle centers,” American Mathematical Monthly, 108 (2001) 63-66.

Let S be the inner Soddy center, X(176). X(482) is the point of concurrence of the Soddy lines of BSC, CSA, and ASB. (Randy Hutson, September 14, 2016)

Let Ia, Ib, Ic be the centers of the Elkies companion incircles. Let A’ be the trilinear product Ib*Ic, and define B’ and C’cyclically. The lines AA’, BB’, CC’ concur in X(482). The lines IaA’, IbB’, IcC’ concur in X(176). (Randy Hutson, September 14, 2016)

Let La be the line tangent to the inner Soddy circle at the touchpoint with the A-Soddy circle. Define Lb and Lc cyclically. Let A’ = Lb∩Lc and define B’ and C’ cyclically. Triangle A’B’C’, here introduced as the inner Soddy tangential triangle, is perspective to ABC, and the perspector is X(482). (Randy Hutson, September 14, 2016)

Incidence¶

X(482) lies and on these lines:

{1, 7}, {226, 486}

Relations¶

  • X(482) = X(79)-Ceva conjugate of X(481)

  • X(482) = trilinear product of centers of Elkies companion incircles

  • X(482) = Kosnita(X(176),X(7)) point

  • X(482) = Kosnita(X(176),X(176)) point

  • X(482) = {X(7),X(175)}-harmonic conjugate of X(1374)

  • X(482) = 2nd-inner-Soddy-isogonal conjugate of X(32057)

  • X(482) = perspector of ABC and the intangents triangle of the three Elkies companion incircles; see X(176)

Construction¶

"""GEOMETOR construction model for X(482) = 2nd EPPSTEIN POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              ceva_conjugate,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              gergonne_point_of,
              incenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00482(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(482) = 2nd EPPSTEIN POINT on reference triangle ABC."""
              X_79 = eval_trilinear_point(model, A, B, C, '1/(1 + 2*cos(A))', ID="X(79)", classes=["center"])
              X_481 = eval_trilinear_point(model, A, B, C, '1 - 2*sec(A/2)*cos(B/2)*cos(C/2)', ID="X(481)", classes=["center"])
              X_482 = ceva_conjugate(model, A, B, C, X_79, X_481, ID="X(482)", classes=["selected", "target"])
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center", "incident"])
              X_7 = gergonne_point_of(model, A, B, C, ID="X(7)", classes=["center", "incident"])
              central_line(model, X_1, X_7, 1, 7, incident=True)
              X_226 = eval_trilinear_point(model, A, B, C, '(csc(A))*(cos(B) + cos(C))', ID="X(226)", classes=["center", "incident"])
              X_486 = eval_trilinear_point(model, A, B, C, 'sec(A + pi /4)', ID="X(486)", classes=["center", "incident"])
              central_line(model, X_226, X_486, 226, 486, incident=True)
              return promote_point_to_top(model, X_482)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(482) on the given reference triangle."""
              model = create_model('X(482) = 2nd EPPSTEIN POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00482(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00482.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00482.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
