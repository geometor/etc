Notes¶

Let A’B’C’ be the extangents triangle. Let La be the trilinear polar of A’, and define Lb and Lc cyclically. Let A″ = Lb∩Lc, B″ = Lc∩La, C″ = La∩Lb. The lines AA″, BB″, CC″ concur in X(42). (Randy Hutson, December 26, 2015)

Let A’B’C’ be the extangents triangle. Let A″ be the trilinear product B’*C’, and define B″ and C″ cyclically. The lines AA″, BB″, CC″ concur in X(42).(Randy Hutson, December 26, 2015)

Let Ab, Ac, Bc, Ba, Ca, Cb be as defined at X(3588). Let A* be the intersection of the tangents to the Myakishev conic at Ba and Ca, and define B* and C* cyclically. The lines AA*, BB*, CC* concur in X(42).(Randy Hutson, December 26, 2015)

X(42) is the {X(1),X(43)}-harmonic conjugate of X(2).

Construction¶

"""GEOMETOR construction model for X(42) = CROSSPOINT OF INCENTER AND SYMMEDIAN POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              incircle,
              promote_point_to_top,
              symmedian_point_of,
              tangential_triangle,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00042(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(42) = CROSSPOINT OF INCENTER AND SYMMEDIAN POINT on reference triangle ABC."""
              incircle(model, A, B, C)
              tangential_triangle(model, A, B, C)
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              central_line(model, X_1, X_2, 1, 2)
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              X_31 = eval_trilinear_point(model, A, B, C, 'a**(2)', ID="X(31)", classes=["center"])
              central_line(model, X_6, X_31, 6, 31)
              X_25 = eval_trilinear_point(model, A, B, C, 'sin(A)*tan(A)', ID="X(25)", classes=["center"])
              X_41 = eval_trilinear_point(model, A, B, C, 'a**(2)*(b + c - a)', ID="X(41)", classes=["center"])
              central_line(model, X_25, X_41, 25, 41)
              X_42 = eval_trilinear_point(model, A, B, C, 'a*(b + c)', ID="X(42)", classes=["selected", "target"])
              return promote_point_to_top(model, X_42)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(42) on the given reference triangle."""
              model = create_model('X(42) = CROSSPOINT OF INCENTER AND SYMMEDIAN POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00042(model, A, B, C)
              return model
