X(204) = X(1)-CEVA CONJUGATE OF X(19)¶

Coordinates¶

Trilinears¶

  • \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where f(A,B,C) = (tan A)(tan B + tan C - tan A)

Barycentrics¶

  • \((\sin A)f(A,B,C) : (\sin B)f(B,C,A) : (\sin C)f(C,A,B)\)

  • Kimberling (6, 9, 13) Search Value: \(0.347587580012\)

Incidence¶

X(204) lies and on these lines:

{6, 33}, {19, 31}, {25, 34}, {55, 1033}, {63, 162}, {108, 223}, {207, 221}

Relations¶

  • X(204) = isogonal conjugate of X(19611)

  • X(204) = crosspoint of X(1) and X(610)

  • X(204) = crosssum of X(i) and X(j) for these {i,j}: {1, 2184}, {525, 7358}

  • X(204) = X(1)-Ceva conjugate of X(19)

  • X(204) = X(i)-beth conjugate of X(j) for these (i,j): (108, 204), (162, 223)

"""GEOMETOR construction model for X(204) = X(1)-CEVA CONJUGATE OF X(19)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
              symmedian_point_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00204(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(204) = X(1)-CEVA CONJUGATE OF X(19) on reference triangle ABC."""
              X_204 = eval_trilinear_point(model, A, B, C, '(tan(A))*(tan(B) + tan(C) - tan(A))', ID="X(204)", classes=["selected", "target"])
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center", "incident"])
              X_33 = eval_trilinear_point(model, A, B, C, '1 + sec(A)', ID="X(33)", classes=["center", "incident"])
              central_line(model, X_6, X_33, 6, 33, incident=True)
              X_19 = eval_trilinear_point(model, A, B, C, 'tan(A)', ID="X(19)", classes=["center", "incident"])
              X_31 = eval_trilinear_point(model, A, B, C, 'a**(2)', ID="X(31)", classes=["center", "incident"])
              central_line(model, X_19, X_31, 19, 31, incident=True)
              X_25 = eval_trilinear_point(model, A, B, C, 'sin(A)*tan(A)', ID="X(25)", classes=["center", "incident"])
              X_34 = eval_trilinear_point(model, A, B, C, '1 - sec(A)', ID="X(34)", classes=["center", "incident"])
              central_line(model, X_25, X_34, 25, 34, incident=True)
              return promote_point_to_top(model, X_204)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,

              """Build a `geometor.model.Model` for X(204) on the given reference triangle."""
              model = create_model('X(204) = X(1)-CEVA CONJUGATE OF X(19)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00204(model, A, B, C)
              return model
