X(391) = INTERSECTION OF LINES X(2,6) AND X(8,9)¶

Coordinates¶

Trilinears¶

  • \(bc(3a + b + c)(b + c - a) : :\)

Barycentrics¶

  • \((3a + b + c)(b + c - a) : :\)

  • \(a^{2} - s^{2} : b^{2} - s^{2} : c^{2} - s^{2}\)

  • Kimberling (6, 9, 13) Search Value: \(4.179129206605\)

Notes¶

X(391) is the {X(8),X(9)}-harmonic conjugate of X(346).

Incidence¶

X(391) lies and on these lines:

{2, 6}, {8, 9}, {20, 573}, {37, 145}, {75, 144}, {319, 344}

Relations¶

  • X(391) = crosssum of X(940) and X(4383)

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.render import write_center_svg


          def construct_x_00391(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point

              """Construct X(391) = INTERSECTION OF LINES X(2,6) AND X(8,9) on reference triangle ABC."""
              X_391 = eval_trilinear_point(model, A, B, C, 'b*c*(3*a + b + c)*(b + c - a)', ID="X(391)", classes=["selected", "target"])

              central_line(model, X_37, X_145, 37, 145, incident=True)
              return promote_point_to_top(model, X_391)


          def build_model(
