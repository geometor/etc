X(268) = ISOGONAL CONJUGATE OF X(196)¶

Coordinates¶

Trilinears¶

  • \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where f(A,B,C) = (cos A cot A/2)/(-1 - cos A + cos B + cos C)

Barycentrics¶

  • \((\sin A)f(A,B,C) : (\sin B)f(B,C,A) : (\sin C)f(C,A,B)\)

  • Kimberling (6, 9, 13) Search Value: \(3.669332046882\)

Incidence¶

X(268) lies and on these lines:

{3, 9}, {21, 280}, {219, 255}, {220, 577}, {222, 1073}, {281, 1012}

Relations¶

  • X(268) = isogonal conjugate of X(196)

  • X(268) = X(i)-cross conjugate of X(j) for these (i,j): (48, 219), (55, 3)

  • X(268) = crosssum of X(19) and X(207)

  • X(268) = X(92)-isoconjugate of X(221)

          from __future__ import annotations

          import sympy.geometry as spg

          from geometor.etc.render import write_center_svg


          def construct_x_00268(

          def build_model(
