X(66) = ISOGONAL CONJUGATE OF X(22)¶

Coordinates¶

Trilinears¶

  • \(bc/(b^{4} + c^{4} - a^{4}) : :\)

Barycentrics¶

  • \(1/(b^{4} + c^{4} - a^{4}) : :\)

  • Kimberling (6, 9, 13) Search Value: \(9.640588374561\)

Notes¶

Let P be a point on the circumcircle, and let LP be its Steiner line. The locus of the orthopole of LP, as P varies, is an ellipse with center X(4) and perspector X(66). (Randy Hutson, March 29, 2020)

In the plane of a triangle ABC, let

  • A’B’C’ = anticomplementary triangle;

  • Oa = circle with diameter BC, and define Ob and Oc cyclically;

  • Ab = A’BC’∩Oa, and define Bc and Ca cyclically;

  • Ac = B’CA’∩Oa, and define Ba and Cb cyclically;

  • A″= BcBa∩CaCb, and define B″ and C″ cyclically.

The triangle A″B″C″ is perspective to ABC, and the perspector is X(66). (Dasari Naga Vijay Krishna, April 15, 2021)

Construction¶

"""GEOMETOR construction model for X(66) = ISOGONAL CONJUGATE OF X(22)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              circumcircle,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00066(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(66) = ISOGONAL CONJUGATE OF X(22) on reference triangle ABC."""
              circumcircle(model, A, B, C)
              X_22 = eval_trilinear_point(model, A, B, C, 'a*(b**(4) + c**(4) - a**(4))', ID="X(22)", classes=["center"])
              X_66 = isogonal_conjugate(model, A, B, C, X_22, ID="X(66)", classes=["selected", "target"])
              return promote_point_to_top(model, X_66)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(66) on the given reference triangle."""
              model = create_model('X(66) = ISOGONAL CONJUGATE OF X(22)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00066(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00066.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00066.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
