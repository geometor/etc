X(370) = EQUILATERAL CEVIAN TRIANGLE POINT¶

Coordinates¶

Trilinears¶

  • \((see below)\)

Barycentrics¶

  • \((see below)\)

  • Kimberling (6, 9, 13) Search Value: \(1.277501263430\)

Notes¶

A point P is an equilateral cevian triangle point if the cevian triangle of P is equilateral. Jiang Huanxin introduced this notion in 1997.

Jean-Pierre Ehrmann notes (11/6/02) that the normalized barycentric coordinates (x,y,z) of X(370) are the unique solution of this system:

y(1 - y)SB + z(1 - z)SC = x(1 + x)F

z(1 - z)SC + x(1 - x)SA = y(1 + y)F

x(1 - x)SA + y(1 - y)SB = z(1 + z)F

x + y + z = 1,

where SA = (b2 + c2 - a2)/2; SB, SC are defined cyclically, F = [2 area(ABC)]/sqrt(3), and x>0, y>0, z>0.

Jiang Huanxin and David Goering, Problem 10358* and Solution, “Equilateral cevian triangles,” American Mathematical Monthly 104 (1997) 567-570 [proposed 1994].

Incidence¶

X(370) lies on the Neuberg cubic.

Construction¶

"""GEOMETOR construction model for X(370) = EQUILATERAL CEVIAN TRIANGLE POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              construct_baseline_triangle,
              create_model,
              point_from_barycentrics,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00370(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(370) = EQUILATERAL CEVIAN TRIANGLE POINT on reference triangle ABC."""
              X_370 = point_from_barycentrics(model, A, B, C, 0.2620507, 0.3232068, 0.4147425, ID="X(370)", classes=["selected", "target"])
              return promote_point_to_top(model, X_370)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(370) on the given reference triangle."""
              model = create_model('X(370) = EQUILATERAL CEVIAN TRIANGLE POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00370(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00370.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00370.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
