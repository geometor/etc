X(70) = ISOGONAL CONJUGATE OF X(26)¶

Coordinates¶

Trilinears¶

  • \(bc/[b^{2} \cos 2B + c^{2} \cos 2C - a^{2} \cos 2A] : :\)

Barycentrics¶

  • \(1/(a^8 - 2 a^6 (b^2 + c^2) + 2 a^2 (b^6 + c^6) - (b^2 - c^2)^2 (b^4 + c^4)) : :\)

  • Kimberling (6, 9, 13) Search Value: \(5.721069014472\)

Linear Combinations¶

  • X(70) = (S cot ω- 2R2)/(S cot ω-3 R2)*X(3) - X(8907) (Peter Moses, December 28, 2015)

Incidence¶

X(70) lies on the Jerabek circumhyperbola and on these lines:

{3, 8907}, {6, 1594}, {54, 1899}, {64, 6240}, {66, 6403}, {71, 2158}, {74, 1288}, {265, 6243}, {1176, 1352}, {1177, 3542}, {3448, 5504}, {3527, 7507}, {4846, 6241}, {6145, 6152}

Construction¶

"""GEOMETOR construction model for X(70) = ISOGONAL CONJUGATE OF X(26)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00070(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(70) = ISOGONAL CONJUGATE OF X(26) on reference triangle ABC."""
              X_26 = eval_trilinear_point(model, A, B, C, 'a*(b**(2)*cos(2*B) + c**(2)*cos(2*C) - a**(2)*cos(2*A))', ID="X(26)", classes=["center"])
              X_70 = isogonal_conjugate(model, A, B, C, X_26, ID="X(70)", classes=["selected", "target"])
              return promote_point_to_top(model, X_70)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(70) on the given reference triangle."""
              model = create_model('X(70) = ISOGONAL CONJUGATE OF X(26)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00070(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00070.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00070.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
