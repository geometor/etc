X1599¶

POINT CHORT I

X1599 = anticomplement of X1591

Constructed Elements

  • Derived Triangle: Anticomplementary Triangle △KaKbKc — vertices Ka, Kb, Kc (Formed by lines through A, B, C parallel to opposite sides)

  • Central Lines: {2, 1591}, {2, 3} (Euler line)

  • Related Centers: X2 (CENTROID), X1591 (POINT CHARA III), X3 (CIRCUMCENTER)

Trilinears: \(f(A,B,C) : f(B,C,A) : f(C,A,B)\), where \(f(A,B,C) = \csc A + 2 \cos A\)
Barycentrics: \((\sin A)f(A,B,C) : (\sin B)f(B,C,A) : (\sin C)f(C,A,B)\)
Search Value (6, 9, 13): \(3.555076776934\)
