X(356) = MORLEY CENTER¶

Coordinates¶

Trilinears¶

  • \(\cos A/3 + 2 \cos B/3 \cos C/3 : :\)

  • \(= \cos(B/3 - C/3) + \sqrt{3}\sin(A/3 + \pi /3) (M. Stevanovic, 12/25/2007)\)

  • Kimberling (6, 9, 13) Search Value: \(1.625386564358\)

Linear Combinations¶

  • X(356) = X(3276) + X(3277) - X(3)

Notes¶

X(356) is the centroid of the Morley equilateral triangle. For a discussion of the theorem and extensive list of references, see

C. O. Oakley and J. C. Baker, “The Morley trisector theorem,” American Mathematical Monthly 85 (1978) 737-745.

For a sketch of the Morley cubic and list of centers on it, including X(356), X(357), X(358), see Bernard Gibert’s site.

See also Dao Thanh Oai, Some new equilateral triangles in a plane geometry.

Let A’B’C’ be the 1st Morley triangle. Let A″ be the cevapoint of B’ and C’, and define B″ and C″ cyclically. The lines AA″, BB″, CC″ concur in X(356). (Randy Hutson, September 14, 2016)

For a biographical sketch, including details about Morley’s famous theorem on angle trisectors, with history and references, see

Frank Morley (1860-1937) geometer (../bstud/morley.html).

Incidence¶

X(356) lies and on these lines:

{2, 5455}, {3, 3278}, {357, 358}, {1134, 1135}, {3605, 5456}

Relations¶

  • X(356) = isogonal conjugate of X(3605)

  • X(356) = orthology center of 1st Morley adjunct triangle and 1st Morley triangle

Construction¶

"""GEOMETOR construction model for X(356) = MORLEY CENTER."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00356(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(356) = MORLEY CENTER on reference triangle ABC."""
              X_356 = eval_trilinear_point(model, A, B, C, 'cos(A/3) + 2*cos(B/3)*cos(C/3)', ID="X(356)", classes=["selected", "target"])
              X_357 = eval_trilinear_point(model, A, B, C, 'sec(A/3)', ID="X(357)", classes=["center", "incident"])
              X_358 = eval_trilinear_point(model, A, B, C, 'cos(A/3)', ID="X(358)", classes=["center", "incident"])
              central_line(model, X_357, X_358, 357, 358, incident=True)
              return promote_point_to_top(model, X_356)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(356) on the given reference triangle."""
              model = create_model('X(356) = MORLEY CENTER')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00356(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00356.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00356.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
