X(33) = PERSPECTOR OF THE ORTHIC AND INTANGENTS TRIANGLES¶

Coordinates¶

Trilinears¶

  • \(1 + \sec A : 1 + \sec B : 1 + \sec C\)

  • \(\tan A \cot(A/2) : \tan B \cot(B/2) : \tan C \cot(C/2)\)

  • \((b + c - a)/(b^{2} + c^{2} - a^{2}) : :\)

  • \(\sec A \cos^{2}(A/2) : :\)

Barycentrics¶

  • \(\sin A + \tan A : \sin B + \tan B : \sin C + \tan C\)

  • \(\tan A \cos^{2}(A/2) : :\)

  • Kimberling (6, 9, 13) Search Value: \(5.246983589481\)

Linear Combinations¶

  • X(33) = (r + 2R - s)(r + 2R + s)*X(1) - 6rR*X(2) + 4rR*X(3) (Peter Moses, April 2, 2013)

Notes¶

Let LA be the reflection of line BC in the internal angle bisector of angle A, and define LB and LC cyclically. Let DEF be the triangle formed by LA, LB, LC. Then DEF (the intangents triangle) is homothetic to the orthic triangle, and the homothetic center is X(33). (Randy Hutson, 9/23/2011)

X(33) is the {X(1),X(4)}-harmonic conjugate of X(34). For a list of other harmonic conjugates, click Tables at the top of this page.

Construction¶

"""GEOMETOR construction model for X(33) = PERSPECTOR OF THE ORTHIC AND INTANGENTS TRIANGLES."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              orthic_triangle,
              orthocenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00033(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(33) = PERSPECTOR OF THE ORTHIC AND INTANGENTS TRIANGLES on reference triangle ABC."""
              orthic_triangle(model, A, B, C)
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              central_line(model, X_1, X_4, 1, 4)
              X_19 = eval_trilinear_point(model, A, B, C, 'tan(A)', ID="X(19)", classes=["center"])
              X_25 = eval_trilinear_point(model, A, B, C, 'sin(A)*tan(A)', ID="X(25)", classes=["center"])
              central_line(model, X_19, X_25, 19, 25)
              X_24 = eval_trilinear_point(model, A, B, C, 'sec(A)*cos(2*A)', ID="X(24)", classes=["center"])
              X_35 = eval_trilinear_point(model, A, B, C, '1 + 2*cos(A)', ID="X(35)", classes=["center"])
              central_line(model, X_24, X_35, 24, 35)
              X_33 = eval_trilinear_point(model, A, B, C, '1 + sec(A)', ID="X(33)", classes=["selected", "target"])
              return promote_point_to_top(model, X_33)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(33) on the given reference triangle."""
              model = create_model('X(33) = PERSPECTOR OF THE ORTHIC AND INTANGENTS TRIANGLES')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00033(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00033.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00033.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
