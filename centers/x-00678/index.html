X(678) = CROSSPOINT OF X(1) AND X(44)¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = (b + c - 2a)2

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = af(a,b,c)

  • Kimberling (6, 9, 13) Search Value: \(2.169048499762\)

Incidence¶

X(678) lies on the incentral inellipse (a.k.a. Hofstadter ellipse E(1/2)).

X(678) lies and on these lines:

{1, 88}, {44, 902}, {45, 55}

Relations¶

  • X(678) = isogonal conjugate of X(679)

  • X(678) = X(1)-Ceva conjugate of X(44)

  • X(678) = crosspoint of X(1) and X(44)

  • X(678) = crosssum of X(i) and X(j) for these (i,j): (1, 88), (244, 1022)

  • X(678) = crossdifference of every pair of points on line X(88)X(1022)

  • X(678) = trilinear square of X(44)

Construction¶

"""GEOMETOR construction model for X(678) = CROSSPOINT OF X(1) AND X(44)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00678(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(678) = CROSSPOINT OF X(1) AND X(44) on reference triangle ABC."""
              X_678 = eval_trilinear_point(model, A, B, C, '(b + c - 2*a)**(2)', ID="X(678)", classes=["selected", "target"])
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center", "incident"])
              X_88 = eval_trilinear_point(model, A, B, C, '1/(b + c - 2*a)', ID="X(88)", classes=["center", "incident"])
              central_line(model, X_1, X_88, 1, 88, incident=True)
              X_45 = eval_trilinear_point(model, A, B, C, '2*b + 2*c - a', ID="X(45)", classes=["center", "incident"])
              X_55 = eval_trilinear_point(model, A, B, C, 'a*(b + c - a)', ID="X(55)", classes=["center", "incident"])
              central_line(model, X_45, X_55, 45, 55, incident=True)
              X_44 = eval_trilinear_point(model, A, B, C, 'b + c - 2*a', ID="X(44)", classes=["center", "incident"])
              X_902 = eval_trilinear_point(model, A, B, C, 'a*(b + c - 2*a)', ID="X(902)", classes=["center", "incident"])
              central_line(model, X_44, X_902, 44, 902, incident=True)
              return promote_point_to_top(model, X_678)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(678) on the given reference triangle."""
              model = create_model('X(678) = CROSSPOINT OF X(1) AND X(44)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00678(model, A, B, C)
              return model
