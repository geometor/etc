X(855) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(57)¶

Coordinates¶

Trilinears¶

  • \(f(A,B,C) : f(B,C,A) : f(C,A,B),\), where f(A,B,C) = cot(C/2) sin 2B sin(C - A) + cot(B/2) sin 2C sin(B - A)

Barycentrics¶

  • \(g(A,B,C) : g(B,C,A) : g(C,A,B)\), where g(A,B,C) = (sin A)f(A,B,C)

  • Kimberling (6, 9, 13) Search Value: \(0.008868750603\)

Notes¶

As a point on the Euler line, X(855) has Shinagawa coefficients (ES2+$abSC2$+$abSASB$ -$abSC$(E+F), -3ES\ :sup:`2`-3$abSASB$ +2$ab$S2).

Incidence¶

X(855) lies and on these lines:

{2, 3}, {513, 663}

Relations¶

  • X(855) = reflection of X(851) in X(859)

  • X(855) = crossdifference of every pair of points on line X(9)X(647)

Construction¶

"""GEOMETOR construction model for X(855) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(57)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcenter_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00855(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(855) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(57) on reference triangle ABC."""
              X_855 = eval_trilinear_point(model, A, B, C, 'cot(C/2)*sin(2*B)*sin(C - A) + cot(B/2)*sin(2*C)*sin(B - A)', ID="X(855)", classes=["selected", "target"])
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              central_line(model, X_2, X_3, 2, 3)
              X_513 = eval_trilinear_point(model, A, B, C, 'b - c', ID="X(513)", classes=["center", "incident"])
              X_663 = eval_trilinear_point(model, A, B, C, 'a*(b - c)*(b + c - a)', ID="X(663)", classes=["center", "incident"])
              central_line(model, X_513, X_663, 513, 663, incident=True)
              return promote_point_to_top(model, X_855)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(855) on the given reference triangle."""
              model = create_model('X(855) = INTERCEPT OF EULER LINE AND TRILINEAR POLAR OF X(57)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00855(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00855.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00855.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
