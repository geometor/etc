X(357) = 1st MORLEY-TAYLOR-MARR CENTER¶

Coordinates¶

Trilinears¶

  • \(\sec A/3 : \sec B/3 : \sec C/3\)

Barycentrics¶

  • \(\sin A \sec A/3 : \sin B \sec B/3 : \sin C \sec C/3\)

  • Kimberling (6, 9, 13) Search Value: \(1.486625299299\)

Notes¶

X(357) is the perspector of Morley triangle and ABC, and also the Hofstadter 1/3 point. See

F. Glanville Taylor and W. L. Marr, “The six trisectors of each of the angles of a triangle,” Proceedings of the Edinburgh Mathematical Society 33 (1913-14) 119-131, especially item 9, page 127.

Incidence¶

X(357) lies and on these lines:

{356, 358}, {1134, 3275}, {3280, 5454}

Relations¶

  • X(357) = isogonal conjugate of X(358)

  • X(357) = {X(1135),X(3272)}-harmonic conjugate of X(3603)

  • X(357) = trilinear product of vertices of 1st Morley triangle

Construction¶

"""GEOMETOR construction model for X(357) = 1st MORLEY-TAYLOR-MARR CENTER."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00357(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(357) = 1st MORLEY-TAYLOR-MARR CENTER on reference triangle ABC."""
              X_357 = eval_trilinear_point(model, A, B, C, 'sec(A/3)', ID="X(357)", classes=["selected", "target"])
              X_356 = eval_trilinear_point(model, A, B, C, 'cos(A/3) + 2*cos(B/3)*cos(C/3)', ID="X(356)", classes=["center", "incident"])
              X_358 = eval_trilinear_point(model, A, B, C, 'cos(A/3)', ID="X(358)", classes=["center", "incident"])
              central_line(model, X_356, X_358, 356, 358, incident=True)
              return promote_point_to_top(model, X_357)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(357) on the given reference triangle."""
              model = create_model('X(357) = 1st MORLEY-TAYLOR-MARR CENTER')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00357(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00357.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00357.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
