X(589) = 2nd KENMOTU-VAN LAMOEN POINT¶

Coordinates¶

Trilinears¶

  • \(f(a,b,c) : f(b,c,a) : f(c,a,b)\), where f(a,b,c) = a/(a2 - 4*area(ABC))

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = af(a,b,c)

  • Kimberling (6, 9, 13) Search Value: \(-7.143200881171\)

Notes¶

X(589) is the perspector of triangles ABC and A’B’C’, where A’ is the circumcenter of X(372) and the points where the squares in the Kenmotu configuration with center X(372) meet sideline BC, and B’ and C’ are defined cyclically. See the reference at X(588).

X(588) is the homothetic center of triangle ABC and the Lucas(-2:1) homothetic triangle; see X(371) and X(588). (Randy Hutson, 9/23/2011)

Let A’B’C’ be the Lucas(-1) central triangle. Let A″ be the trilinear pole of line B’C’; define B″ and C″ cyclically. Let A* be the trilinear pole of line B″C″; define B* and C* cyclically. The lines AA*, BB*, CC* concur in X(589). (Randy Hutson, January 29, 2015)

Incidence¶

X(589) lies and on these lines:

{39, 588}

Relations¶

  • X(589) = isogonal conjugate of X(615)

  • X(589) = cevapoint of X(6) and X(372)

  • X(589) = X(1994)-cross conjugate of X(588)

Construction¶

"""GEOMETOR construction model for X(589) = 2nd KENMOTU-VAN LAMOEN POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00589(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(589) = 2nd KENMOTU-VAN LAMOEN POINT on reference triangle ABC."""
              X_589 = eval_trilinear_point(model, A, B, C, 'a/(a**(2)- 4*area*(A*B*C))', ID="X(589)", classes=["selected", "target"])
              X_39 = eval_trilinear_point(model, A, B, C, 'a*(b**(2) + c**(2))', ID="X(39)", classes=["center", "incident"])
              X_588 = eval_trilinear_point(model, A, B, C, 'a/(a**(2)+ 4*area*(A*B*C))', ID="X(588)", classes=["center", "incident"])
              central_line(model, X_39, X_588, 39, 588, incident=True)
              return promote_point_to_top(model, X_589)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(589) on the given reference triangle."""
              model = create_model('X(589) = 2nd KENMOTU-VAN LAMOEN POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00589(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00589.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00589.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
