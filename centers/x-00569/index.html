X(569) = HARMONIC OF X(52)¶

Coordinates¶

Trilinears¶

  • \(\sin A + \cot D/2 \cos A : :,\)

  • \(\cot D/2 = (2e_{3} + e_{2} - e_{1})/[64*(area)^{3}]\), where, e1 = a6 + b6 + c6, e2 = a4(b2 + c2) + b4(c2 + a2) + c4(a2 + b2), e3 = a2b2c2

  • Kimberling (6, 9, 13) Search Value: \(2.078407331492\)

Incidence¶

X(569) lies and on these lines:

{2, 54}, {3, 6}, {5, 156}, {26, 51}, {140, 343}

Relations¶

  • X(569) = inverse-in-Brocard-circle of X(52)

Construction¶

"""GEOMETOR construction model for X(569) = HARMONIC OF X(52)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcenter_of,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              intersect_lines,
              promote_point_to_top,
              symmedian_point_of,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00569(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(569) = HARMONIC OF X(52) on reference triangle ABC."""
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              X_6 = symmedian_point_of(model, A, B, C, ID="X(6)", classes=["center"])
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_54 = eval_trilinear_point(model, A, B, C, 'sec(B - C)', ID="X(54)", classes=["center"])
              central_line(model, X_3, X_6, 3, 6)
              central_line(model, X_2, X_54, 2, 54)
              X_569 = intersect_lines(model, X_3, X_6, X_2, X_54, ID="X(569)", classes=["selected", "target"])
              X_26 = eval_trilinear_point(model, A, B, C, 'a*(b**(2)*cos(2*B) + c**(2)*cos(2*C) - a**(2)*cos(2*A))', ID="X(26)", classes=["center", "incident"])
              X_51 = eval_trilinear_point(model, A, B, C, 'a**(2)*cos(B - C)', ID="X(51)", classes=["center", "incident"])
              central_line(model, X_26, X_51, 26, 51, incident=True)
              return promote_point_to_top(model, X_569)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(569) on the given reference triangle."""
              model = create_model('X(569) = HARMONIC OF X(52)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00569(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00569.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00569.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
