X(92) = CEVAPOINT OF INCENTER AND CLAWSON POINT¶

Coordinates¶

Trilinears¶

  • \(\csc 2A : \csc 2B : \csc 2C\)

  • \(\cot A + \tan A : :\)

Barycentrics¶

  • \(\sec A : \sec B : \sec C\)

  • Kimberling (6, 9, 13) Search Value: \(31.410531526384\)

Linear Combinations¶

  • X(92) = 2r(r+2R)*X(4) - ((r + 2R)^2 - s^2)*X(8)

  • X(92) = (sec A)*[A] + (sec B)*[B] + (sec C)*[C], where A, B, C denote angles and [A], [B], [C] denote vertices

Notes¶

Let LA be the line through X(4) parallel to the internal bisector of angle A, and let

  • A’ = BC∩LA. Define B’ and C’ cyclically.

Alexei Myakishev, “The M-Configuration of a Triangle,” Forum Geometricorum 3 (2003) 135-144,

proves that the lines AA’, BB’, CC’ concur in X(92). He notes that another construction follows from Proposition 2 of the article: let A1 be the midpoint of the arc BC of the circumcircle that passes through A, and let A2 be the point, other than A, in which the A-altitude meets the circumcircle. Let A″ = A1A2∩BC. Define B″ and C″ cyclically. Then the lines AA″, BB″, CC″ concur in X(92).

Suppose that T = A’B’C’ is a central triangle. Let A’’ be the pole with respect to the polar circle of the line B’C’, and define B’’ and C’’ cyclically. The appearance of T in the following list means that the lines AA’’, BB’’, CC’’ concur in X(92): Feurerbach, incentral, excentral, extangents, Apollonius, mixtilinear excentral. (Randy Hutson, December 26, 2015)

"""GEOMETOR construction model for X(92) = CEVAPOINT OF INCENTER AND CLAWSON POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              incenter_of,
              incircle,
              isogonal_conjugate,
              nagel_point_of,
              orthocenter_of,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00092(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(92) = CEVAPOINT OF INCENTER AND CLAWSON POINT on reference triangle ABC."""
              incircle(model, A, B, C)
              X_4 = orthocenter_of(model, A, B, C, ID="X(4)", classes=["center"])
              X_8 = nagel_point_of(model, A, B, C, ID="X(8)", classes=["center"])
              central_line(model, X_4, X_8, 4, 8)
              X_1 = incenter_of(model, A, B, C, ID="X(1)", classes=["center"])
              X_29 = eval_trilinear_point(model, A, B, C, '(sec(A))/(cos(B) + cos(C))', ID="X(29)", classes=["center"])
              central_line(model, X_1, X_29, 1, 29)
              X_19 = eval_trilinear_point(model, A, B, C, 'tan(A)', ID="X(19)", classes=["center"])
              X_27 = eval_trilinear_point(model, A, B, C, '(sec(A))/(b + c)', ID="X(27)", classes=["center"])
              central_line(model, X_19, X_27, 19, 27)
              X_48 = eval_trilinear_point(model, A, B, C, 'tan(B) + tan(C)', ID="X(48)", classes=["center"])
              X_92 = isogonal_conjugate(model, A, B, C, X_48, ID="X(92)", classes=["selected", "target"])
              return promote_point_to_top(model, X_92)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(92) on the given reference triangle."""
              model = create_model('X(92) = CEVAPOINT OF INCENTER AND CLAWSON POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00092(model, A, B, C)
              return model
