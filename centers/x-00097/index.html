X(97) = ISOGONAL CONJUGATE OF X(53)¶

Coordinates¶

Trilinears¶

  • \(\cot A \sec(B - C) : \cot B \sec(C - A) : \cot C \sec(A - B)\)

Barycentrics¶

  • \(\cos A \sec(B - C) : \cos B \sec(C - A) : \cos C \sec(A - B)\)

  • Kimberling (6, 9, 13) Search Value: \(-13.339586550833\)

Notes¶

In the plane of a triangle ABC, let

  • Ia = line through X(3) parallel to BC, and define Ib and Ic cyclically.

  • Ac = Ia∩AB, and define Ba and Cb cyclically.

  • Ab = Ia∩AC, and define Bc and Ca cyclically.

  • Oa = circumcircle of A, Bc, Cb, and define Ob and Oc cyclically.

Then X(97) = radical center of Oa, Ob, Oc. See also X(77). (Ivan Pavlov, April 1, 2022)

Incidence¶

X(97) lies and on these lines:

{2, 95}, {3, 54}, {110, 418}, {216, 288}, {276, 401}

Relations¶

  • X(97) = isogonal conjugate of X(53)

  • X(97) = isotomic conjugate of X(324)

  • X(97) = anticomplement of X(34836)

  • X(97) = complement of isogonal conjugate of X(34433)

  • X(97) = X(95)-Ceva conjugate of X(54)

  • X(97) = X(3)-cross conjugate of X(95)

  • X(97) = cevapoint of X(3) and X(577)

  • X(97) = X(51)-isoconjugate of X(92)

  • X(97) = Cundy-Parry Phi transform of X(7592)

Construction¶

"""GEOMETOR construction model for X(97) = ISOGONAL CONJUGATE OF X(53)."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              central_line,
              centroid_of,
              circumcenter_of,
              circumcircle,
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              isogonal_conjugate,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00097(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(97) = ISOGONAL CONJUGATE OF X(53) on reference triangle ABC."""
              circumcircle(model, A, B, C)
              X_3 = circumcenter_of(model, A, B, C, ID="X(3)", classes=["center"])
              X_54 = eval_trilinear_point(model, A, B, C, 'sec(B - C)', ID="X(54)", classes=["center"])
              central_line(model, X_3, X_54, 3, 54)
              X_2 = centroid_of(model, A, B, C, ID="X(2)", classes=["center"])
              X_95 = eval_trilinear_point(model, A, B, C, 'b**(2)*c**(2)*sec(B - C)', ID="X(95)", classes=["center"])
              central_line(model, X_2, X_95, 2, 95)
              X_53 = eval_trilinear_point(model, A, B, C, 'tan(A)*cos(B - C)', ID="X(53)", classes=["center"])
              X_97 = isogonal_conjugate(model, A, B, C, X_53, ID="X(97)", classes=["selected", "target"])
              return promote_point_to_top(model, X_97)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(97) on the given reference triangle."""
              model = create_model('X(97) = ISOGONAL CONJUGATE OF X(53)')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00097(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00097.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00097.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
