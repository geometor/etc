X(333) = CEVAPOINT OF X(8) AND X(9)¶

Let A27B27C27 be Gemini triangle 27. Let A’ be the perspector of conic {A,B,C,B27,C27}}, and define B’ and C’ cyclically. The lines AA’, BB’, CC’ concur in X(333). (Randy Hutson, January 15, 2019)
Trilinears: \(bc(b + c - a)/(b + c) : ca(c + a - b)/(c + a) : ab(a + b - c)/(a + b)\)
Barycentrics: \((b + c - a)/(b + c) : (c + a - b)/(c + a) : (a + b - c)/(a + b)\)
Search Value (6, 9, 13): \(4.136357530042\)

X(333) lies.
