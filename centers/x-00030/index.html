X(30) = EULER INFINITY POINT¶

Coordinates¶

Trilinears¶

  • \(\cos A - 2 \cos B \cos C : \cos B - 2 \cos C \cos A : \cos C - 2 \cos A cosB\)

  • \(bc[2a^{4} - (b^{2} - c^{2})^{2} - a^{2}(b^{2} + c^{2})] : :\)

  • \(2 \sec A - \sec B \sec C : :\)

  • \(\sin B \sin C - 3 \cos B \cos C : :\)

Barycentrics¶

  • \(g(a,b,c) : g(b,c,a) : g(c,a,b)\), where g(a,b,c) = 2a4 - (b2 - c2)2 - a2(b2 + c2)

  • \(S^2 - 3 SB SC : :\)

Linear Combinations¶

  • X(30) = X(2) - X(3); if (i) and X(j) are on the Euler line, then X(30) = X(i) - X(j)

Notes¶

As a point on the Euler line, X(30) has Shinagawa coefficients (1, -3).

Let A’B’C’ be the reflection triangle. Let A″ be the cevapoint of B’ and C’, and define B″ and C″ cyclically. The lines AA″, BB″, CC″ are parallel to the Euler line, and therefore concur in X(30). (Randy Hutson, December 10, 2016)

X(30) is the point of intersection of the Euler line and the line at infinity. Thus, each of the lines listed below is parallel to the Euler line.

Construction¶

"""GEOMETOR construction model for X(30) = EULER INFINITY POINT."""

          from __future__ import annotations

          from pathlib import Path

          import sympy.geometry as spg
          from geometor.model import Model

          from geometor.etc.ops import (
              construct_baseline_triangle,
              create_model,
              eval_trilinear_point,
              promote_point_to_top,
          )
          from geometor.etc.render import write_center_svg


          def construct_x_00030(
              model: Model, A: spg.Point, B: spg.Point, C: spg.Point
          ) -> spg.Point:
              """Construct X(30) = EULER INFINITY POINT on reference triangle ABC."""
              X_30 = eval_trilinear_point(model, A, B, C, 'cos(A) - 2*cos(B)*cos(C)', ID="X(30)", classes=["selected", "target"])
              return promote_point_to_top(model, X_30)


          def build_model(
              sides: tuple[float, float, float] = (5.0, 6.0, 7.0),
              show_guides: bool = False,
          ) -> Model:
              """Build a `geometor.model.Model` for X(30) on the given reference triangle."""
              model = create_model('X(30) = EULER INFINITY POINT')
              A, B, C = construct_baseline_triangle(model, *sides, show_guides=show_guides)
              construct_x_00030(model, A, B, C)
              return model


          if __name__ == "__main__":
              here = Path(__file__).resolve().parent
              model_acute = build_model((5.0, 6.0, 7.0))
              model_acute.save(str(here / "x-00030.json"))
              write_center_svg(
                  model_acute,
                  here / "x-00030.svg",
                  subtitle="(a, b, c) = (5, 6, 7) | AB = 1",
              )
