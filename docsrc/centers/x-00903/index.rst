X_903
=====

.. rubric:: X_1-BLAIKIE TRANSFORM OF X_2

.. enunciation::

   James Blaikie (1847-1929) proposed the following problem. Let :g:`O <O>` be any point in the plane of triangle :g:`ABC << A B C >>`, and let any straight line g through O meet :g:`BC <[ B C ]>` in :g:`P <P>`, :g:`CA <[ C A ]>` in :g:`Q <Q>`, :g:`AB <[ A B ]>` in R; then, if points :g:`P' <P'>`, :g:`Q' <Q'>`, :g:`R' <R'>` be taken on the line so that :g:`PO <[ P O ]>` = :g:`OP' <[ O P' ]>`, :g:`QO <[ Q O ]>` = :g:`OQ' <[ O Q' ]>`, RO = :g:`OR' <[ O R' ]>`. Prove that :g:`AP' <[ A P' ]>`, :g:`BQ' <[ B Q' ]>`, :g:`CR' <[ C R' ]>` concur.

Notes
-----

.. container:: note-item

   Darij Grinberg introduces the term *Blaikie point of :g:`O <O>` and g* for the point :g:`Z <Z>` of concurrence. If

.. container:: note-item

   :g:`O <O>` =\ :math:`x : y : z` and g = [:math:`k : l : m`] (barycentric coordinates),

   then Z has first barycentric 1/[k(y-z) - (ly-mz)]. Given a point S =\ :math:`u : v : w`, Grinberg then defines the *S-Blaikie transform of :g:`O* <O*>` as the Blaikie point of :g:`O <O>` and OS. The first barycentric of Z can be written as

      1/[yw(y+x) + zv(z+x) - yz(2u+v+w)].

.. container:: note-item

   Seet `Blaikie theorem in barycentrics. <http://mathforum.org/epigone/geometry-college/glexzhuntwyr>`__ (Darij Grinberg, 12/28/02)
