.. enunciation::

The lines :g:`AA″ <[ A A″ ]>`, :g:`BB″ <[ B B″ ]>`, :g:`CC″ <[ C C″ ]>` concur in :ref:`X(31) <X(31)>`. (:person:`Randy Hutson <randy-hutson>`, February 10, 2016)
