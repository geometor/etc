X_1140
======

.. rubric:: INNER PENTAGON POINT

.. enunciation::

   Let :g:`A' <A'>` be the innermost vertex of the regular pentagon erected inward on side :g:`BC <[ B C ]>` of :g:`ABC << A B C >>`. Define :g:`B' <B'>` and :g:`C' <C'>` cyclically. Then triangle :g:`A'B'C' << A' B' C' >>` is perspective to :g:`ABC << A B C >>`, and the perspector is :ref:`X_1140 <X_1140>`. See references at :ref:`X_1140 <X_1140>`.
