X_1131
======

.. rubric:: ARCTAN(2) KIEPERT POINT

.. enunciation::

   To construct the Vecten point, :ref:`X_485 <X_485>`, squares are erected outward on the sides of :g:`ABC << A B C >>`. If :g:`A' <A'>`, :g:`B' <B'>`, :g:`C' <C'>` are the centers of these squares, then triangle :g:`A'B'C' << A' B' C' >>` is perspective to :g:`ABC << A B C >>` with perspector :ref:`X_485 <X_485>`. Now let :g:`A″ <A″>` be the midpoint of the side of the A-square that does not touch line :g:`BC <[ B C ]>`, and define :g:`B″ <B″>` and :g:`C″ <C″>` cyclically. Then triangle :g:`A″B″C″ << A″ B″ C″ >>` is perspective to :g:`ABC << A B C >>` with perspector :ref:`X_1131 <X_1131>`. Angle(:g:`A″BC << A″ B C >>`) = angle(:g:`B″CA << B″ C A >>`) = angle(:g:`C″AB << C″ A B >>`), so that :ref:`X_1131 <X_1131>` lies on the Kiepert hyperbola. Here, the common angle is arctan(2). (:person:`Darij Grinberg <darij-grinberg>` 9/22/02)
