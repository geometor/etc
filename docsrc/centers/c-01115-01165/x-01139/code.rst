X_1139
======

.. rubric:: OUTER PENTAGON POINT

.. enunciation::

   Let :g:`A' <A'>` be the outermost vertex of the regular pentagon erected outward on side :g:`BC <[ B C ]>` of :g:`ABC << A B C >>`. Define :g:`B' <B'>` and :g:`C' <C'>` cyclically. Then triangle :g:`A'B'C' << A' B' C' >>` is perspective to :g:`ABC << A B C >>`, and the perspector is :ref:`X_1139 <X_1139>`. (Steve Sigur and :person:`Antreas Hatzipolakis <antreas-hatzipolakis>`, #5246, 12/31/02; generalizations to n-gons, for odd n, by Milorad R. Stevanovic, #5253, 5256)
