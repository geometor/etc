.. rubric:: 2nd HATZIPOLAKIS PERSPECTOR

.. enunciation::

   Let triangle :g:`A_{0}B_{0}C_{0} << A_0 B_0 C_0 >>` be as defined for :ref:`X_1118 <X_1118>`. Let :g:`A_{1} <A_1>` be the orthogonal projection of :g:`A_{0} <A_0>` onto line :g:`BC <[ B C ]>`, and define :g:`B_{1} <B_1>` and :g:`C_{1} <C_1>` cyclically. Then triangle :g:`A_{1}B_{1}C_{1} << A_1 B_1 C_1 >>` is perspective to :g:`ABC << A B C >>`, and the perspector is :ref:`X_1119 <X_1119>`. (:person:`Antreas Hatzipolakis <antreas-hatzipolakis>`, #5321, 4/30/02)
