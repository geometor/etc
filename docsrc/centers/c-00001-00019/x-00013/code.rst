X_13
====

.. rubric:: 1st ISOGONIC CENTER (FERMAT POINT, TORRICELLI POINT)

.. enunciation::

   Construct the equilateral triangle :g:`BA'C << B A' C >>` having base :g:`BC <[ B C ]>` and vertex :g:`A' <A'>` on the negative side of :g:`BC <[ B C ]>`; similarly construct equilateral triangles :g:`CB'A << C B' A >>` and :g:`AC'B << A C' B >>` based on the other two sides. The lines :g:`AA' <[ A A' ]>`, :g:`BB' <[ B B' ]>`, :g:`CC' <[ C C' ]>` concur in :ref:`X_13 <X_13>`. If each of the angles :g:`A <A>`, :g:`B <B>`, :g:`C <C>` is < 2π/3, then :ref:`X_13 <X_13>` is the only center X for which the angles :g:`BXC << B X C >>`, :g:`CXA << C X A >>`, :g:`AXB << A X B >>` are equal, and :ref:`X_13 <X_13>` minimizes the sum \|\ :g:`AX <[ A X ]>`\ \| + \|\ :g:`BX <[ B X ]>`\ \| + \|\ :g:`CX <[ C X ]>`\ \|. The :term:`antipedal triangle <antipedal-triangle>` of :ref:`X_13 <X_13>` is equilateral.
