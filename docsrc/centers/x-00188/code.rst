X(188) = 2nd MID-ARC POINT OF ANTICOMPLEMENTARY TRIANGLE — Code
===============================================================

.. enunciation::

   Let :g:`A'B'C' << A' B' C' >>` be the :term:`excentral triangle <excentral-triangle>` of :g:`ABC << A B C >>`, so that :g:`A' <A'>` = :math:`-1 : 1 : 1` (trilinears). Let :g:`A″ <A″>` be the point where the bisector of angle :g:`BA'C << B A' C >>` meets the line :g:`BC <[ B C ]>`. Define :g:`B″ <B″>` and :g:`C″ <C″>` cyclically. The lines :g:`AA″ <[ A A″ ]>`, :g:`BB″ <[ B B″ ]>`, :g:`CC″ <[ C C″ ]>` concur in :ref:`X(188) <X(188)>`. (Seiichi Kirikami, February 14, 2010)
