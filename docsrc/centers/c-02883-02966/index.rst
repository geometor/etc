.. admonition:: Group Preamble — Isogonal Conjugates wrt Special Triangles (Isogonal Conjugates with respect to Special Triangles)
   :class: note

   Suppose :g:`A'B'C' << A' B' C' >>` is the :term:`medial triangle <medial-triangle>` of :g:`ABC << A B C >>` and X is a triangle center wrt :g:`ABC << A B C >>`. Let :g:`X' <X'>` be the isogonal conjugate of :g:`X <X>` wrt :g:`A'B'C' << A' B' C' >>`. Then :g:`X' <X'>` is a triangle center wrt :g:`ABC << A B C >>`. In order to determine its center function g, the method of :cite:`TCCT <tcct>`, p. 207 applies. Write :g:`X <X>` =\ :math:`x : y : z` (wrt :g:`ABC << A B C >>`). Then trilinears of :g:`X <X>` wrt :g:`A'B'C' << A' B' C' >>` are

   (- ax + by + cz)/a : (ax - by + cz)/b : (ax + by - cz)/c,

   so that the isogonal conjugate of :g:`X <X>` wrt :g:`A'B'C' << A' B' C' >>` is

   a/(- ax + by + cz) : b/(ax - by + cz) : c/(ax + by - cz),

   which, in trilinears wrt :g:`ABC << A B C >>`, is :math:`g(a,b,c,x,y,z) : g(b,c,a,y,z,x) : g(c,a,b,z,x,y)`, where

   :math:`g(a,b,c,x,y,z) = bc(ax - by - cz)[b^{2}(ax + by - cz) + c^{2}(ax - by + cz)]`

   This point is the isogonal conjugate of :g:`X <X>` wrt the medial triangle, or, more simply, the medial isogonal conjugate of X. In like manner, other conjugates of :g:`X <X>` wrt other triangles are defined. In this section, only isogonal conjugates are considered, and trilinears wrt to selected triangles are given by first trilinear wrt :g:`ABC << A B C >>`, as follows:

   | MEDIAL ISOGONAL CONJUGATE OF :g:`X <X>` =\ :math:`x : y : z`
   | bc(ax - by - cz)[:math:`b^{2}(ax + by - cz)` + :math:`c^{2}(ax - by + cz)`]

   | ANTICOMPLEMENTARY ISOGONAL CONJUGATE OF :g:`X <X>` =\ :math:`x : y : z`
   | bc[- :math:`a^{2}`/(by + cz) + :math:`b^{2}`/(cz + ax) + :math:`c^{2}`/(ax + by)]

   | ORTHIC-ISOGONAL CONJUGATE OF :g:`X <X>` =\ :math:`x : y : z`
   | x(x cos A - y cos B - z cos C)

   | TANGENTIAL-ISOGONAL CONJUGATE OF :g:`X <X>` =\ :math:`x : y : z`
   | a[- :math:`a^{3}`/(cy + bz) + :math:`b^{3}`/(az + cx) + :math:`c^{3}`/(bx + ay)]

   EXCENTRAL-ISOGONAL CONJUGATE OF :g:`X <X>` =\ :math:`x : y : z`

   - a/[(b + c - a)(y + z)] + b/[(c + a - b)(z + x)] + c/[(a + b - c)(x + y)]

   In each of the above cases,\ :math:`x : y : z`, as a triangle center, is given by trilinears :math:`h(a,b,c) : h(b,c,a) : h(c,a,b)` for some function h. Accordingly, each of the first trilinears given above defines a triangle center :math:`f(a,b,c) : f(b,c,a) : f(c,a,b)`.

   The term ":term:`complementary conjugate <complementary-conjugate>`" already in use at the time of this writing (11/25/04) is a synonym for "medial isogonal conjugate", as is ":term:`anticomplementary conjugate <anticomplementary-conjugate>`" for "anticomplementary isogonal conjugate"; accordingly, the earlier terms will be used in the sequel. Also, "excentral isogonal conjugate" is ":ref:`X_188 <X_188>`-:term:`aleph conjugate <aleph-conjugate>`" and "orthic isogonal conjugate" is ":ref:`X_4 <X_4>`-:term:`Ceva conjugate <ceva-conjugate>`"; in these cases, the new terminology will be used.

   The subject of isogonal conjugation with respect to a :term:`central triangle <central-triangle>` continues at the preamble just before X_6000.
