X(600) = 3rd HATZIPOLAKIS-YIU POINT — Code
==========================================

.. enunciation::

   Let :g:`O_{A} <O_A>` be the circle with center A and radius R, the circumradius of triangle :g:`ABC << A B C >>`. Let :g:`B_{A} <B_A>` be the point where :g:`O_{A} <O_A>` meets line :g:`AB <[ A B ]>` farthest from B. Define :g:`C_{B} <C_B>` and :g:`A_{C} <A_C>` cyclically. Let :g:`C_{A} <C_A>` be the point where :g:`O_{A} <O_A>` meets line :g:`AC <[ A C ]>` farthest from C. Define :g:`A_{B} <A_B>` and :g:`B_{C} <B_C>` cyclically. :ref:`X(600) <X(600)>` is the radical center of the circles :g:`AB_{A}C_{A} << A B_A C_A >>`, :g:`BC_{B}A_{B} << B C_B A_B >>`, :g:`CA_{C}B_{C} << C A_C B_C >>`. If "farthest from" is changed to "nearest to" in the construction, the resulting point is X(5507). (:person:`Antreas Hatzipolakis <antreas-hatzipolakis>`, :person:`Paul Yiu <paul-yiu>`, 1/5/01, :cite:`Hyacinthos #2344 <hyacinthos>`, #2346-8; for a correction in coordinates, see Paul Yiu, Adgeom #202.)
