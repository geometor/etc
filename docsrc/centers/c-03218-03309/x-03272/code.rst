.. rubric:: CENTER OF EQUILATERAL TRIANGLE J1J2J3

.. enunciation::

   Let :g:`A_{1}B_{1}C_{1} << A_1 B_1 C_1 >>`, :g:`A_{2}B_{2}C_{2} << A_2 B_2 C_2 >>`, :g:`A_{3}B_{3}C_{3} << A_3 B_3 C_3 >>` be the 1st Morley, 2nd Morley and 3rd Morley triangles of :g:`ABC << A B C >>`, respectively. Then {A, :g:`A_{1} <A_1>`, :g:`A_{2} <A_2>`, :g:`A_{3} <A_3>`} are concyclic on a circle, A0.
