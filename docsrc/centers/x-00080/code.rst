X(80) = REFLECTION OF INCENTER IN FEUERBACH POINT — Code
========================================================

.. enunciation::

   Let :g:`A' <A'>` be the reflection in :g:`BC <[ B C ]>` of the :g:`A <A>`-vertex of the :term:`excentral triangle <excentral-triangle>`, and define :g:`B' <B'>` and :g:`C' <C'>` cyclically. The circumcircles of :g:`A'BC << A' B C >>`, :g:`B'CA << B' C A >>`, and :g:`C'AB << C' A B >>` concur in :ref:`X(80) <X(80)>`. Also, the lines :g:`AA' <[ A A' ]>`, :g:`BB' <[ B B' ]>`, :g:`CC' <[ C C' ]>` concur in :ref:`X(80) <X(80)>`. (:person:`Randy Hutson <randy-hutson>`, December 10, 2016)
