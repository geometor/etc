X_400
=====

.. rubric:: YFF-MALFATTI POINT

.. enunciation::

   In 1997, Yff considered the configuration for the 1st Ajima-Malfatti point, :ref:`X_179 <X_179>`. He proved that the same tangencies are possible in another way if the circles are not required to lie inside :g:`ABC << A B C >>`. With tangency points labeled as before, the lines :g:`AA' <[ A A' ]>`, :g:`BB' <[ B B' ]>`, :g:`CC' <[ C C' ]>` concur in :ref:`X_400 <X_400>`.
