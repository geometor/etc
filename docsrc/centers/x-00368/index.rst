X(368) = EQUI-BROCARD CENTER
============================

.. enunciation::

   The center X for which the triangle :g:`XBC << X B C >>`, :g:`XCA << X C A >>`, :g:`XAB << X A B >>` have equal Brocard angles. :person:`Peter Yff <peter-yff>` proved that :ref:`X(368) <X(368)>` lies on the self-:term:`isogonal conjugate <isogonal-conjugate>` cubic with trilinear equation f(a,b,c)u + f(b,c,a)v + f(c,a,b)w = 0, where :math:`f(a,b,c) = bc(b^{2} - c^{2})` and, for variable :math:`x : y : z`, the cubics u, v, w are given by u(x,y,z) = :math:`x(y^{2}` + :math:`z^{2})`, v = u(y,z,x), w = u(z,x,y).
