.. enunciation::

The isogonal (and isotomic) conjugate of :ref:`X_2 <X_2>` wrt :g:`A'B'C' << A' B' C' >>` is :ref:`X_531 <X_531>`. (:person:`Randy Hutson <randy-hutson>`, February 10, 2016)
