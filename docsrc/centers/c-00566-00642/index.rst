.. _preamble-0014:

.. admonition:: Group Preamble — Centers X_566-X_584
   :class: note

   Centers :ref:`X_566 <X_566>`-:ref:`X_584 <X_584>` lie on the Brocard axis, L(3,6). Each is the center X of a circle that meets the sides of triangle :g:`ABC << A B C >>` with three equal angles at :g:`X <X>`.

   Let :g:`A_{B} <A_B>`, :g:`A_{C} <A_C>`, :g:`B_{C} <B_C>`, :g:`B_{A} <B_A>`, :g:`C_{A} <C_A>`, :g:`C_{B} <C_B>` denote the meeting-points; e.g., :g:`A_{B} <A_B>` and :g:`C_{B} <C_B>` are on side :g:`CA <[ C A ]>`. The equal angles are given by

   :g:`D <D>` = angle(:g:`A_{B}XA_{C} << A_B X A_C >>`) = angle(:g:`B_{C}XB_{A} << B_C X B_A >>`) = angle(:g:`C_{A}XC_{B)} << C_A X C_B) >>`

   Then trilinears for :g:`X <X>` are given by

   :g:`X <X>` = sin A + cot D/2 cos A : sin B + cot D/2 cos B : sin C + cot D/2 cos C.

   Definitions: Y is the **orthogonal** of X if D(X) + D(Y) = π/2;

   Y is the **harmonic** of X if X and Y are harmonic conjugates with respect to :ref:`X_3 <X_3>` and :ref:`X_6 <X_6>`;

   Y is the **orthoharmonic** if Y is the harmonic of the orthogonal of X. The centers in this section were contributed by Edward Brisse, December, 2000.

.. admonition:: Group Preamble — Centers X_616-X_642
   :class: note

   Centers :ref:`X_616 <X_616>`-:ref:`X_642 <X_642>` were contributed by Bernard Gibert, March 2, 2001. Notation:

   :math:`S_{A}` = (:math:`b^{2}` + :math:`c^{2}` - :math:`a^{2})`/2 :math:`S_{B}` = (:math:`c^{2}` + :math:`a^{2}` - :math:`b^{2})`/2 :math:`S_{C}` = (:math:`a^{2}` + :math:`b^{2}` - :math:`c^{2})`/2

   Joe Goggins (Oct. 19, 2005) found trilinears for points in this section, using the following notation. Let

   | :math:`F(13) = a \csc(A + \pi /3) + b \csc(B + \pi /3) + c \csc(C + \pi /3)`
   | :math:`F(14) = a \csc(A - \pi /3) + b \csc(B - \pi /3) + c \csc(C - \pi /3)`
   | These are based on trilinears for the isogonic centers, :ref:`X_13 <X_13>` and :ref:`X_14 <X_14>`. In like manner, F(i) is defined for i = 15, 16, 17, 18, 61, 62.

   | Using this notation, we have, for example,
   | :ref:`X_616 <X_616>` = F(13)/a - 2 csc(A + π/3) : F(13)/b - 2 csc(B + π/3) : F(13)/c - 2 csc(C + π/3)
   | :ref:`X_617 <X_617>` = F(14)/a - 2 csc(A - π/3) : F(14)/b - 2 csc(B - π/3) : F(14)/c - 2 csc(C - π/3)

   Trilinears of this sort are given below at X_i for these i: 616-619, 621-624, 627-630, and 633-636.
