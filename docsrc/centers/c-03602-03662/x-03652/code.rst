X_3652
======

.. rubric:: KS(CARNOT TRIANGLE)

.. enunciation::

   Quim Castellsaguer defines the `Carnot triangle <http://www.xtec.es/~qcastell/ttw/ttweng/definicions/d_Carnot_tr.html>`__ as the triangle formed by the circumcenters of the triangles :g:`BCH << B C X_4 >>`, :g:`CAH << C A X_4 >>`, :g:`ABH << A B X_4 >>`, where H denotes the orthocenter. The Carnot triangle is also known as the Johnson triangle.
