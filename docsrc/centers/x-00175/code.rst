X_175
=====

.. rubric:: ISOPERIMETRIC POINT

.. enunciation::

   A point :g:`X <X>` is defined as an isoperimetric point of triangle :g:`ABC << A B C >>` if \|\ :g:`XB <[ X B ]>`\ \| + \|\ :g:`XC <[ X C ]>`\ \| + \|\ :g:`BC <[ B C ]>`\ \| = \|\ :g:`XC <[ X C ]>`\ \| + \|\ :g:`XA <[ X A ]>`\ \| + \|\ :g:`CA <[ C A ]>`\ \| = \|\ :g:`XA <[ X A ]>`\ \| + \|\ :g:`XB <[ X B ]>`\ \| + \|\ :g:`AB <[ A B ]>`\ \|. Veldkamp established that :g:`X <X>` = :ref:`X_175 <X_175>`, uniquely, for some triangles :g:`ABC << A B C >>`, but the conditions he gives are not correct. Hajja and Yff proved that the condition tan(A/2) + tan(B/2) + tan(C/2) < 2 is necessary and sufficient. See also :ref:`X_176 <X_176>` and the 1st and 2nd Eppstein points, :ref:`X_481 <X_481>`, :ref:`X_482 <X_482>`.
