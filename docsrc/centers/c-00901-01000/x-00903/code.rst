X_903
=====

.. rubric:: X_1-BLAIKIE TRANSFORM OF X_2

.. enunciation::

   James Blaikie (1847-1929) proposed the following problem. Let :g:`O <O>` be any point in the plane of triangle :g:`ABC << A B C >>`, and let any straight line g through O meet :g:`BC <[ B C ]>` in :g:`P <P>`, :g:`CA <[ C A ]>` in :g:`Q <Q>`, :g:`AB <[ A B ]>` in R; then, if points :g:`P' <P'>`, :g:`Q' <Q'>`, :g:`R' <R'>` be taken on the line so that :g:`PO <[ P O ]>` = :g:`OP' <[ O P' ]>`, :g:`QO <[ Q O ]>` = :g:`OQ' <[ O Q' ]>`, RO = :g:`OR' <[ O R' ]>`. Prove that :g:`AP' <[ A P' ]>`, :g:`BQ' <[ B Q' ]>`, :g:`CR' <[ C R' ]>` concur.
