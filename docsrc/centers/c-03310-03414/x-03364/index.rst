X_3364
======

.. rubric:: COS(A - 5π/12) POINT

.. enunciation::

   :ref:`X_3364 <X_3364>` and related points occupy :person:`Bernard Gibert <bernard-gibert>`'s Table 38 concerning these three loci: Brocard axis, Kiepert hyperbola, and the cubic K457. Trilinear equations for these curves, of degrees 1,2,3, respectively, in the variables a,b,c, are given as follows:

   Curve Trilinears Brocard axis :math:`\cos(A + t) : \cos(B + t) : \cos(C + t)` Kiepert hyperbola :math:`\sec(A + t) : \sec(B + t) : \sec(C + t)` K457 :math:`\tan(A + t) : \tan(B + t) : \tan(C + t)`
