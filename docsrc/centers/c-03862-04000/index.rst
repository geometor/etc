.. admonition:: Group Preamble — Inverse Triangles and More Combos
   :class: note

   The Euler triangle and the 2nd, 3rd, 4th, and 5th Euler triangles are discussed in the preamble to :ref:`X_3758 <X_3758>`, along with eight other central triangles using the notation T(f(a,b,c), g(b,c,a)). Recall that the inverse of a normalized central triangle :g:`T <T>`, denoted by Inverse(nT) or Inverse(n(T)), is also a normalized central triangle. Barycentrics for the inverse of each of the 13 triangles and properties of these triangles are given (:person:`Peter Moses <peter-moses>`, December 2011) as follows:

   | **Inverse(n(Euler triangle))** = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = (b^{2} - c^{2})^{2} + a^{2}(3a^{2} - 4b^{2} - 4c^{2})`
   | :math:`g(b,c,a) = b^{4} - (c^{2} - a^{2})^{2}`

   | **Inverse(n(2nd Euler triangle))** = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = a^{2}(a^{2} - b^{2} - c^{2})(a^{6} + b^{6} + c^{6} - a^{4}b^{2} - a^{4}c^{2} - a^{2}b^{4} - a^{2}c^{4} - 2a^{2}b^{2}c^{2} - b^{4}c^{2} - b^{2}c^{4})`
   | :math:`g(b,c,a) = b^{2}(b^{2} - c^{2} - a^{2}(a^{6} + b^{6} - c^{6} - a^{4}b^{2} - 3a^{4}c^{2} - a^{2}b^{4} + 3a^{2}c^{4} + 2a^{2}b^{2}c^{2} - 3b^{4}c^{2} + 3b^{2}c^{4})`

   | **Inverse(n(3rd Euler triangle))** = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = a(b^{2} + c^{2} - ab - ac + bc)`
   | :math:`g(b,c,a) = b(a^{2} - ab - ac + bc - c^{2})`

   | **Inverse(n(4th Euler triangle))** = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = a(a - b - c)(b^{2} + c^{2} + ab + ac)`
   | :math:`g(b,c,a) = b(-a + b + c)(a^{2} + ab - ac - bc - c^{2})`

   | **Inverse(n(5th Euler triangle))** = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = (a^{2} - 2b^{2} - 2c^{2})(3a^{2} + b^{2} + c^{2})`
   | :math:`g(b,c,a) = -(a^{2} - b^{2} - c^{2})(2a^{2} - b^{2} + 2c^{2})`

   | Inverse(n(T(bc,\ :math:`b^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = -bc(a^{2} - bc)(b^{2} + c^{2} + bc)`
   | :math:`g(b,c,a) = b^{2}(ab - c^{2})(a^{2} + c^{2} + ac)`

   | Inverse(n(T(-bc,\ :math:`b^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = bc(a^{2} - bc)(b^{2} + c^{2} - bc)`
   | :math:`g(b,c,a) = b^{2}(ab + c^{2})(a^{2} + c^{2} - ac)`

   | Inverse(n(T(bc,\ :math:`c^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = -a(a^{2} - bc)(b^{2} + c^{2} + bc)`
   | :math:`g(b,c,a) = (ab - c^{2})(a^{2} + c^{2} + ac)`

   | Inverse(n(T(-bc,\ :math:`c^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = -a(a^{2} - bc)(b^{2} + c^{2} - bc)`
   | :math:`g(b,c,a) = (ab + c^{2})(a^{2} + c^{2} - ac)`

   | Inverse(n(:math:`T(a^{2}`,\ :math:`a^{2}` - :math:`b^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = (3a^{2} - b^{2} - c^{2})(b^{4} + c^{4} - b^{2}c^{2})`
   | :math:`g(b,c,a) = (a^{2} - 3b^{2} + c^{2})(a^{2}b^{2} - 2b^{2}c^{2} + c^{4})`

   | Inverse(n(:math:`T(a^{2}`,\ :math:`a^{2}` - :math:`c^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = a^{2}(b^{2} + c^{2} - 3a^{2})`
   | :math:`g(b,c,a) =(a^{2} - c^{2})(a^{2} - 3b^{2} + c^{2})`

   | Inverse(n(:math:`T(a^{2}`,\ :math:`a^{2}` + :math:`b^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = -(3a^{2} + b^{2} + c^{2})(b^{4} + c^{4} + b^{2}c^{2})`
   | :math:`g(b,c,a) = (a^{2} + 3b^{2} + c^{2})(a^{2}b^{2} + c^{4})`

   | Inverse(n(:math:`T(a^{2}`,\ :math:`a^{2}` + :math:`c^{2})`) = T(f(a,b,c), g(b,c,a)), where
   | :math:`f(a,b,c) = -a^{2}(a^{2} + b^{2} + c^{2})(3a^{2} + b^{2} + c^{2})`
   | :math:`g(b,c,a) = (a^{2} + c^{2})(a^{2} + b^{2} - c^{2})(a^{2} + 3b^{2} + c^{2})`

   For present purposes, label these last triangles as :g:`IT_{1} <[ I T_1 ]>`, :g:`IT_{2} <[ I T_2 ]>`, :g:`IT_{3} <[ I T_3 ]>`, :g:`IT_{4} <[ I T_4 ]>`, :g:`IT_{5} <[ I T_5 ]>`, :g:`IT_{6} <[ I T_6 ]>`, :g:`IT_{7} <[ I T_7 ]>`, :g:`IT_{8} <[ I T_8 ]>`; then all except :g:`IT_{5} <[ I T_5 ]>` and :g:`IT_{6} <[ I T_6 ]>` are perspective to the reference triangle :g:`ABC << A B C >>`; perspectors are described at :ref:`X_3862 <X_3862>`-:ref:`X_3866 <X_3866>`. Label the corresponding original triangles :g:`T_{1} <T_1>`, :g:`T_{2} <T_2>`, :g:`T_{3} <T_3>`, :g:`T_{4} <T_4>`, :g:`T_{5} <T_5>`, :g:`T_{6} <T_6>`, :g:`T_{7} <T_7>`, :g:`T_{8} <T_8>`; then the following pairs are perspective: (:g:`T_{1} <T_1>`, :g:`IT_{1} <[ I T_1 ]>`), (:g:`T_{2} <T_2>`, :g:`IT_{2} <[ I T_2 ]>`), (:g:`T_{3} <T_3>`,\ :g:`IT_{3} <[ I T_3 ]>`), (:g:`T_{4} <T_4>`, :g:`IT_{4} <[ I T_4 ]>`), (:g:`T_{7} <T_7>`, :g:`IT_{7} <[ I T_7 ]>`), (:g:`T_{8} <T_8>`,\ :g:`IT_{8} <[ I T_8 ]>`); coordinates for the perspectors are long and omitted.

   The triangles :g:`IT_{1} <[ I T_1 ]>` and :g:`IT_{2} <[ I T_2 ]>` are triply perspective to :g:`ABC << A B C >>` (as are :g:`T_{1} <T_1>` and :g:`T_{3} <T_3>`). Order-label :g:`IT_{1} <[ I T_1 ]>` as :g:`A'B'C' << A' B' C' >>`. The three perspectivities are then given by

   | :g:`AA' <[ A A' ]>`\ ∩\ :g:`BB' <[ B B' ]>`\ ∩\ :g:`CC' <[ C C' ]>` = :ref:`X_3862 <X_3862>`
   | :g:`AB' <[ A B' ]>`\ ∩\ :g:`BC' <[ B C' ]>`\ ∩\ :g:`CA' <[ C A' ]>` =\ :math:`f(a,b,c) : f(b,c,a) : f(c,a,b)`, where :math:`f(a,b,c) = ab(a^{2} - bc)(c^{2} - ab)(b^{2} + bc + c^{2})`
   | :g:`AC' <[ A C' ]>`\ ∩\ :g:`BA' <[ B A' ]>`\ ∩\ :g:`CB' <[ C B' ]>` =\ :math:`f(a,c,b) : f(b,a,c) : f(c,b,a)`

   Note that the second two perspectors are a bicentric pair (not :term:`triangle centers <triangle-center>`; see :cite:`TCCT <tcct>`, page 47); likewise for the other triple perspectivity, with :g:`IT_{3} <[ I T_3 ]>` order-labeled as :g:`A'B'C' << A' B' C' >>`:

   | :g:`AA' <[ A A' ]>`\ ∩\ :g:`BB' <[ B B' ]>`\ ∩\ :g:`CC' <[ C C' ]>` = :ref:`X_3864 <X_3864>`
   | :g:`AB' <[ A B' ]>`\ ∩\ :g:`BC' <[ B C' ]>`\ ∩\ :g:`CA' <[ C A' ]>` =\ :math:`g(a,b,c) : g(b,c,a) : g(c,a,b)`, where :math:`g(a,b,c) = a(a^{2} - bc)(c^{2} - ab)(b^{2} + bc + c^{2})`
   | :g:`AC' <[ A C' ]>`\ ∩\ :g:`BA' <[ B A' ]>`\ ∩\ :g:`CB' <[ C B' ]>` =\ :math:`g(a,c,b) : g(b,a,c) : g(c,b,a)`
