X_39
====

.. rubric:: BROCARD MIDPOINT

.. enunciation::

   :ref:`X_39 <X_39>` is the midpoint of the 1st and 2nd Brocard points, given by trilinears :math:`c/b : a/c : b/a` and :math:`b/c : c/a : a/b`. The third and fourth trilinear representations were given by Peter J. C. Moses (10/3/03); cf. :ref:`X_511 <X_511>`, :ref:`X_32 <X_32>`, :ref:`X_182 <X_182>`.
