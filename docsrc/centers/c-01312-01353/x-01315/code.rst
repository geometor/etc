X_1315
======

.. rubric:: 4th MOSES INTERSECTION

.. enunciation::

   :ref:`X_1315 <X_1315>` is a point of intersection of the Euler line and the incircle. For some obtuse triangles, this point is not in the real plane (specifically, for those a,b,c such that Q < 0).
