.. rubric:: 2nd WERNAU POINT

.. enunciation::

   Let :g:`A'BC << A' B C >>` be the internal equilateral triangle on side :g:`BC <[ B C ]>`, and define :g:`CB'A << C B' A >>` and :g:`AC'B << A C' B >>` cyclically. Let (:g:`AB'C' << A B' C' >>`) be the circle passing through the points :g:`A <A>`, :g:`B' <B'>`, :g:`C' <C'>`, and define (:g:`BC'A' << B C' A' >>`) and (:g:`CA'B' << C A' B' >>`) cyclically. The three circles concur in :ref:`X_1338 <X_1338>`. For details, see :ref:`X_1337 <X_1337>`.
