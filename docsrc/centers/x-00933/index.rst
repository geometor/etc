.. container:: note-item

   Let :g:`P <P>` be a point on the circumcircle, and let

   (Oab) = circle through :g:`A <A>` tangent to line :g:`BC <[ B C ]>` at B

   (Oac) = circle through :g:`A <A>` tangent to line :g:`BC <[ B C ]>` at C

   :g:`B_{a} <B_a>` = point other than A where the line :g:`PB <[ P B ]>` meets (Oab)

   :g:`C_{a} <C_a>` = point other than A where the line :g:`PC <[ P C ]>` meets (Oac)

   Hab = orthocenter of APBa

   Hac = orthocenter of APCa

.. container:: note-item

   Define Hbc and Hca cyclically, and define Hba and Hcb cyclically. The points Hab, Hac, Hbc, Hba, Hca, Hcb lies on a hyperbola with center = midpoint(P and H), where H = :ref:`X(4) <X(4)>`, the orthocenter. This hyperbola is rectangular if and only if :g:`P <P>` = :ref:`X(933) <X(933)>`. This note is related to a problem posed in `2017 Olympiad of Rusanovsky Lyceum in Kyiv, Ukraine , IX-X Team p9 <https://artofproblemsolving.com/community/c6t48f6h2603674_collinear_orthocenters_wanted>`__. For details, see `El centro X(933) y una hipérbola rectangular <https://amontes.webs.ull.es/otrashtm/HGT2021.htm#HG300621>`__. (:person:`Angel Montesdeoca <angel-montesdeoca>`, July 3, 2021)
