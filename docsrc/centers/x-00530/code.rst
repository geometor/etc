X(530) = DIRECTION OF VECTOR AX + BX + CX, where X = X(13) — Code
=================================================================

.. enunciation::

   Let :g:`A' <A'>` be the nine-point center of :g:`BC <[ B C ]>`\ :ref:`X(14) <X(14)>`, and define :g:`B' <B'>` and :g:`C' <C'>` cyclically. :g:`A'B'C' << A' B' C' >>` is an equilateral triangle concyclic with :ref:`X(2) <X(2)>` and :ref:`X(14) <X(14)>` (inscribed in the 2nd Hutson circle). The isogonal (and isotomic) conjugate of :ref:`X(2) <X(2)>` wrt :g:`A'B'C' << A' B' C' >>` is :ref:`X(530) <X(530)>`. (:person:`Randy Hutson <randy-hutson>`, February 10, 2016)
