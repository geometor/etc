geometor.etc.triangles
======================

.. py:module:: geometor.etc.triangles

.. autoapi-nested-parse::

   Exact symbolic reference triangles for the Encyclopedia of Triangle Centers.

   Defines the four canonical exact symbolic reference triangles over closed-form
   algebraic number fields in SymPy:

   1. ``heronian`` — Acute Heronian :math:`(15, 13, 14)` over :math:`\mathbb{Q}`
   2. ``right`` — Pythagorean Right :math:`(3, 4, 5)` over :math:`\mathbb{Q}`
   3. ``kepler`` — Kepler Golden Right :math:`(1, \sqrt{\phi}, \phi)` over :math:`\mathbb{Q}(\sqrt{\phi})`
   4. ``kimberling`` — Kimberling Search :math:`(6, 9, 13)` over :math:`\mathbb{Q}(\sqrt{35})`

.. py:class:: SymbolicTriangle

   Exact symbolic reference triangle with side lengths, vertices, and invariants.

   :param key: Preset identifier (``"heronian"``, ``"right"``, ``"kepler"``, ``"kimberling"``,
               or ``"acute"``).
   :param label: Short human-readable title (e.g. ``"Heronian (15, 13, 14)"``).
   :param field_latex: LaTeX string naming the ambient algebraic field (e.g. ``r"\mathbb{Q}"``).
   :param a: Exact side lengths :math:`a = |BC|`, :math:`b = |CA|`, :math:`c = |AB|`.
   :param b: Exact side lengths :math:`a = |BC|`, :math:`b = |CA|`, :math:`c = |AB|`.
   :param c: Exact side lengths :math:`a = |BC|`, :math:`b = |CA|`, :math:`c = |AB|`.
   :param A_xy: Exact Cartesian coordinates of vertices :math:`A`, :math:`B`, :math:`C`.
   :param B_xy: Exact Cartesian coordinates of vertices :math:`A`, :math:`B`, :math:`C`.
   :param C_xy: Exact Cartesian coordinates of vertices :math:`A`, :math:`B`, :math:`C`.
   :param area: Exact area :math:`\Delta = \operatorname{Area}(\triangle ABC)`.
   :param simplify_fn: Field-aware exact simplification callable.

.. py:function:: build_symbolic_triangle_from_sides(a: sympy.Expr | float, b: sympy.Expr | float, c: sympy.Expr | float, *, key: str = 'custom', label: str | None = None, unit_baseline: bool = False) -> SymbolicTriangle

   Construct an exact :class:`SymbolicTriangle` from three side lengths.

   Any Python ``float`` inputs representing exact rationals (such as ``5.0``) are
   coerced via :func:`sympy.nsimplify` so zero ``sp.Float`` atoms enter symbolic
   computations.
