.. _preamble-0025:

.. admonition:: Group Preamble — Mimosa Transforms 1707-1788
   :class: note

   The Mimosa transform M(X) of a point :g:`X <X>` =\ :math:`x : y : z` is defined (9/15/03) by

   M(X) = - yz cos A + zx cos B + xy cos C : - zx cos B + xy cos C + yz cos A : - xy cos C + yz cos A + xy cos C

   and the inverse Mimosa transform :math:`M ^{-1}(X)`, by

   :math:`M ^{-1}(X)` = (cos A)/(y + z) : (cos B)/(z + x) : (cos C)/(x + y).

   As with other names in ETC, the name Mimosa is that of a star. M(X) is the :g:`X* <X*>`\ :ref:`X_4 <X_4>`-:term:`Ceva conjugate <ceva-conjugate>` of :ref:`X_1 <X_1>`, where \* denotes trilinear product, and :math:`M ^{-1}(X)` is the trilinear quotient :ref:`X_3 <X_3>`/P(X), where P(X) is the :term:`crosssum <crosssum>` of :ref:`X_1 <X_1>` and X.

   Let g(P,X) denote the P-:term:`gimel conjugate <gimel-conjugate>` of X. The Mimosa transform M(X) arises in connection with the equation :math:`g(P,X) = X`. Referring to the definition of gimel conjugate in the Glossary, if

   :g:`P <P>` =\ :math:`p : q : r` and :g:`X <X>` =\ :math:`x : y : z`

   are triangle centers, then the equation :math:`g(P,X) = X is equivalent to the ratio-equation`

   (2absvS - 8yσ\ :sup:`2`)/(2abswS - 8zσ\ :sup:`2`) = y/z,

   where v = (cos A)/p - (cos B)/q + (cos C)/r and w = (cos A)/p + (cos B)/q - (cos C)/r.

   If S = 0, then the ratio-equation holds. As S = x(bq + cr) + y(cr + ap) + z(ap + bq), it follows that if P is given, then :math:`g(P,X) = X if X is on the line S`\ = 0 (regarding :math:`x : y : z` as variable); and that if X is given, then :math:`g(P,X) = P if P is on the line S`\ = 0 (regarding :math:`p : q : r` as variable). There are too many such cases of gimel conjugates for all to be itemized in ETC. For example, if :g:`X <X>` = :ref:`X_1 <X_1>`, then :math:`g(P,X) = X` for every P on the line at infinity; if :g:`X <X>` = :ref:`X_513 <X_513>`, then :math:`g(P,X) = X` for every P on the line :ref:`X_1 <X_1>`\ \ :ref:`X_2 <X_2>`; and if :g:`X <X>` = :ref:`X_656 <X_656>`, then :math:`g(P,X) = X` for every P on the Euler line, :ref:`X_2 <X_2>`\ \ :ref:`X_3 <X_3>`.

   If S ≠ 0, the ratio-equation lends itself to easy simplifications and two **Tables** conclusions: (1) if P is given then :g:`X <X>` = M(P) is a solution of :math:`g(P,X) = X`, and (2) if X is given then :g:`P <P>` = :g:`M* <M*>`\ (X) is a solution of :math:`g(P,X) = X`.
