X(368) = EQUI-BROCARD CENTER — Code
===================================

.. enunciation::

   The center X for which the triangle XBC, XCA, XAB have equal Brocard angles. :person:`Peter Yff <peter-yff>` proved that :ref:`X(368) <X(368)>` lies on the self-:term:`isogonal conjugate <isogonal-conjugate>` cubic with trilinear equation f(a,b,c)u + f(b,c,a)v + f(c,a,b)w = 0, where f(a,b,c) = bc(b\ :sup:`2` - c\ :sup:`2`) and, for variable x : y : z, the cubics u, v, w are given by u(x,y,z) = x(y\ :sup:`2` + z\ :sup:`2`), v = u(y,z,x), w = u(z,x,y).
