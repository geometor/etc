X_3
====

.. rubric:: CIRCUMCENTER

.. enunciation::

   :ref:`X_3 <X_3>` is the point of concurrence of the perpendicular bisectors of the sides of :g:`ABC << A B C >>`. The lengths of segments :g:`AX <[ A X ]>`, :g:`BX <[ B X ]>`, :g:`CX <[ C X ]>` are equal if and only if :g:`X <X>` = :ref:`X_3 <X_3>`. This common distance is the radius of the circumcircle, which passes through vertices :g:`A <A>`, :g:`B <B>`, :g:`C <C>`. Called the circumradius, it is given by :math:`R = a/(2 \sin A) = abc/(4 \operatorname{area}(ABC))`.
