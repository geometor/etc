Notes
-----

.. container:: note-item

   Seiichi Kirikami (November 1, 2010), defined a point P having actual trilinear distances (p,q,r) by the equations a + p = b + q = c + r and a point :g:`P' <P'>` with distances (p',q',r') satisfying p - a = q - b = r - c. Here, :g:`P <P>` = :ref:`X_3640 <X_3640>` and :g:`P' <P'>` = :ref:`X_3641 <X_3641>`. Kirikami also discovered a bicentric pair of points satisfying p + b = q + c = r + a and another bicentric pair satisfying p - b = q - c = r - a. The six point are given by homogeneous trilinears :math:`t(a,b,c) : t(b,c,a) : t(c,a,b)` as follows:

   :ref:`X_3640 <X_3640>`: t(a,b,c) = :math:`b^{2}` + :math:`c^{2}` - ab - ac + 2\*area(:g:`ABC << A B C >>`)

   :ref:`X_3641 <X_3641>`: t(a,b,c) = :math:`b^{2}` + :math:`c^{2}` - ab - ac - 2\*area(:g:`ABC << A B C >>`)

   :g:`K_{1} <K_1>`: t(a,b,c) = ac - :math:`b^{2}` + 2\*area(:g:`ABC << A B C >>`)

   :g:`K_{2} <K_2>`: t(a,b,c) = ab - :math:`c^{2}` + 2\*area(:g:`ABC << A B C >>`)

   :g:`K_{3} <K_3>`: t(a,b,c) = ac - :math:`b^{2}` + 2\*area(:g:`ABC << A B C >>`)

   :g:`K_{4} <K_4>`: t(a,b,c) = ab -:math:`cb^{2}` + 2\*area(:g:`ABC << A B C >>`)

.. container:: note-item

   :person:`Peter Moses <peter-moses>` (November 1, 2010) found that the six points lie on an ellipse, E, here called the Kirikami-Moses ellipse. The center of :g:`E <E>` is the incenter of :g:`ABC << A B C >>`, and an equation for :g:`E <E>` is as follows:

      e(a,b,c,x,y,z) + e(b,c,a,y,z,x) + e(c,a,b,z,x,y) = 0, where

   e(a,b,c,x,y,z) = h(a,b,c)\ :math:`x^{2}` - j(a,b,c)yz, where

   :math:`h(a,b,c) = (5a^{4} + b^{4} + c^{4} - 4a^{3}b - 4a^{3}c - 4a^{2}bc + 2b^{2}c^{2} + 2c^{2}a^{2} + 2a^{2}b^{2})`

   and

.. container:: note-item

   Moses found six more points on :g:`E <E>`:

   :g:`M_{1} <M_1>` = (b - c) (a + b + c) + 2\*\ :math:`\sqrt{3}`\ \*area(:g:`ABC << A B C >>`) : :

      * :g:`M_{2} <M_2>` = (b - c) (a + b + c) - 2\*\ :math:`\sqrt{3}`\ \*area(:g:`ABC << A B C >>`) : :
      * :g:`M_{3} <M_3>` = 2ab + ac - :math:`b^{2}` - :math:`2c^{2}` + 2\*\ :math:`\sqrt{3}`\ \*area(:g:`ABC << A B C >>`) : :
      * :g:`M_{4} <M_4>` = 2ac + ab - :math:`c^{2}` - :math:`2b^{2}` + 2\*\ :math:`\sqrt{3}`\ \*area(:g:`ABC << A B C >>`) : :
      * :g:`M_{5} <M_5>` = 2ab + ac - :math:`b^{2}` - :math:`2c^{2}` - 2\*\ :math:`\sqrt{3}`\ \*area(:g:`ABC << A B C >>`) : :
      * :g:`M_{6} <M_6>` = 2ac + ab - :math:`c^{2}` - :math:`2b^{2}` - 2\*\ :math:`\sqrt{3}`\ \*area(:g:`ABC << A B C >>`) : : '

.. container:: note-item

   These six points comprise three bicentric pairs: {:g:`M_{1} <M_1>`, :g:`M_{2} <M_2>`}, {:g:`M_{3} <M_3>`, :g:`M_{4} <M_4>`}, {:g:`M_{5} <M_5>`, :g:`M_{6} <M_6>`}.

.. container:: note-item

   Further properties found by Moses:

      (1) The incenter is the midpoint of the segments :ref:`X_3640 <X_3640>`\ \ :ref:`X_3641 <X_3641>`, :g:`K_{1}K_{2} <[ K_1 K_2 ]>`, and :g:`K_{3}K_{4} <[ K_3 K_4 ]>`.

      (2) :ref:`X_3640 <X_3640>` and :ref:`X_3641 <X_3641>` lie on the line :ref:`X_1 <X_1>`\ \ :ref:`X_6 <X_6>`.

      (3) The lines :g:`K_{1}K_{4} <[ K_1 K_4 ]>` and :g:`K_{2}K_{3} <[ K_2 K_3 ]>` are parallel to the line :ref:`X_1 <X_1>`\ \ :ref:`X_6 <X_6>`.

      (4) The lines :ref:`X_3640 <X_3640>`\ :g:`K_{4} <K_4>`, :g:`K_{1}K_{3} <[ K_1 K_3 ]>`, and :ref:`X_3641 <X_3641>`\ :g:`K_{2} <K_2>` are parallel; indeed, the reflection of the first in the second is the third.\

      (5) The lines :ref:`X_3640 <X_3640>`\ :g:`K_{3} <K_3>`, :g:`K_{2}K_{3} <[ K_2 K_3 ]>`, and :ref:`X_3641 <X_3641>`\ :g:`K_{1} <K_1>` are parallel, and the reflection of the first in the second is the third.

      (6) The lines tangent to :g:`E <E>` at :ref:`X_3640 <X_3640>` and :ref:`X_3641 <X_3641>` are perpendicular to the line :ref:`X_1 <X_1>`\ \ :ref:`X_3 <X_3>`, as are the lines :g:`K_{1}K_{2} <[ K_1 K_2 ]>` and :g:`K_{3}K_{4} <[ K_3 K_4 ]>`.

      (7) The following four lines are parallel: the tangents to :g:`E <E>` at :g:`K_{2} <K_2>` and :g:`K_{4} <K_4>`, and :ref:`X_3640 <X_3640>`\ :g:`K_{1} <K_1>` and :ref:`X_3641 <X_3641>`\ :g:`K_{3} <K_3>`.

      (8) The following four lines are parallel: the tangents to :g:`E <E>` at :g:`K_{1} <K_1>` and :g:`K_{3} <K_3>`, and :ref:`X_3640 <X_3640>`\ :g:`K_{2} <K_2>` and :ref:`X_3641 <X_3641>`\ :g:`K_{4} <K_4>`.
