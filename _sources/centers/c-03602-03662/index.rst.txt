X_3602–X_3662
=============

.. rubric:: Morley Cubics, Medial Homothetic Centers H(X; M, t) & Kirikami-Schiffler Points

.. enunciation::

   Centers associated with the three Morley cubics K029–K031 (:ref:`X_3602 <X_3602>`\ –\ :ref:`X_3615 <X_3615>`), medial-triangle t-dilation homothetic centers H(X; M, t) and their :term:`isogonal conjugates <isogonal-conjugate>` H⁻¹(X; M, t) (:ref:`X_3616 <X_3616>`\ –\ :ref:`X_3637 <X_3637>`), Soddy-Gergonne, Kirikami, Alkaid, and Almach points (:ref:`X_3638 <X_3638>`\ –\ :ref:`X_3646 <X_3646>`), and Kirikami-Schiffler points KS(T) (:ref:`X_3647 <X_3647>`\ –\ :ref:`X_3662 <X_3662>`).

.. _preamble-0055:

.. admonition:: Group Preamble — Homothetic Centers: X_3616-X_3637
   :class: note

   Suppose that X is a :term:`triangle center <triangle-center>`, that M is the :term:`medial triangle <medial-triangle>`, and that t is a real number. The t-dilation of M from :g:`X <X>`, denoted by H(X; M, t), is a triangle center. If :g:`X <X>` =\ :math:`x : y : z` (trilinears), then

   H(X; M, t) = bc[(1 + t)ax + (1 - t)by + (1 - t)cz] : ca[(1 - t)ax + (1 + t)by + (1 - t)cz] : ab[(1 - t)ax + (1 - t)by + (1 + t)cz],

   with inverse given by

   :math:`H^{-1}(X; M, t)` = bc[(1 - t)(by + cz) - 2ax] : ca[(1 - t)(cz + ax) - 2by : ab[(1 - t)(ax + by) - 2cz].

.. _preamble-0056:

.. admonition:: Group Preamble — Kirikami-Schiffler Points: X_3647-X_3652
   :class: note

   Suppose that X is a point and :g:`A'B'C' << A' B' C' >>` is a :term:`central triangle <central-triangle>`. Let :g:`L_{A} <L_A>` be the line through :g:`A' <A'>` parallel to the Euler line of triangle :g:`BCX << B C X >>`, let :g:`L_{B} <L_B>` be the line through :g:`B' <B'>` parallel to the Euler line of :g:`CXA << C X A >>`, and let :g:`L_{C} <L_C>` be the line through :g:`C' <C'>` parallel to the Euler line of :g:`AXB << A X B >>`.

   It is well known that if :g:`X <X>`\ =\ :ref:`X_1 <X_1>`, the incenter, then the three aforementioned Euler lines concur in the Schiffler point, :ref:`X_21 <X_21>`. If their parallels, the lines :g:`L_{A} <L_A>`, :g:`L_{B} <L_B>`, :g:`L_{C} <L_C>` concur, the point of concurrence is the Kirikami-Schiffler point of the triangle :g:`A'B'C' << A' B' C' >>`, denoted by KS(:g:`A'B'C' << A' B' C' >>`). Seiichi Kirikami (February 1, 2011) found that those lines concur if :g:`A'B'C' << A' B' C' >>` is the reference triangle :g:`ABC << A B C >>` and also concur if :g:`A'B'C' << A' B' C' >>` is the medial triangle. :person:`Peter Moses <peter-moses>` found additional cases and properties. A summary follows:

   triangle :g:`A'B'C' << A' B' C' >>` :g:`L_{A} <L_A>`\ ∩\ :g:`L_{B} <L_B>`\ ∩\ :g:`L_{C} <L_C>` :g:`ABC << A B C >>` :ref:`X_79 <X_79>` medial :ref:`X_3647 <X_3647>` excentral :ref:`X_191 <X_191>` anticomplementary :ref:`X_3648 <X_3648>` intouch :ref:`X_3649 <X_3649>` extouch :ref:`X_3650 <X_3650>` Feuerbach :ref:`X_442 <X_442>` Fuhrmann :ref:`X_191 <X_191>` 1st circumperp :ref:`X_3651 <X_3651>` 2nd circumperp :ref:`X_21 <X_21>` Carnot :ref:`X_3652 <X_3652>`

   Suppose that :g:`A'B'C' << A' B' C' >>` is the :term:`cevian triangle <cevian-triangle>` of a point :g:`P <P>`. Then :g:`L_{A} <L_A>`, :g:`L_{B} <L_B>`, :g:`L_{C} <L_C>` concur if and only if P lies on the cubic K455.

   Suppose that :g:`A'B'C' << A' B' C' >>` is the :term:`anticevian triangle <anticevian-triangle>` of a point :g:`P <P>`. Then :g:`L_{A} <L_A>`, :g:`L_{B} <L_B>`, :g:`L_{C} <L_C>` concur if and only if P lies on the cubic given by the barycentric equation

   a(2a + b + c)yz(y - z) + b(2b + c + a)zx(z - x) + c(2c + a + b)xy(x - y) = 0.

   Suppose that :g:`A'B'C' << A' B' C' >>` is the :term:`pedal triangle <pedal-triangle>` of a point :g:`P <P>` on the line :ref:`X_1 <X_1>`\ \ :ref:`X_3 <X_3>`. Then :g:`L_{A} <L_A>`, :g:`L_{B} <L_B>`, :g:`L_{C} <L_C>` concur.

   Suppose that :g:`A'B'C' << A' B' C' >>` is the :term:`antipedal triangle <antipedal-triangle>` of a point :g:`P <P>` on the line :ref:`X_1 <X_1>`\ \ :ref:`X_4 <X_4>`. Then :g:`L_{A} <L_A>`, :g:`L_{B} <L_B>`, :g:`L_{C} <L_C>` concur.
