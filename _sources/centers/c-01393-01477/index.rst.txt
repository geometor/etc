.. admonition:: Group Preamble — Beth Conjugates 1393-1477
   :class: note

   | If X is a :term:`triangle center <triangle-center>` then :g:`X <X>` = :g:`P <P>`-beth conjugate of :g:`P <P>` for some triangle center P. Using the definition of beth conjugate (in the Glossary), it is easy to prove that the :g:`P <P>`-beth conjugate of :g:`P <P>` is the trilinear product :g:`P* <P*>`\ :ref:`X_56 <X_56>`,
   | so that :g:`P <P>` = :g:`X* <X*>`\ :ref:`X_8 <X_8>`. In trilinears,

   if :g:`P <P>` =\ :math:`p : q : r`, then (:g:`P <P>`-beth conjugate of :g:`P <P>`) =\ :math:`up : vq : wr`, where

   | :math:`u : v : w` = a/(b + c - a) : b/(c + a - b) : c/(a + b - c), or equivalently,
   | :math:`u : v : w` = 1 - cos A : 1 - cos B : 1 - cos C.
