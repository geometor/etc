X_4000
======

.. rubric:: X_346com[T(-a, c)]

.. enunciation::

   As described in the preamble to :ref:`X_3758 <X_3758>`, the notation T(-a, c) represents the :term:`central triangle <central-triangle>` whose :g:`A <A>`-vertex is the point :math:`-a : c : b`. This triangle and seven others are discussed just before X_4357.
