X(531) = DIRECTION OF VECTOR AX + BX + CX, where X = X(14) — Code
=================================================================

.. enunciation::

   Let :g:`A' <A'>` be the nine-point center of :g:`BC <[ B C ]>`\ :ref:`X(13) <X(13)>`, and define :g:`B' <B'>` and :g:`C' <C'>` cyclically. :g:`A'B'C' << A' B' C' >>` is an equilateral triangle concyclic with :ref:`X(2) <X(2)>` and :ref:`X(13) <X(13)>` (inscribed in the 1st Hutson circle). The isogonal (and isotomic) conjugate of :ref:`X(2) <X(2)>` wrt :g:`A'B'C' << A' B' C' >>` is :ref:`X(531) <X(531)>`. (:person:`Randy Hutson <randy-hutson>`, February 10, 2016)
