.. rubric:: NAPOLEON CEVAPOINT

.. enunciation::

   Let :g:`N <N>` denote the nine-point center, :ref:`X_5 <X_5>`. Let :g:`N_{A} <N_A>` = N-of-triangle :g:`NBC << N B C >>`, and define :g:`N_{B} <N_B>` and :g:`N_{C} <N_C>` cyclically. Triangle :g:`N_{A}N_{B}N_{C} << N_A N_B N_C >>` is perspective to :g:`ABC << A B C >>`, and :ref:`X_1487 <X_1487>` is the perspector. :ref:`X_1487 <X_1487>` is the :term:`cevapoint <cevapoint>` of the Napoleon points, :ref:`X_17 <X_17>` and :ref:`X_18 <X_18>`. (Coordinates found by :person:`Paul Yiu <paul-yiu>`.)
