X(173) = CONGRUENT ISOSCELIZERS POINT — Code
============================================

.. enunciation::

   Let :g:`P_{B} <P_B>` on sideline :g:`AC <[ A C ]>` and :g:`Q_{C} <Q_C>` be equidistant from :g:`A <A>`, so that :g:`AP_{B}Q_{C} << A P_B Q_C >>` is an isosceles triangle. The line :g:`P_{B}Q_{C} <[ P_B Q_C ]>` is called an :term:`isoscelizer <isoscelizer>`. The lines :g:`P_{B}Q_{C} <[ P_B Q_C ]>`, :g:`P_{C}Q_{A} <[ P_C Q_A ]>`, :g:`P_{A}Q_{B} <[ P_A Q_B ]>` concur in :ref:`X(173) <X(173)>`. (P. Yff, unpublished notes, 1989)
