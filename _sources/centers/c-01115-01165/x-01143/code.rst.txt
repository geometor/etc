X_1143
======

.. rubric:: 2nd MALFATTI-RABINOWITZ POINT

.. enunciation::

   Along each side of :g:`ABC << A B C >>` there is a segment that is a common tangent to two of the three Malfatti circles of :g:`ABC << A B C >>`. Let :g:`A' <A'>`, :g:`B' <B'>`, :g:`C' <C'>` be the midpoints of these respective segments. Then triangle :g:`A'B'C' << A' B' C' >>` isperspective to :g:`ABC << A B C >>`, and the perspector is :ref:`X_1143 <X_1143>`.
